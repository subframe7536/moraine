## Findings considered and rejected

- Replacing `solid-file-router` or the SSG/MDX build pipeline is not worth doing: the current pipeline
  already produces typed routes, prerendered pages, API references, Markdown endpoints, SEO metadata,
  and `llms.txt`; the remaining issues are shared UX integration problems.
- Rewriting component pages wholesale is not justified. Plan 006 performs a targeted 42-page example
  audit, adds common-prop coverage, and preserves generated API content and established page structure.
- Automatically exposing every public prop in a playground is rejected. Author-selected primitive
  controls keep examples understandable; JSX, callbacks, objects, render props, and complex state stay
  in dedicated examples where their behavior can be demonstrated correctly.
- Adding a third-party full-text search dependency is deferred: generated page metadata and heading
  destinations provide the highest-value search improvement without new runtime weight.
