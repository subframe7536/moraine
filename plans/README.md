## Dependency notes

- 001 introduces `cn`, `recipe`, CSS-variable helpers, and explicit preset
  constants while retaining an internal-only legacy bridge so the repository
  remains buildable during the two component-family migrations.
- 002 creates the provider contract used by both family migrations. It does
  not itself change component rendering.
- 003 and 004 jointly remove every internal `cva` caller. Sequential execution
  (003 before 004) is strongly recommended because navigation and overlay
  components (Pagination, Dialog, Sheet, Tabs, Stepper, Tooltip) directly import
  and render elements (Button, Icon, List, Resizable, KbdGroup).
- 005 is deliberately after both migrations because it deletes the legacy
  dependency, precompiled component CSS pipeline, and v3 support.
- 005.5 fixes the Select/MultiSelect resolver boundary, preserves Modal
  primitive ownership, and composes Dialog/Sheet overlay slot overrides with
  the canonical Modal overlay base. Its automated consumer fixtures remain
  isolated built-dist integration tests; real npm tarball/package validation is
  a manual release check owned by the user.
- 006 depended on 005.5 as the final prerequisite and completed the
  repository-wide audit and production-validation gate. Its automated consumer
  coverage remains isolated built-dist integration testing; real npm
  tarball/package validation is a manual release check owned by the user.

## Scope and non-goals

The target is a breaking pre-alpha refactor of the complete Moraine styling
system, not a backward-compatible adapter. Tailwind CSS v3, `cva`,
`extendCN`, shortcut expansion, component CSS bundles, recipe caches, and
claims of constant-time resolution are intentionally removed. `icon.css`
remains an optional runtime mask asset and never replaces the mandatory
Tailwind plugin or UnoCSS preset. Documentation-only UnoCSS authoring syntax
and `transformerVariantGroup` remain outside the library-source token audit.

## Findings considered and rejected

- Keeping a `cva` compatibility export: rejected by the PRD's explicit
  breaking-change decision. A temporary internal bridge is allowed only until
  plans 003 and 004 have migrated all callers; plan 005 removes it.
- Retaining `tw3.css`/`tw4.css` as a fallback: rejected because it obscures
  consumer-engine ownership and cannot make Tailwind v4 plugin registration
  optional.
- Treating `icon.css` as component CSS: rejected. It contains icon mask rules
  only and is intentionally independent of component utility generation.
