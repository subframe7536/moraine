## Usage

Use DropdownMenu for a compact set of actions from a visible trigger. Use [Select](/components/select)
for choosing a form value. Use [ContextMenu](/components/context-menu) for actions at a pointer
location. Use [Popover](/components/popover) when the content is not a list of commands. Use
[Dialog](/components/dialog) when the user must complete a labeled modal task.

```tsx
import { Button, DropdownMenu } from 'moraine'

export function Example() {
  return (
    <DropdownMenu>
      <DropdownMenu.Trigger as={Button}>Actions</DropdownMenu.Trigger>
      <DropdownMenu.Content items={[{ label: 'Copy' }]} />
    </DropdownMenu>
  )
}
```

### Trigger and items

Use `DropdownMenu.Trigger` to compose the click, keyboard, and ARIA behavior with your native
attributes. Describe each action in the item model; groups and separators organize that model
without adding application state.

```tsx
<DropdownMenu>
  <DropdownMenu.Trigger as={Button} trailing="i-lucide:chevron-down">
    Account options
  </DropdownMenu.Trigger>
  <DropdownMenu.Content
    items={[
      { label: 'Edit profile', icon: 'i-lucide:user' },
      { label: 'Billing details', icon: 'i-lucide:credit-card' },
    ]}
  />
</DropdownMenu>
```

### Stateful and nested items

Checkbox items receive their checked state from your application through `checked` and
`onCheckedChange`. A `radio-group` item owns the selected value for its radio items: pass `value` and
`onValueChange` (or `defaultValue` for uncontrolled state) once on the group, and give each radio item
only its `value`. Nested children create submenus. Disabled items remain visible but cannot be
activated.

A parent item with `children` can take `open` and `onOpenChange` to control its submenu. `onOpenChange`
reports every open or close request from pointer, keyboard, or click interaction. With a controlled
`open`, the submenu stays at the prop value until you update it.

```tsx
<DropdownMenu.Content
  items={[
    {
      type: 'checkbox',
      label: 'Show bookmarks bar',
      checked: showBookmarks(),
      onCheckedChange: setShowBookmarks,
    },
    {
      label: 'Theme',
      children: [
        {
          type: 'radio-group',
          value: theme(),
          onValueChange: setTheme,
          items: [{ type: 'radio', label: 'System', value: 'system' }],
        },
      ],
    },
  ]}
/>
```

### Keyboard interaction

| Key                                                        | Description                                           |
| ---------------------------------------------------------- | ----------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> | Opens the menu from an eligible trigger interaction.  |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>                  | Moves the active item through available menu entries. |
| <kbd>ArrowRight</kbd>                                      | Opens an available submenu from its parent item.      |
| <kbd>ArrowLeft</kbd>                                       | Returns from a submenu to its parent menu.            |
| <kbd>Enter</kbd> / <kbd>Space</kbd>                        | Activates the current menu item.                      |
| <kbd>Escape</kbd>                                          | Closes the current menu layer.                        |
