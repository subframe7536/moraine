## Usage

Use DropdownMenu for a compact set of actions from a visible trigger.

- Use [Select](/components/select) for choosing a form value.
- Use [ContextMenu](/components/context-menu) for actions at a pointer location.
- Use [Popover](/components/popover) when the content is not a list of commands.
- Use [Dialog](/components/dialog) when the user must complete a modal task.

```tsx
import { Button, DropdownMenu } from 'moraine'

export function Example() {
  return (
    <DropdownMenu>
      <DropdownMenu.Trigger as={Button}>Actions</DropdownMenu.Trigger>
      <DropdownMenu.Content items={[{ label: 'Copy' }]} />
    </DropdownMenu>
  )
}
```

### Trigger and items

`DropdownMenu.Trigger` adds click, keyboard, and ARIA behavior to the element it renders. It renders
a `button`; pass `as` to render another component such as `Button`, and `disabled` to prevent
opening.

Describe each action in `items`. An entry that is an array of items forms its own group, and the
menu draws a separator between groups. An item accepts `icon`, `kbds`, `disabled`,
and `danger`, and runs `onSelect` before the menu closes. A `{ type: 'separator' }` entry draws a
divider and takes no other options.

```tsx
<DropdownMenu>
  <DropdownMenu.Trigger as={Button} trailing="i-lucide:chevron-down">
    Account options
  </DropdownMenu.Trigger>
  <DropdownMenu.Content
    items={[
      { label: 'Edit profile', icon: 'i-lucide:user' },
      { label: 'Billing details', icon: 'i-lucide:credit-card' },
    ]}
  />
</DropdownMenu>
```

### Stateful and nested items

Control a checkbox item with `checked` and `onCheckedChange`, or omit `checked` and set
`defaultChecked` for uncontrolled state. A `radio-group` item owns the selected value for its radio
items: pass `value` and `onValueChange` (or `defaultValue` for uncontrolled state) once on the
group, and give each radio item only its `value`. Selecting a checkbox or radio item keeps the menu
open.

Nested `children` create submenus, and disabled items stay visible but cannot be activated. A parent
item with `children` can take `open` and `onOpenChange` to control its submenu. `onOpenChange`
reports every open or close request from pointer, keyboard, or click interaction; with a controlled
`open`, the submenu stays at the prop value until you update it.

```tsx
<DropdownMenu.Content
  items={[
    {
      type: 'checkbox',
      label: 'Show bookmarks bar',
      checked: showBookmarks(),
      onCheckedChange: setShowBookmarks,
    },
    {
      label: 'Theme',
      children: [
        {
          type: 'radio-group',
          value: theme(),
          onValueChange: setTheme,
          children: [{ type: 'radio', label: 'System', value: 'system' }],
        },
      ],
    },
  ]}
/>
```

### Dismissal and positioning

Escape and outside interaction close the menu by default. Set `closeOnEscape={false}` or
`closeOnOutsideClick={false}` to keep it open and receive `onClosePrevented` for each blocked
attempt.

By default the menu locks body scroll while open; set `preventScroll={false}` to keep the page
scrollable. `placement` (default `'bottom'`), `align`, `gutter`, `shift`, `flip`, and `slide` tune
where the content opens.

```tsx
<DropdownMenu closeOnOutsideClick={false} onClosePrevented={() => setHint(true)} flip={false}>
  {/* Trigger and Content */}
</DropdownMenu>
```

### Keyboard interaction

| Key                                                        | Description                                                               |
| ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> | Opens the menu from the trigger and focuses the first item.               |
| <kbd>ArrowUp</kbd>                                         | Opens the menu from the trigger and focuses the last item.                |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>                  | Moves focus to the next or previous item.                                 |
| <kbd>Home</kbd> / <kbd>End</kbd>                           | Moves focus to the first or last item.                                    |
| Printable characters                                       | Moves focus to the next item whose text starts with the typed characters. |
| <kbd>ArrowRight</kbd>                                      | Opens the submenu of the focused item.                                    |
| <kbd>ArrowLeft</kbd>                                       | Closes the current submenu and returns to its parent item.                |
| <kbd>Enter</kbd> / <kbd>Space</kbd>                        | Activates the focused item, or opens its submenu.                         |
| <kbd>Escape</kbd>                                          | Closes the current menu layer and restores focus.                         |
| <kbd>Tab</kbd>                                             | Closes the menu.                                                          |
