## Usage

Use Input for native single-line text editing. Compose it with [Field](/components/field) for a
label and validation message, or [InputGroup](/components/input-group) for adjacent addons. Use
[Textarea](/components/textarea) for multi-line text and [NumberInput](/components/number-input)
for a constrained numeric stepper.

```tsx
import { Field, Input } from 'moraine'

export function Example() {
  return (
    <Field label="Your name">
      <Input placeholder="Your name" />
    </Field>
  )
}
```

### Native attributes

`Input` forwards native input attributes. Use `value` with `onValueChange` for controlled text and
`defaultValue` for an initial uncontrolled value; a native form reset restores `defaultValue`.
`value={undefined}` leaves the input uncontrolled, and a controlled input restores its displayed text
to `value` after every edit, so update `value` from `onValueChange`. `readOnly` keeps the field
focusable without allowing edits; `disabled` removes it from interaction. `autoComplete` defaults to
`'off'`.

```tsx
<Input value={query()} onValueChange={setQuery} placeholder="Search projects..." />
```

Inside a [Field](/components/field), Input inherits `size`, `required`, `disabled`, and `readOnly`,
takes its `name` from the field when it sets none, and links the label, description, and error
through ARIA attributes. Set `variant` (`'outline'`, `'subtle'`, `'ghost'`, or `'none'`) and `size`
(`'sm'`, `'md'`, or `'lg'`) to change its presentation.

### Value modifiers

`modifiers` transforms the text before it reaches `onValueChange` and form state, and sets the
callback's value type.

| Modifier | Effect                                                                      |
| -------- | --------------------------------------------------------------------------- |
| `trim`   | Strips surrounding whitespace, also from the displayed text on `change`     |
| `lazy`   | Updates the value on `change` (blur or Enter) instead of on every keystroke |
| `number` | Parses the text to a `number`; empty or non-numeric text gives `null`       |
| `empty`  | `'null'` turns empty text into `null`; `'preserve'` keeps the string        |

```tsx
<Input modifiers={{ number: true, empty: 'null' }} onValueChange={(value) => setAge(value)} />
```

Here `value` is `number | null`. Use [NumberInput](/components/number-input) when the user needs
stepping, bounds, or formatting.

### Composed controls

Use `InputGroup.Leading` and `InputGroup.Trailing` for static context such as an icon or unit.
Password visibility, clearing, copying, and loading stay in your application: compose buttons and
icons into these parts and provide their labels and handlers.

```tsx
<InputGroup>
  <InputGroup.Leading>
    <Icon name="i-lucide:key-round" />
  </InputGroup.Leading>
  <Input type={showPassword() ? 'text' : 'password'} placeholder="Enter secret token" />
  <InputGroup.Trailing compact>
    <Button
      variant="ghost"
      size="icon-sm"
      onClick={() => setShowPassword((prev) => !prev)}
      aria-label={showPassword() ? 'Hide token' : 'Show token'}
    />
  </InputGroup.Trailing>
</InputGroup>
```
