The `table` sits inside a `container` element (`data-slot="table-container"`) that scrolls
horizontally, so wide tables do not stretch the page.

## Usage

Use Table to present data you lay out yourself: invoices, comparison grids, or summaries with a
known set of columns. When the table needs sorting, selection, pagination, or server data, use
[DataTable](/components/data-table) instead. For a one-column collection, use
[List](/components/list).

Table is a styled set of native table elements. Compose the parts in table order.

```tsx
import { Table } from 'moraine'

export function InvoiceTable() {
  return (
    <Table>
      <Table.Caption>Recent invoices</Table.Caption>
      <Table.Header>
        <Table.Row>
          <Table.Head>Invoice</Table.Head>
          <Table.Head>Status</Table.Head>
          <Table.Head align="right">Amount</Table.Head>
        </Table.Row>
      </Table.Header>
      <Table.Body>
        <Table.Row>
          <Table.Cell>INV-001</Table.Cell>
          <Table.Cell>Paid</Table.Cell>
          <Table.Cell align="right">$250.00</Table.Cell>
        </Table.Row>
      </Table.Body>
    </Table>
  )
}
```

### Parts and native attributes

Each part renders one fixed element and forwards native attributes to it.

| Part            | Element   | Own props                |
| --------------- | --------- | ------------------------ |
| `Table`         | `table`   | Variants, `containerRef` |
| `Table.Caption` | `caption` | None                     |
| `Table.Header`  | `thead`   | None                     |
| `Table.Body`    | `tbody`   | None                     |
| `Table.Footer`  | `tfoot`   | None                     |
| `Table.Row`     | `tr`      | `selected`               |
| `Table.Head`    | `th`      | `align`, `truncated`     |
| `Table.Cell`    | `td`      | `align`, `truncated`     |

Use native attributes for table semantics: `colSpan` and `rowSpan` on cells, and `scope="row"` on a
`Table.Head` that labels a body row. Name the table with `Table.Caption`, or with `aria-label` when
a visible caption does not fit.

```tsx
<Table.Row>
  <Table.Head scope="row">Storage</Table.Head>
  <Table.Cell>10 GB</Table.Cell>
  <Table.Cell>100 GB</Table.Cell>
</Table.Row>
```

`ref` targets the `table`; `containerRef` targets the scroll container.

### Density and borders

`size` sets cell padding and text size. `showBorder` draws row dividers (`'row'`, the default),
column dividers (`'col'`), or both (`'both'`). `striped` shades even body rows, and `hoverEffect`
highlights body rows under the pointer. Neither applies to selected rows.

### Alignment and truncation

`align` sets text alignment on `Table.Head` and `Table.Cell`: `'left'` (default), `'center'`, or
`'right'`. Because `Table.Head` defaults to left, header text is not centered the way the browser
centers a plain `th`. Right-align numeric columns in both the header and the cells.

`truncated` keeps text on one line with an ellipsis. Give the cell a width limit, such as a
`max-w-*` class, so there is a width to truncate at.

```tsx
<Table.Cell truncated class="max-w-40">
  {customer.address}
</Table.Cell>
```

### Selected rows

`selected` on `Table.Row` applies the selected background through `data-selected`. It is visual
only: `aria-selected` is not valid on rows of a static table, so it is not set. Put a labelled
control in the row, such as a checkbox, so assistive technology knows the row is selected.

```tsx
<Table.Row selected={isSelected(invoice.id)}>
  <Table.Cell>
    <Checkbox
      checked={isSelected(invoice.id)}
      onCheckedChange={(checked) => setSelected(invoice.id, checked)}
      aria-label={`Select ${invoice.id}`}
    />
  </Table.Cell>
  <Table.Cell>{invoice.id}</Table.Cell>
</Table.Row>
```

### Virtualized rows and columns

For thousands of rows, put `Table.VirtualRows` inside `Table.Body`. Give it the rows as `items`, a
`virtualizer` from `createTableVirtualizer` (`moraine/virtualizer`), and an `itemRender` that
returns one `Table.Row`. Spread `context.props` onto the row; they carry the measurement ref,
`aria-rowindex`, and striping attributes. `Table.VirtualRows` is the only content of its body.

```tsx
const virtualizer = createTableVirtualizer<Invoice>({ estimateSize: () => 41 })

<Table.Body>
  <Table.VirtualRows
    items={invoices}
    virtualizer={virtualizer}
    itemRender={(context) => (
      <Table.Row {...context.props}>
        <Table.Cell>{context.item.id}</Table.Cell>
      </Table.Row>
    )}
  />
</Table.Body>
```

For many columns, create the virtualizer with the `columns` option, pass the columns and their
widths to `Table.VirtualRows`, and render each row's cells with `Table.VirtualCells`. It renders
only the visible columns and fills the skipped ones with placeholder cells. Header and footer rows
still render every column.

```tsx
const virtualizer = createTableVirtualizer<Row, Hour>({
  estimateSize: () => 41,
  columns: { overscan: 2 },
})

<Table.VirtualRows
  items={rows}
  virtualizer={virtualizer}
  scrollElement={scrollElement()}
  columns={hours}
  columnSize={() => 72}
  itemRender={(row) => (
    <Table.Row {...row.props}>
      <Table.VirtualCells<Hour>
        itemRender={(cell) => <Table.Cell {...cell.props}>{row.item.usage[cell.index]}</Table.Cell>}
      />
    </Table.Row>
  )}
/>
```

The [Virtualization guide](/docs/virtualization#table) covers the scroll container and layout.

### Building a data grid

You have two options for a sortable, filterable grid:

- **DataTable.** Use [DataTable](/components/data-table) from `moraine/data-table`. It renders
  sorting, selection, pagination, pinning, resizing, and loading states from a `createDataTable`
  instance.
- **TanStack Table with Table parts.** Use [`@tanstack/solid-table`](https://tanstack.com/table/latest)
  directly and render its header groups and rows with Table parts. You own every control, as in the
  TanStack example below.
