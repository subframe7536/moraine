## Usage

Use `Table` to present tabular data with rows and columns. By default, `Table` wraps the native
`<table>` element in a scrollable `<div>` (`data-slot="table-container"`) to ensure horizontal
scrollability on smaller screens without breaking page layout.

```tsx
import { Table } from 'moraine'

export function InvoiceTable() {
  return (
    <Table>
      <Table.Caption>Recent invoices</Table.Caption>
      <Table.Header>
        <Table.Row>
          <Table.Head>Invoice</Table.Head>
          <Table.Head>Status</Table.Head>
          <Table.Head align="right">Amount</Table.Head>
        </Table.Row>
      </Table.Header>
      <Table.Body>
        <Table.Row>
          <Table.Cell>INV-001</Table.Cell>
          <Table.Cell>Paid</Table.Cell>
          <Table.Cell align="right">$250.00</Table.Cell>
        </Table.Row>
      </Table.Body>
    </Table>
  )
}
```

### Divider Borders

Use `showBorder` to control divider borders on rows and columns:

- `'row'` (default): Displays horizontal borders separating rows and sections.
- `'col'`: Displays vertical dividing borders between columns.
- `'both'`: Displays both horizontal row dividers and vertical column dividers.

```tsx
<Table showBorder="both">
  <Table.Header>
    <Table.Row>
      <Table.Head>Invoice</Table.Head>
      <Table.Head>Status</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell>INV-001</Table.Cell>
      <Table.Cell>Paid</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>
```

### Column Alignment and Truncation

Use `align="left" | "center" | "right"` on `Table.Head` and `Table.Cell` to control text alignment.
Use `truncated` to prevent long text from wrapping and add an ellipsis.

```tsx
<Table.Header>
  <Table.Row>
    <Table.Head truncated class="max-w-[150px]">
      Very Long Column Header
    </Table.Head>
    <Table.Head align="center">Status</Table.Head>
    <Table.Head align="right">Amount</Table.Head>
  </Table.Row>
</Table.Header>
```

### Row Hover

Pass `hoverEffect` to highlight rows on hover. It is disabled by default.

```tsx
<Table hoverEffect>
  <Table.Body>
    <Table.Row>
      <Table.Cell>Hoverable row</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>
```

### Selected Rows

Pass `selected` to `Table.Row` to apply the theme's active background highlight, `data-selected`,
and `aria-selected="true"`.

```tsx
<Table.Row selected={isSelected()}>
  <Table.Cell>Selected Row</Table.Cell>
</Table.Row>
```

### Virtualized Rows

Render long datasets by composing `createTableVirtualizer` from `moraine/virtualizer` inside
`Table.Body`. The adapter observes its host `tbody` as the scroll container, so the header stays
fixed naturally; spread the virtual row props onto `Table.Row` so rows are measured and keyed
correctly. Screen-reader semantics are automatic — the adapter sets `aria-rowcount` on the table
and `aria-rowindex` on every rendered row.

Read the [Virtualization guide](/docs/virtualization) for the fixed-header layout recipe, sizing,
keys, and overscan guidance.

### Data Table with TanStack Table

For advanced headless control over state, column toggling, and complex custom cells, combine Moraine's low-level `Table` primitives with [`@tanstack/solid-table`](https://tanstack.com/table/latest) as shown in the [interactive template below](#interactive-data-table-with-tanstack-table).

If you want a styled data grid around a TanStack Table instance, use Moraine's dedicated [DataTable component](/components/data-table) from `moraine/data-table`. Pass `createDataTable()` as `table`; DataTable renders sorting, selection, pagination, loading overlays, and virtualization from that instance.
