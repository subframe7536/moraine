This is the horizontal layout. A vertical layout wraps the buttons in a `controls` slot after the input.

## Usage

Use NumberInput for a numeric field with step controls and constrained committed values. Use a
plain [Input](/components/input) when free-form numeric text is required, and
[Slider](/components/slider) when the value is chosen spatially.

```tsx
import { Field, NumberInput } from 'moraine'

export function Example() {
  return (
    <Field label="Quantity">
      <NumberInput min={0} max={10} defaultValue={1} />
    </Field>
  )
}
```

### Values and boundaries

`value`, `defaultValue`, and `onValueChange` all use `number | undefined`. `value={undefined}` keeps
the input uncontrolled. Display text comes from `locale` (default: the provider locale, then
`en-US`) and `formatOptions`, so the value stays a plain number. Clearing the input emits
`undefined`. Typing commits as soon as the text is a complete number; partial text such as `-` waits
for blur or Enter. Committed, stepped, and controlled values are clamped to `min` and `max`.
`onValueChange` does not fire when the value is unchanged. Decimal steps are calculated to avoid
typical floating-point display noise.

```tsx
<NumberInput value={value()} onValueChange={setValue} min={0} max={10} locale="de-DE" />
<NumberInput defaultValue={19.99} locale="de-DE" formatOptions={{ style: 'currency', currency: 'EUR' }} />
```

Set `name` to submit the plain number through a hidden input, and `form` to associate the control
with a `<form>` outside its ancestors.

### Stepping and repeat

The default layout is horizontal: decrement button, input, increment button. With
`orientation="vertical"`, both buttons move into a `controls` wrapper after the input. Either way,
the input stays the `spinbutton` keyboard target. `increment={false}` or `decrement={false}` hides a
button, and `incrementDisabled` or `decrementDisabled` disables it without blocking keyboard or
wheel stepping. A button is also disabled at `max` or `min`.

`step` (default `1`) sets the amount for the buttons, ArrowUp and ArrowDown, and the mouse wheel.
`largeStep` (default `step * 10`) sets the amount for PageUp and PageDown, and for the wheel while
Shift is held. By default stepping lands on the step grid anchored at `min` (or at `0` without
`min`), so `step={5}` from `7` goes to `10`; set `stepSnapping={false}` to step from the exact
value. Typed values are clamped, never snapped. The wheel steps only when `wheel` is set and the
input is focused.

Hold-to-repeat on the buttons is enabled by default. Tune it with
`repeat={{ delay, interval, throttle, pointerTypes }}` (defaults `500`, `80`, `0`, and `'all'`;
`interval` has a floor of 16 ms) or disable it with `repeat={false}`.

```tsx
<NumberInput defaultValue={100} step={5} largeStep={25} />
<NumberInput defaultValue={0.5} step={0.1} min={0} max={1} />
```

### Keyboard interaction

Keys have no effect while the control is disabled or read-only.

| Key                  | Description                                          |
| -------------------- | ---------------------------------------------------- |
| <kbd>ArrowUp</kbd>   | Increments the value by `step`.                      |
| <kbd>ArrowDown</kbd> | Decrements the value by `step`.                      |
| <kbd>PageUp</kbd>    | Increments by `largeStep` (defaults to `step * 10`). |
| <kbd>PageDown</kbd>  | Decrements by `largeStep` (defaults to `step * 10`). |
| <kbd>Home</kbd>      | Sets the value to `min` when `min` is set.           |
| <kbd>End</kbd>       | Sets the value to `max` when `max` is set.           |
| <kbd>Enter</kbd>     | Commits the typed text as a number.                  |
