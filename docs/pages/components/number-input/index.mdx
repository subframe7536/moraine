## Usage

Use NumberInput for a numeric field with step controls and constrained committed values. Choose a
plain [Input](/components/input) when free-form numeric text is required. Use
[Slider](/components/slider) when the value is chosen spatially.

```tsx
import { Field, NumberInput } from 'moraine'

export function Example() {
  return (
    <Field label="Quantity">
      <NumberInput minValue={0} maxValue={10} defaultValue={1} />
    </Field>
  )
}
```

### Values and boundaries

`value`, `defaultValue`, and `onValueChange` all use `number | undefined`. Display text comes from
`locale` and `formatOptions`, so the value stays a plain number. Clearing the input emits
`undefined`. The component preserves partial typed input until commit, then applies `minValue` and
`maxValue`. Decimal steps are calculated to avoid typical floating-point display noise.

```tsx
<NumberInput value={value()} onValueChange={setValue} minValue={0} maxValue={10} locale="de-DE" />
```

### Stepping and repeat

In vertical layout, the input precedes an optional controls wrapper containing increment and
decrement buttons. The input remains the spinbutton keyboard target.

`step` controls increment and decrement buttons, while `largeStep` controls PageUp and PageDown.
Hold-to-repeat is enabled by default and can be tuned with `repeat={{ delay, interval, throttle, pointerTypes }}` or disabled with `repeat={false}`.

```tsx
<NumberInput defaultValue={100} step={5} largeStep={25} />
<NumberInput defaultValue={0.5} step={0.1} minValue={0} maxValue={1} />
```

### Keyboard interaction

| Key                  | Description                                             |
| -------------------- | ------------------------------------------------------- |
| <kbd>ArrowUp</kbd>   | Increments the value by `step`.                         |
| <kbd>ArrowDown</kbd> | Decrements the value by `step`.                         |
| <kbd>PageUp</kbd>    | Increments by `largeStep` (defaults to `step * 10`).    |
| <kbd>PageDown</kbd>  | Decrements by `largeStep` (defaults to `step * 10`).    |
| <kbd>Home</kbd>      | Sets the value to `minValue` when a minimum is defined. |
| <kbd>End</kbd>       | Sets the value to `maxValue` when a maximum is defined. |
| <kbd>Enter</kbd>     | Commits the current text input as a numeric value.      |
