## Usage

Use NumberInput for a numeric field with step controls and constrained committed values. Use a
plain [Input](/components/input) when free-form numeric text is required, and
[Slider](/components/slider) when the value is chosen spatially.

```tsx
import { Field, NumberInput } from 'moraine'

export function Example() {
  return (
    <Field label="Quantity">
      <NumberInput min={0} max={10} defaultValue={1} />
    </Field>
  )
}
```

### Values and boundaries

- **Value representation**: `value`, `defaultValue`, and `onValueChange` use `number | null`, where `null` represents an empty input. `value={undefined}` keeps the input uncontrolled, while `value={null}` keeps it controlled and empty.
- **Formatting**: display text is formatted with `locale` (default: provider locale, then `'en-US'`) and `formatOptions`, while the committed value stays a plain number.
- **Commit timing**: clearing the input emits `null`. Typing commits as soon as the text is a complete number; partial text such as `-` waits for blur or Enter. `onValueChange` does not fire when the numeric value is unchanged.
- **Clamping and precision**: committed, stepped, and controlled values are clamped to `min` and `max`. Decimal steps avoid typical floating-point display noise.

```tsx
<NumberInput value={value()} onValueChange={setValue} min={0} max={10} locale="de-DE" />
<NumberInput defaultValue={19.99} locale="de-DE" formatOptions={{ style: 'currency', currency: 'EUR' }} />
```

Set `name` to submit the plain number through a hidden input, and `form` to associate the control with a `<form>` outside its ancestors.

### Stepping and repeat

- **Layout and buttons**: the default horizontal layout places the decrement button, input, and increment button in a row. `orientation="vertical"` moves both buttons into a `controls` wrapper after the input. In both layouts, the input remains the `spinbutton` keyboard target.
- **Visibility and alignment**: `increment={false}` or `decrement={false}` hides a button. `incrementDisabled` or `decrementDisabled` disables a button (as do `max` and `min`) without blocking keyboard or wheel stepping. Without `textAlign`, text is centered, except in a horizontal input with `decrement={false}`, where it is start-aligned.
- **`onStep`**: runs on each step from buttons, keyboard, or wheel with `{ type, emitter, offset, value, event }`. For a button click, it fires before the step so `event.preventDefault()` can cancel it; repeated, keyboard, and wheel steps cannot be cancelled. Use `onValueChange` to observe every value change.
- **Step sizes and snapping**: `step` (default `1`) sets the increment for buttons, ArrowUp/ArrowDown, and the mouse wheel. `largeStep` (default `step * 10`) applies to PageUp/PageDown and Shift+wheel. By default, stepping snaps to the step grid anchored at `min` (or `0` without `min`), so `step={5}` from `7` steps to `10`. Set `stepSnapping={false}` to step from the exact current value. Typed values are clamped, never snapped.
- **Wheel and hold-to-repeat**: the mouse wheel steps only when `wheel` is set and the input is focused. Hold-to-repeat on buttons is enabled by default; tune it with `repeat={{ delay, interval, throttle, pointerTypes }}` (defaults `500`, `80` with a `16` ms floor, `0`, and `'all'`) or disable it with `repeat={false}`.

```tsx
<NumberInput defaultValue={100} step={5} largeStep={25} />
<NumberInput defaultValue={0.5} step={0.1} min={0} max={1} />
```

### Keyboard interaction

Keys have no effect while the control is disabled or read-only.

| Key                  | Description                                          |
| -------------------- | ---------------------------------------------------- |
| <kbd>ArrowUp</kbd>   | Increments the value by `step`.                      |
| <kbd>ArrowDown</kbd> | Decrements the value by `step`.                      |
| <kbd>PageUp</kbd>    | Increments by `largeStep` (defaults to `step * 10`). |
| <kbd>PageDown</kbd>  | Decrements by `largeStep` (defaults to `step * 10`). |
| <kbd>Home</kbd>      | Sets the value to `min` when `min` is set.           |
| <kbd>End</kbd>       | Sets the value to `max` when `max` is set.           |
| <kbd>Enter</kbd>     | Commits the typed text as a number.                  |
