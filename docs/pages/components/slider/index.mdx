## Usage

Use Slider when a numeric value or range is best chosen spatially. Pair it with a labeled numeric
field when users need precise text entry. Use [NumberInput](/components/number-input) when the value
is typed and stepped rather than dragged.
Use [BoldSlider](/components/bold-slider) for a compact single value with the label and value
shown inside the track.

```tsx
import { Field, Slider } from 'moraine'

export function Example() {
  return (
    <Field label="Volume">
      <Slider defaultValue={50} />
    </Field>
  )
}
```

### Single values and ranges

Use a number for one thumb and an array for one thumb per entry, such as an ordered pair for a
range. Values are clamped to `min`–`max` (default `0`–`100`), and arrays are sorted. Pair `value`
with `onValueChange` for controlled state, or use `defaultValue` for uncontrolled state; its shape
sets the shape of the value that callbacks receive.

`onValueChange` fires on every change during a drag, track click, or key press, but not for
programmatic changes to `value`. Use `onValueCommit` to react once when the interaction ends, such
as when saving a setting.

```tsx
<Slider value={volume()} onValueChange={setVolume} />
<Slider value={range()} onValueChange={setRange} onValueCommit={saveRange} />
```

### Step and markers

`step` (default `1`) snaps pointer drag and keyboard navigation to multiples of it from `min`;
`step={0}` keeps the slider continuous. Set `markers` to `true` to draw a tick at each step, or to a
number to draw a tick every that many units without changing how the value snaps.

```tsx
<Slider value={value()} min={0} max={100} step={10} markers onValueChange={setValue} />
<Slider value={value()} min={0} max={100} markers={25} onValueChange={setValue} />
```

### Value text format

`formatOptions` accepts `Intl.NumberFormat` options and formats each thumb's raw value (not its
share of the range) for `aria-valuetext` with the provider locale, as BoldSlider and Progress do. It
does not change the value that callbacks receive. A `percent` style
multiplies by 100, so pair it with a `0`–`1` range. BoldSlider also uses `formatOptions` for its
visible value unless `valueLabel` is a formatter.

```tsx
<Slider defaultValue={50} formatOptions={{ style: 'unit', unit: 'percent' }} aria-label="Zoom" />
```

### Forms

Add `name` for native form submission, or place the slider inside `form.Field` from
[createForm](/components/form) for schema binding. Use standalone [Field](/components/field) when
you only need a label and messages.

```tsx
<Slider name="brightness" defaultValue={75} step={5} min={0} max={100} />
```

### Custom content

Pass `children` to render extra content inside the root after the thumbs. A render function
receives the live `value`, sorted `values`, `percentages` from `0` to `1`, `dragging` state, and the
`startEdge` where the filled range begins. Declare the function's parameter even when you do not use
it; a zero-argument function is called as an accessor and is not mounted as a component.

```tsx
<Slider defaultValue={40}>{(state) => <output>{state.value}</output>}</Slider>
```

### Keyboard interaction

Arrow keys move by `step` (default `1`); with `step={0}` they move by 1% of the configured range.
Page-sized movement is approximately 10% of the range and is snapped to `step` when above `0`. Horizontal
arrow keys swap in right-to-left layouts, and a `reversed` vertical slider swaps <kbd>ArrowUp</kbd>
and <kbd>ArrowDown</kbd>.

| Key                                         | Description                                             |
| ------------------------------------------- | ------------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowUp</kbd>  | Moves in the increasing direction by one keyboard step. |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowDown</kbd> | Moves in the decreasing direction by one keyboard step. |
| <kbd>Shift + Arrow</kbd>                    | Moves by the page-sized increment.                      |
| <kbd>PageUp</kbd> / <kbd>PageDown</kbd>     | Moves by the page-sized increment.                      |
| <kbd>Home</kbd>                             | Moves the focused thumb to its minimum permitted value. |
| <kbd>End</kbd>                              | Moves the focused thumb to its maximum permitted value. |
