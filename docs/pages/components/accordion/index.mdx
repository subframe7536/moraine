## Usage

Use Accordion for several related disclosures that share one open-item policy. For a single independent
disclosure, use [Collapsible](/components/collapsible).

```tsx
import { Accordion } from 'moraine'

export function Example() {
  return (
    <Accordion items={[{ value: 'shipping', label: 'Shipping', content: 'Ships in two days.' }]} />
  )
}
```

### Content

`content` accepts text or JSX, or a component that receives `{ value, expanded, closed, disabled }`.
Use the component form when the panel depends on the item state. Content mounts on first open. `headingLevel` (default `3`) sets the heading level that
wraps each trigger. `icon` adds a leading icon to an item, and `trailing` replaces the indicator icon
for every item.

```tsx
<Accordion
  items={[
    { value: 'billing', label: 'Billing', content: (props) => <Invoices open={props.expanded} /> },
  ]}
/>
```

### Open items

`value`, `defaultValue`, and `onValueChange` always use an array of item values. By default, opening an
item closes the others. Set `multiple` to allow several open items. Pair `value` with `onValueChange`
when the page owns the open set. `onValueChange` receives the complete next array and fires only for
user toggles, not for changes you make to `value`. In single mode, `collapsible` (default `true`)
controls whether the open item can close; with `multiple`, every item can always close.

```tsx
const [open, setOpen] = createSignal<string[]>(['shipping'])

<Accordion items={items} value={open()} onValueChange={setOpen} collapsible />
<Accordion multiple defaultValue={['general', 'security']} items={items} />
```

### Content lifetime

The content shell always stays mounted, so each trigger's `aria-controls` points to a real element.
`forceMount` controls only the content inside that shell. By default, content mounts on first open and
unmounts when it closes. Set `forceMount` to mount content before the first open and keep it mounted, so
hidden fields preserve local state.

```tsx
<Accordion forceMount defaultValue={['notes']} items={items} />
```

### Keyboard interaction

| Key                                 | Description                                  |
| ----------------------------------- | -------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Toggles the focused trigger when enabled.    |
| <kbd>ArrowDown</kbd>                | Moves focus to the next enabled trigger.     |
| <kbd>ArrowUp</kbd>                  | Moves focus to the previous enabled trigger. |
| <kbd>Home</kbd>                     | Moves focus to the first enabled trigger.    |
| <kbd>End</kbd>                      | Moves focus to the last enabled trigger.     |

Arrow-key focus wraps from the last trigger to the first by default. Set `loop={false}` to stop at
either end. Disabled items are skipped.
