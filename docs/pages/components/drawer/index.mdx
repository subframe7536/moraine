## Usage

Use Drawer for a mobile-style surface the user dismisses with a swipe along its edge, optionally
resting at snap points. Use [Sheet](/components/sheet) for an edge panel without gestures. Use
[Dialog](/components/dialog) for a centered labeled task, and [Modal](/components/modal) to compose
backdrop and content yourself.

Drawer shares modal dismissal and focus behavior with Dialog. The default side is `bottom`.

```tsx
import { Button, Drawer } from 'moraine'

export function Example() {
  return (
    <Drawer>
      <Drawer.Trigger as={Button}>Open</Drawer.Trigger>
      <Drawer.Content title="Details">
        <Drawer.Body>Drawer content</Drawer.Body>
        <Drawer.Footer>
          <Drawer.Close as={Button}>Done</Drawer.Close>
        </Drawer.Footer>
      </Drawer.Content>
    </Drawer>
  )
}
```

### Content composition

Use Content `title` and `description` for simple cases, or compose `Drawer.Header`, `Drawer.Title`,
`Drawer.Description`, `Drawer.Body`, and `Drawer.Footer` for a custom layout — the same contract as
[Sheet](/components/sheet#content-composition). An explicit `Drawer.Header` replaces the generated
header. `Drawer.Close` is an explicit close control; root `closable` adds the automatic corner close
button (off by default), and `closeIcon` replaces its icon.

For `top` and `bottom` sides, Content renders a decorative `handle` grab bar as its first child
(`order-last` on top). Set `handle={false}` to hide it.

### Swipe to dismiss

The surface tracks a drag along its dismiss axis — down for `bottom`, up for `top`, and outward for
`left`/`right` — and closes past half its size or on a fast flick. A drag against the dismiss
direction is damped and springs back. The `data-swiping` attribute on the content and overlay marks
the active gesture so transitions pause.

A drag never starts on interactive elements (`button`, `a`, form controls, `[contenteditable]`,
`[role="slider"]`), on `[data-swipe-ignore]` subtrees, or on a mouse press inside `Drawer.Body`, which
stays available for text selection. On touch, `data-swipe-ignore="x"` or `"y"` blocks only that axis.
Touch drags that begin inside a scrollable region defer to native scrolling until the scroller
reaches its edge in the drag direction.

```tsx
<Drawer.Body>
  <div data-swipe-ignore>Drag-free region</div>
</Drawer.Body>
```

### Snap points

`snapPoints` limits where a `top` or `bottom` drawer rests: numbers `<= 1` are a fraction of the
viewport height, larger numbers are pixels, and `'px'`/`'rem'` strings resolve directly. Snap points
are ignored for `left` and `right`. Snap heights are clamped to the content's rendered height, so
give Content an explicit height (for example `class="h-[calc(100dvh-4rem)]"`) when using fractional
or full snap points.

`snapPoint` / `defaultSnapPoint` / `onSnapPointChange` control the resting point (the default is the
first snap point). Release settles on the closest point or closes; `snapToSequentialPoints` advances
at most one point per flick and closes only from the last point.

```tsx
const [snapPoint, setSnapPoint] = createSignal<DrawerT.SnapPoint | null>('148px')

<Drawer snapPoints={['148px', 1]} snapPoint={snapPoint()} onSnapPointChange={setSnapPoint}>
```

### CSS variables

Content declares these variables; set them with `styles.content` or measure them from the binding.

| Variable                     | Default | Description                                       |
| ---------------------------- | ------- | ------------------------------------------------- |
| `--drawer-swipe-movement`    | `0px`   | Current swipe offset along the surface axis.      |
| `--drawer-snap-point-offset` | `0px`   | Offset of the active snap point from fully open.  |
| `--drawer-keyboard-inset`    | `0px`   | Bottom inset reserved for the on-screen keyboard. |

### Keyboard interaction

| Key                    | Description                                             |
| ---------------------- | ------------------------------------------------------- |
| <kbd>Escape</kbd>      | Requests dismissal when `closeOnEscape` is not `false`. |
| <kbd>Tab</kbd>         | Moves focus forward; modal drawers contain focus.       |
| <kbd>Shift + Tab</kbd> | Moves focus backward; modal drawers contain focus.      |

On Android, the system back gesture closes the drawer on browsers that support `CloseWatcher`.
It follows `closeOnEscape` and reports blocked requests through `onClosePrevent`.
