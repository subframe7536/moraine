## Usage

Create a reactive table instance with `createDataTable({ data, columns, ... })` and pass it to `DataTable` via `table`. `createDataTable` configures sorting, selection, expansion, pagination, pinning, resizing, and controlled state on a TanStack Solid Table instance; `DataTable` handles styling, slots, and render parts.

```tsx
import { DataTable, createDataTable } from 'moraine'
import type { DataTableT } from 'moraine'

const data = [
  { id: '1', name: 'Alice', role: 'Engineer' },
  { id: '2', name: 'Bob', role: 'Designer' },
]

const columns: DataTableT.Column<(typeof data)[number]>[] = [
  { accessorKey: 'name', header: 'Name' },
  { accessorKey: 'role', header: 'Role' },
]

export function Example() {
  const table = createDataTable({
    data,
    columns,
    selection: 'multiple',
  })

  return <DataTable table={table} />
}
```

### Selection Modes and Disabled Rows

Set `selection: 'multiple'` to prepend a checkbox column (id `'select'`) with a select-all header, or `selection: 'single'` for radio buttons. Lock specific rows with `canSelectRow`:

```tsx
const table = createDataTable({
  data,
  columns,
  selection: 'single',
  canSelectRow: (row) => row.original.status !== 'terminated',
})

return <DataTable table={table} />
```

### Expandable Rows

Set `expandable: true` (or a `(row) => boolean` predicate) to prepend a chevron toggle column (id `'expand'`), and pass `expandedRowRender` on `DataTable`:

```tsx
const table = createDataTable({
  data,
  columns,
  expandable: true,
})

return (
  <DataTable
    table={table}
    expandedRowRender={(props) => (
      <div>
        Order #{props.row.original.id} contains {props.row.original.items.length} items.
      </div>
    )}
  />
)
```

### Pagination and Server Mode

Pagination is off by default. Pass `pagination: true` or `pagination: { pageSize, pageSizes }` to slice rows and show the pagination toolbar (`pageSizes: false` hides the page-size dropdown). For server-driven sorting, filtering, and paging, set `manual: true` and `rowCount`, pass signals to `state`, and handle resolved values in `onSortingChange` / `onPaginationChange`:

```tsx
const [sorting, setSorting] = createSignal<DataTableT.State['sorting']>([])
const [pagination, setPagination] = createSignal({ pageIndex: 0, pageSize: 20 })

const table = createDataTable({
  data: serverRows,
  columns,
  manual: true,
  rowCount: totalCount,
  pagination: { pageSizes: [10, 20, 50] },
  state: { sorting, pagination },
  onSortingChange: setSorting,
  onPaginationChange: setPagination,
})

return <DataTable table={table} loading={isFetching()} />
```

### Column Pinning

Freeze identifier columns on the start edge or action buttons on the end edge during horizontal scrolling with `initialState.columnPinning` or `state.columnPinning` (injected utility columns use `'select'` and `'expand'`):

```tsx
const table = createDataTable({
  data,
  columns,
  selection: 'multiple',
  initialState: {
    columnPinning: { start: ['select', 'id'], end: ['actions'] },
  },
})

return <DataTable table={table} />
```

### Sticky Header and Footer

Pin the header to the top — and the footer to the bottom — of a scrollable container with `sticky` (`true`, `'header'`, or `'footer'`) and `maxHeight`:

```tsx
<DataTable table={table} sticky maxHeight={360} />
```

### Column Resizing

Enable drag handles on column headers with `resizable: true`:

```tsx
const table = createDataTable({
  data,
  columns,
  resizable: true,
})

return <DataTable table={table} />
```

### Column Order

Control visible column order with `state.columnOrder` and `onColumnOrderChange`. Values are column ids, matching `accessorKey` unless a column sets `id`:

```tsx
const [columnOrder, setColumnOrder] = createSignal(['name', 'role', 'department'])

const table = createDataTable({
  data,
  columns,
  state: { columnOrder },
  onColumnOrderChange: setColumnOrder,
})

return <DataTable table={table} />
```

### Virtualization

Pass `virtualRender={virtualizer.virtualRender}` using `createTableVirtualizer` from `moraine/virtualizer` to virtualize large datasets while keeping native table semantics and column alignment. Leave `pagination` off when virtualizing.
