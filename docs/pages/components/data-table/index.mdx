## Usage

Use `DataTable` as the styled presenter for a TanStack Table instance. Create the table with
`createTable` and `getDefaultDataTableFeatures()`, then pass it as `table`. DataTable props are
style, slots, and render parts only — sorting, selection, pagination, pinning, and resizing are
configured on the table instance. When `table` is omitted, DataTable renders an empty table with
default features.

```tsx
import type { ColumnDef } from '@tanstack/solid-table'
import { createTable } from '@tanstack/solid-table'
import { DataTable, createSelectColumn, getDefaultDataTableFeatures } from 'moraine'

const data = [
  { id: '1', name: 'Alice', role: 'Engineer' },
  { id: '2', name: 'Bob', role: 'Designer' },
]

const columns: ColumnDef<any, (typeof data)[number]>[] = [
  createSelectColumn(),
  { accessorKey: 'name', header: 'Name' },
  { accessorKey: 'role', header: 'Role' },
]

export function Example() {
  const table = createTable({
    features: getDefaultDataTableFeatures({ pagination: false }),
    columns,
    data,
  })

  return <DataTable table={table} />
}
```

### Column Pinning

Freeze critical identifier columns on the start edge or action buttons on the end edge during
horizontal scrolling. Set `state.columnPinning` on `createTable` using TanStack's `start` / `end`
regions:

```tsx
const table = createTable({
  features: getDefaultDataTableFeatures({ pagination: false }),
  columns,
  data,
  state: {
    columnPinning: { start: ['select', 'id'], end: ['actions'] },
  },
})

return <DataTable table={table} />
```

### Sticky Header

Pin the table header to the top of a scrollable container with `stickyHeader` and `maxHeight`:

```tsx
<DataTable table={table} stickyHeader maxHeight={360} />
```

### Column Resizing

Enable drag handles by setting `enableColumnResizing` on the table instance:

```tsx
const table = createTable({
  features: getDefaultDataTableFeatures({ pagination: false }),
  columns,
  data,
  enableColumnResizing: true,
})

return <DataTable table={table} />
```

### Column Order

Control visible column order with `state.columnOrder` on `createTable`. Values are column ids,
matching `accessorKey` unless a column sets `id`.

```tsx
const table = createTable({
  features: getDefaultDataTableFeatures({ pagination: false }),
  columns,
  data,
  state: {
    get columnOrder() {
      return columnOrder()
    },
  },
  onColumnOrderChange: setColumnOrder,
})

return <DataTable table={table} />
```

### Expandable Rows

Add `createExpandColumn()` to the column list, allow rows to expand on the table instance, and pass
`expandedRowRender` as a DataTable part:

```tsx
const table = createTable({
  features: getDefaultDataTableFeatures({ pagination: false }),
  columns: [createExpandColumn(), ...columns],
  data,
  getRowCanExpand: () => true,
})

return (
  <DataTable
    table={table}
    expandedRowRender={(row) => (
      <div>
        Order #{row.original.id} contains {row.original.items.length} items.
      </div>
    )}
  />
)
```

### Selection Modes and Disabled Rows

Add `createSelectColumn()` for checkboxes or `createSelectColumn({ mode: 'single' })` for radios.
Disable rows with `enableRowSelection` on `createTable`:

```tsx
const table = createTable({
  features: getDefaultDataTableFeatures({ pagination: false }),
  columns: [createSelectColumn({ mode: 'single' }), ...columns],
  data,
  enableMultiRowSelection: false,
  enableRowSelection: (row) => row.original.status !== 'terminated',
})

return <DataTable table={table} />
```

### Virtualization

Pass `virtualRender={virtualizer.virtualRender}` using `createTableVirtualizer` from `moraine/virtualizer` to virtualize large datasets while keeping native table semantics and column alignment. Use `getDefaultDataTableFeatures({ pagination: false })` so row virtualization is not sliced by paging.
