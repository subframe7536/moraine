## Usage

Use Textarea for multi-line native text entry. Use [Input](/components/input) for a single line.
Use [InputGroup](/components/input-group) to put controls around it without changing which element
receives typing and focus.

```tsx
import { Field, Textarea } from 'moraine'

export function Example() {
  return (
    <Field label="Message">
      <Textarea placeholder="Write a message" />
    </Field>
  )
}
```

### Native text behavior

`Textarea` forwards native textarea attributes and works with controlled or uncontrolled values.
Use `readOnly` to preserve selection and focus without edits, or `disabled` to prevent interaction.

```tsx
<Textarea value={bio()} onValueChange={setBio} rows={3} />
```

### Size and composition

Enable autoresize and constrain it with `rows` and `maxRows`. Use
`InputGroup orientation="vertical"` with `Leading` and `Trailing` for header and footer regions.
Counters, submit buttons, and keyboard shortcuts remain application-owned behavior.

```tsx
<InputGroup orientation="vertical">
  <Textarea placeholder="Write a comment..." autoResize rows={2} maxRows={6} />
  <InputGroup.Trailing>
    <span>Markdown supported</span>
    <Button size="xs">Comment</Button>
  </InputGroup.Trailing>
</InputGroup>
```
