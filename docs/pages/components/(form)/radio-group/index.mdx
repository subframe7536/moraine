## Usage

Use RadioGroup for one choice from a small visible set. For a longer or space-constrained
collection, use [Select](/components/select). Use [CheckboxGroup](/components/checkbox-group) when
several options may be selected together.

```tsx
import { Field, RadioGroup } from 'moraine'

export function Example() {
  return (
    <Field label="Visibility">
      <RadioGroup
        items={[
          { value: 'public', label: 'Public' },
          { value: 'private', label: 'Private' },
        ]}
      />
    </Field>
  )
}
```

### Single selection

Use one string value for the selected item and pair `value` with `onValueChange` for controlled
state. Disabled items remain visible but cannot be selected. The group uses radio keyboard behavior
rather than the independent focus order of checkboxes.

```tsx
<RadioGroup items={planOptions} value={plan()} onValueChange={setPlan} />
```

### Forms

Set `name` for native form submission. For schema binding and validation, place the group inside
`form.Field` from [createForm](/components/form). Standalone [Field](/components/field) supplies
labels and messages without binding a form store.

```tsx
<RadioGroup name="environment" items={envOptions} defaultValue="staging" />
```

### Indicator

`indicator` places the radio mark at `start` or `end`, or hides it with `hidden`.

```tsx
<RadioGroup indicator="end" items={items} />
<RadioGroup indicator="hidden" items={items} />
```

### Keyboard interaction

| Key                                          | Description                                                   |
| -------------------------------------------- | ------------------------------------------------------------- |
| <kbd>ArrowDown</kbd> / <kbd>ArrowRight</kbd> | Moves focus and selection to the next enabled radio item.     |
| <kbd>ArrowUp</kbd> / <kbd>ArrowLeft</kbd>    | Moves focus and selection to the previous enabled radio item. |
| <kbd>Space</kbd>                             | Selects the focused radio item.                               |
| <kbd>Tab</kbd>                               | Enters or leaves the group according to normal focus order.   |
