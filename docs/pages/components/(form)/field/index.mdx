## Usage

Use Field to label a standalone control and attach description, help, and error text. It registers
the nested control, inherits size and disabled state, and wires ARIA relationships. It does not
validate or submit values.

For schema binding, use `form.Field` from [createForm](/components/form). Put a Moraine control
inside Field so its label, description, and error IDs attach to the actual focusable element. For
local validation, pass the current message to `error`.

```tsx
import { Field, Input } from 'moraine'

export function Example() {
  return (
    <Field label="Email">
      <Input name="email" type="email" />
    </Field>
  )
}
```

### Visually hidden labels

Use `hiddenLabel` when a compact control needs an accessible name without a visible label. It
preserves the label association without reserving label spacing or an empty horizontal label
column. A non-empty `label` takes precedence over `hiddenLabel`. Hint and description text remain
visible; help and error text keep their usual placement.

```tsx
<Field hiddenLabel="Filter commands" help="Search by command name or shortcut.">
  <Input placeholder="Filter commands…" />
</Field>
```

For a switch with a trailing visible label, use `<Switch label="Auto refresh" />`.

### Orientation

`orientation="horizontal"` lays the label beside the control. Use it for settings rows. Vertical
is the default stacked layout.

```tsx
<Field orientation="horizontal" label="Display name" description="Shown to other users.">
  <Input />
</Field>
```

Help and error are mutually exclusive; the error replaces help when the field is invalid.
