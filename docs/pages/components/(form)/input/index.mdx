## Usage

Use Input for native single-line text editing. Compose it with [Field](/components/field) for a
label and validation message, or [InputGroup](/components/input-group) for adjacent addons. Use
[Textarea](/components/textarea) for multi-line text and [InputNumber](/components/input-number)
for a constrained numeric stepper.

```tsx
import { Field, Input } from 'moraine'

export function Example() {
  return (
    <Field label="Your name">
      <Input placeholder="Your name" />
    </Field>
  )
}
```

### Native input behavior

`Input` forwards native input attributes. Use `value` with `onValueChange` for controlled text and
`defaultValue` for an initial uncontrolled value. `readOnly` keeps the field focusable without
allowing edits; `disabled` removes it from interaction.

```tsx
<Input value={query()} onValueChange={setQuery} placeholder="Search projects..." />
```

### Composed controls

Use `InputGroup.Leading` and `InputGroup.Trailing` for static context such as an icon or unit.
Password visibility, clearing, copying, and loading remain application behavior: compose buttons
and icons into these parts and provide their labels and handlers.

```tsx
<InputGroup>
  <InputGroup.Leading>
    <Icon name="i-lucide:key-round" />
  </InputGroup.Leading>
  <Input type={showPassword() ? 'text' : 'password'} placeholder="Enter secret token" />
  <InputGroup.Trailing compact>
    <Button
      variant="ghost"
      size="icon-sm"
      onClick={() => setShowPassword((prev) => !prev)}
      aria-label={showPassword() ? 'Hide token' : 'Show token'}
    />
  </InputGroup.Trailing>
</InputGroup>
```
