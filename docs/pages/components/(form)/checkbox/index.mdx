## Usage

Use Checkbox for an independent boolean or mapped choice that can be selected alongside other
choices. Use [Switch](/components/switch) when the control represents an immediate on/off setting.
Use [CheckboxGroup](/components/checkbox-group) when several choices submit as one array.

```tsx
import { Checkbox } from 'moraine'

export function Example() {
  return <Checkbox label="Accept terms" />
}
```

### State and form values

Use `checked` with `onCheckedChange` for controlled state, or `defaultChecked` for an initial value.
Set `indeterminate` from aggregate selection state; it changes the mixed presentation without
adding a third submitted value.

`trueValue` and `falseValue` map checked state to domain values for callbacks and schema-bound
forms. Native form submission uses the separate `value` prop only while checked; an unchecked
checkbox contributes no entry.

```tsx
<Checkbox
  checked={checked()}
  onCheckedChange={setChecked}
  label="Subscribe to product updates"
/>
<Checkbox trueValue="opted-in" falseValue="opted-out" label="Anonymous telemetry" />
```

### Read-only and disabled

`disabled` removes the control from normal interaction. `readOnly` preserves the value and
focusability while preventing changes.

```tsx
<Checkbox disabled defaultChecked label="Disabled" />
<Checkbox readOnly defaultChecked label="Read-only" />
```
