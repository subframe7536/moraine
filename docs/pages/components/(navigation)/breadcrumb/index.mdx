import { Breadcrumb } from '@src'

Use Breadcrumb to show a resource’s place in a navigation hierarchy. The current page is represented as a non-link item.

## Basic usage

```tsx
import { Breadcrumb } from 'moraine'

export function Example() {
  return <Breadcrumb items={[{ label: 'Home', href: '/' }, { label: 'Settings' }]} />
}
```

## Usage

### Items and current page

Use links for navigable ancestors. The last item is the current page by default; use `active` to select another item explicitly. The current page is a non-link `span` with `aria-current="page"`. Explicitly disabled ancestors remain non-interactive and expose `aria-disabled="true"`.
