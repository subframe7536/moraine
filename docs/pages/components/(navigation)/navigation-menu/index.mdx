## Usage

Use NavigationMenu for website destinations, with direct links and expandable link panels. Use [DropdownMenu](/components/dropdown-menu) for a menu of actions.

```tsx
import { NavigationMenu } from 'moraine'

export function Example() {
  return (
    <NavigationMenu aria-label="Main navigation">
      <NavigationMenu.List>
        <NavigationMenu.Item value="products">
          <NavigationMenu.Trigger>Products</NavigationMenu.Trigger>
          <NavigationMenu.Content>
            <NavigationMenu.Link href="/overview" closeOnClick>
              Overview
            </NavigationMenu.Link>
          </NavigationMenu.Content>
        </NavigationMenu.Item>
        <NavigationMenu.Item>
          <NavigationMenu.Link href="/docs">Documentation</NavigationMenu.Link>
        </NavigationMenu.Item>
      </NavigationMenu.List>
    </NavigationMenu>
  )
}
```

### Basic

Combine expandable panels with direct links. Use `NavigationMenu.Content` for each panel and `NavigationMenu.Link` for its destinations.

<Preview path="./basic" />

### Controlled state and disabled items

Use stable item values with `value` and `onValueChange`. Set the value to `null` to close. Disabled or removed items cannot keep a panel open. `defaultValue` opens an item after hydration.

<Preview path="./controlled" />

### Orientation

Set `orientation="vertical"` for a vertical list. Use `placement="right"` to place its panels beside the triggers.

<Preview path="./orientation" />

### RTL

Set `dir="rtl"` on the surrounding container for right-to-left navigation.

<Preview path="./rtl" />

### Custom links

Use `linkRender` for a router's link component. Forward the supplied attributes, events, children, object style and ref to the anchor. `active` marks the current page with `aria-current="page"`. `closeOnClick` defaults to `false`; enable it when activation should also close the panel. A cancelled click does not request closing.

<Preview path="./router-link" />

### Keyboard interaction

Arrow keys along the list axis move focus without opening a panel. Home and End focus the first and last enabled navigation controls. Enter and Space activate a trigger. ArrowDown opens a horizontal menu and enters its content; ArrowRight does the same for a vertical LTR menu, and ArrowLeft for RTL.

Tab and Shift+Tab preserve the order between the trigger, its portaled content and the following navigation control. Arrow keys and Home/End move between panel links, while inputs retain their editing keys. Escape closes the panel and returns focus to its trigger. Outside click and focus close the panel without taking focus away from the destination.

The root renders a navigation landmark. Give it an accessible name when the page has several navigation landmarks. This version supports one level of panels.
