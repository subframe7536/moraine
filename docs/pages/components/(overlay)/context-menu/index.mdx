## Usage

Use ContextMenu for actions tied to a specific surface or item at the pointer location. Use
[DropdownMenu](/components/dropdown-menu) when the same actions open from a visible trigger. Use
[Popover](/components/popover) when the content is not a list of commands. Use
[Dialog](/components/dialog) when the user must confirm a labeled modal task. Keep essential
actions discoverable through another visible path.

```tsx
import { ContextMenu } from 'moraine'

export function Example() {
  return (
    <ContextMenu>
      <ContextMenu.Trigger>Right-click here</ContextMenu.Trigger>
      <ContextMenu.Content items={[{ label: 'Copy' }]} />
    </ContextMenu>
  )
}
```

### Triggering the menu

Wrap the target with `ContextMenu.Trigger`. The menu opens from a context-menu gesture, keyboard
context-menu keys, or a supported touch/pen long press.

```tsx
<ContextMenu>
  <ContextMenu.Trigger as="div" class="flex h-32 items-center justify-center">
    Right-click or long-press inside this area
  </ContextMenu.Trigger>
  <ContextMenu.Content
    items={[
      { label: 'Back', icon: 'i-lucide:arrow-left' },
      { label: 'Forward', icon: 'i-lucide:arrow-right', disabled: true },
      { label: 'Reload', icon: 'i-lucide:rotate-cw' },
    ]}
  />
</ContextMenu>
```

### Item models

Groups, separators, checkbox items, radio items, disabled items, and nested children are all
represented in the public item model. Keep state for checkbox and radio values in the application
and update it through item callbacks.

```tsx
<ContextMenu.Content
  items={[
    {
      type: 'checkbox',
      label: 'Pin item',
      checked: pinned(),
      onCheckedChange: setPinned,
    },
    { type: 'separator' },
    {
      type: 'radio',
      label: 'High priority',
      group: 'priority',
      value: 'high',
      checked: priority() === 'high',
      onValueChange: setPriority,
    },
  ]}
/>
```

### Keyboard interaction

| Key                                             | Description                                                |
| ----------------------------------------------- | ---------------------------------------------------------- |
| <kbd>Shift + F10</kbd> / <kbd>ContextMenu</kbd> | Opens from a focused trigger when the trigger supports it. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>       | Moves the active item through available menu entries.      |
| <kbd>ArrowRight</kbd>                           | Opens an available submenu from its parent item.           |
| <kbd>ArrowLeft</kbd>                            | Returns from a submenu to its parent menu.                 |
| <kbd>Enter</kbd> / <kbd>Space</kbd>             | Activates the current menu item.                           |
| <kbd>Escape</kbd>                               | Closes the current menu layer.                             |
