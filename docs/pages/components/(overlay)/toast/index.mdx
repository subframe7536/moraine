`<Toast />` renders an accessible, portaled root live region and list stack. Individual toast notifications render as list items with status icon, wrapper with title and description, action and cancel buttons, close control, and duration progress bar.

## Usage

Use Toast for temporary feedback that does not interrupt the user's workflow. Use
[Dialog](/components/dialog) when an action requires explicit user confirmation. Use
[Empty](/components/empty) to explain missing content within the page layout.

Mount `<Toast />` once at your application root or inside a layout. Trigger notifications from
event handlers or asynchronous tasks using static methods on `Toast`.

```tsx
import { Button, Toast } from 'moraine'

export function Example() {
  return (
    <>
      <Button onClick={() => Toast.success({ title: 'Preferences saved' })}>Save</Button>
      <Toast />
    </>
  )
}
```

### Status tones

Call dedicated tone methods to communicate distinct outcomes, or use `Toast.add` for a neutral notice:

```tsx
Toast.success({ title: 'Project published', description: 'Your changes are now live.' })
Toast.error({ title: 'Upload failed', description: 'File size exceeds the 10 MB limit.' })
Toast.warning({ title: 'Low disk space', description: 'Volume is at 92% capacity.' })
Toast.info({ title: 'Update available', description: 'Version 2.4 is ready to install.' })
Toast.add({ title: 'Draft saved' })
```

### Action and dismissal

Provide an interactive `action` button for reversible operations, or a `cancel` button for explicit dismissal:

```tsx
Toast.add({
  title: 'Conversation archived',
  action: {
    label: 'Undo',
    onClick: () => restoreConversation(),
  },
})
```

### Large multi-line layout

Enable `large` to switch to a multi-line notification layout where actions wrap to a full-width bottom row and the close control moves to the top-right corner:

```tsx
Toast.success({
  title: 'Export finished',
  description: 'Your dataset is packaged and ready to download.',
  variants: { large: true },
  action: { label: 'Download', onClick: () => downloadFile() },
  cancel: { label: 'Dismiss', onClick: () => {} },
  close: { label: 'Close' },
})
```

You can also set `large` globally on the `<Toast large />` host component to render all notifications in the large layout by default.

### Asynchronous promises

Use `Toast.promise` to automatically track pending, success, and error outcomes of an asynchronous task:

```tsx
Toast.promise(deployProject(), {
  loading: 'Deploying project...',
  success: 'Deployment live!',
  error: (err) => `Deploy failed: ${String(err)}`,
})
```

### In-place updates and programmatic dismissal

Update an existing toast in place using its returned identifier, or close toasts programmatically:

```tsx
const id = Toast.loading({ title: 'Exporting report...' })

// Update the toast when the task finishes
Toast.update(id, { title: 'Report ready', variants: { variant: 'success' }, duration: 4000 })

// Close a specific toast or dismiss all active toasts
Toast.close(id)
Toast.close()
```

### Preventing duplicate toasts

Enable `preventDuplicate` on the `<Toast />` host or pass it directly in toast options to keep rapid clicks from flooding the viewport:

```tsx
Toast.info({
  title: 'Link copied to clipboard',
  preventDuplicate: true,
})
```

### Custom rendering

Render arbitrary Solid JSX using `Toast.custom`:

```tsx
Toast.custom((id) => (
  <div class="p-3 bg-background border rounded-lg shadow-overlay flex items-center justify-between gap-4">
    <span class="text-sm">Maintenance scheduled in 10 minutes</span>
    <Button size="sm" variant="ghost" onClick={() => Toast.close(id)}>
      Dismiss
    </Button>
  </div>
))
```
