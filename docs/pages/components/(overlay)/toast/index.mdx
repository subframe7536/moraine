## Usage

Mount `<Toast />` once at your application root or inside a layout, then trigger toasts anywhere
in your app using static methods on `Toast`.

```tsx
import { Button, Toast } from 'moraine'

export default function App() {
  return (
    <>
      <Button onClick={() => Toast.success({ title: 'Changes saved!' })}>Save</Button>
      <Toast />
    </>
  )
}
```

### Semantic methods

Call dedicated tone methods for direct feedback, or use `Toast.add` for the default tone:

```tsx
Toast.add({ title: 'Default message' })
Toast.success({ title: 'File uploaded successfully' })
Toast.error({ title: 'Network request failed' })
Toast.warning({ title: 'Storage is almost full' })
Toast.info({ title: 'New release available' })
```

### Action and cancel buttons

Pass `action` or `cancel` configurations to prompt for immediate user interaction:

```tsx
Toast.add({
  title: 'Message archived',
  action: {
    label: 'Undo',
    onClick: () => restoreMessage(),
  },
})
```

### Promises

Bind asynchronous tasks to pending, success, and error outcomes with `Toast.promise`:

```tsx
Toast.promise(saveSettings(), {
  loading: 'Saving profile...',
  success: 'Profile updated successfully',
  error: (err) => `Failed to save: ${String(err)}`,
})
```

### Custom rendering

Render arbitrary Solid JSX using `Toast.custom`:

```tsx
Toast.custom((id) => (
  <div class="p-4 bg-background border rounded-lg shadow-overlay flex items-center gap-3">
    <span>Custom banner notification</span>
    <Button size="sm" variant="ghost" onClick={() => Toast.close(id)}>
      Dismiss
    </Button>
  </div>
))
```

### Updates and closing

Update an existing toast in place using `Toast.update`, or close programmatically using `Toast.close`:

```tsx
const id = Toast.loading({ title: 'Uploading files...' })

// Update title and visual variant in place
Toast.update(id, { title: 'Upload complete', variant: 'success' })

// Close specific toast or close all toasts
Toast.close(id)
Toast.close()
```

### Accessibility and navigation

The toast container is rendered as an accessible notification region (`role="region"`) with a
persistent polite live region. Dismiss individual toasts with the close button, action/cancel
controls, swipe gestures, or `Toast.close`.
