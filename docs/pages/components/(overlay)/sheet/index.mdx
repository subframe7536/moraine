import { Button, Input, Sheet } from '@src'

Use Sheet for a focused drawer from a viewport edge, such as mobile navigation or an inspector. It shares modal dismissal and focus behavior with its overlay family.

## Basic usage

```tsx
import { Button, Sheet } from 'moraine'

export function Example() {
  return (
    <Sheet>
      <Sheet.Trigger as={Button}>Open</Sheet.Trigger>
      <Sheet.Content title="Details">
        <Sheet.Body>Sheet content</Sheet.Body>
        <Sheet.Footer>
          <Sheet.Close as={Button}>Done</Sheet.Close>
        </Sheet.Footer>
      </Sheet.Content>
    </Sheet>
  )
}
```

## Usage

### Content composition

Use Content `title` and `description` for simple cases:

```tsx
<Sheet>
  <Sheet.Content title="Settings" description="Update your account.">
    <Sheet.Body>...</Sheet.Body>
    <Sheet.Footer>...</Sheet.Footer>
  </Sheet.Content>
</Sheet>
```

For a custom header layout, compose the anatomy parts:

```tsx
<Sheet.Content>
  <Sheet.Header>
    <Sheet.Title>Settings</Sheet.Title>
    <Sheet.Description>Update your account.</Sheet.Description>
    <Sheet.Action>...</Sheet.Action>
  </Sheet.Header>
  <Sheet.Body>...</Sheet.Body>
  <Sheet.Footer>...</Sheet.Footer>
</Sheet.Content>
```

Explicit `Sheet.Header` replaces the header generated by Content `title` and `description`. `Sheet.Title` and `Sheet.Description` register their actual IDs for the surface's ARIA relationships. Without a title, supply root `ariaLabel` or native ARIA attributes on Content. Configure the overlay, side, inset layout, transition, modal focus and accessibility behavior, and automatic close button on the root. `modal` controls focus containment, initial and restored focus, ARIA isolation, and prevention of native outside pointer actions. With `modal={false}`, outside pointer interactions and Escape still request dismissal according to `dismissible`. `preventScroll` defaults to `true` independently, and the default overlay still intercepts pointer input unless `overlay={false}`. `Sheet.Action` is the header-side action region; `contentClose` is the automatic corner close rendered by Content. `Sheet.Close` is a separate close control you can place anywhere inside the root.

Use root `close={false}` to hide the automatic close button, or `closeIcon` to change its icon. Root `portalMount` places Content in a chosen container when there is no Trigger, or overrides the Trigger's document body.

Set `class` or `style` directly on each part. Root `classes` and `styles` provide family-wide slot defaults; Content `classes` and `styles` configure only `overlay`, `content`, and `contentClose`. See [Styling](/docs/customization#style-overrides).

### Structured drawer

Set root `side` to choose the viewport edge, then compose title, description, body, and footer through the provided regions. Sheet is the structured alternative to manually composing a Modal surface.

### State and dismissal

Use controlled open state when a layout owns visibility. Disable normal dismissal only when the sheet has a clear explicit close action; `onClosePrevent` receives blocked outside or Escape attempts.

<Preview path="./state-usage" />

### Keyboard interaction

| Key                    | Description                                                  |
| ---------------------- | ------------------------------------------------------------ |
| <kbd>Escape</kbd>      | Dismisses the open sheet and returns focus to the trigger.   |
| <kbd>Tab</kbd>         | Cycles forward through focusable elements inside the sheet.  |
| <kbd>Shift + Tab</kbd> | Cycles backward through focusable elements inside the sheet. |
