import { Button, Input, Popover } from '@src'

Use Popover for anchored interactive content that does not need the structure of a full dialog. Use [Tooltip](/components/tooltip) for brief, non-interactive hints.

## Basic usage

```tsx
import { Button, Popover } from 'moraine'

export function Example() {
  return (
    <Popover>
      <Popover.Trigger as={Button}>Details</Popover.Trigger>
      <Popover.Content>More information</Popover.Content>
    </Popover>
  )
}
```

## Usage

### Trigger modes and state

Render the trigger with the supplied props. Click mode is the default; hover mode also responds to focus and blur and can use open and close delays. Use controlled `open` state only when the application needs to coordinate visibility.

<Preview path="./trigger-modes" />

### Dismissal and accessibility

Escape and outside interaction close a dismissible popover. When a popover has no visible label, provide `ariaLabel`. `modal` defaults to `false`; when enabled with a composed `Popover.Close`, it contains focus, hides outside content from assistive technology, prevents the native default action of outside pointer events, and locks body scroll. Without a composed Close, it stays non-modal so assistive-technology users retain a dismissal route. `modal={false}` does not disable outside or Escape dismissal; use `dismissible` for that. `preventScroll` can lock body scroll independently of `modal`.

<Preview path="./dismissal-usage" />

### Keyboard interaction

Keyboard behavior depends on the trigger element and Popper mode. Escape requests dismissal when the popover is dismissible; focusable controls inside non-modal content participate in normal document focus order. Modal content contains focus.
