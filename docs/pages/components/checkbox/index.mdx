## Usage

Use Checkbox for an independent boolean or mapped choice that can be selected alongside other
choices. Use [Switch](/components/switch) when the control represents an immediate on/off setting.
Use [CheckboxGroup](/components/checkbox-group) when several choices submit as one array.

```tsx
import { Checkbox } from 'moraine'

export function Example() {
  return <Checkbox label="Accept terms" />
}
```

### State and forms

Use `checked` with `onCheckedChange` for controlled state, or `defaultChecked` for an initial value.
Pass `checked="indeterminate"` from aggregate selection state; it shows the mixed presentation
without adding a third submitted value.

`trueValue` and `falseValue` map the checked state to domain values. `onCheckedChange` receives them,
and a bound `form.Field` stores them. Native form submission uses `value` while checked. Without
`value`, it submits a string or number `trueValue`, or `'on'` otherwise. An unchecked or
indeterminate checkbox contributes no entry. `onCheckedChange` fires only for user toggles, never
while `disabled` or `readOnly`, and toggling from `'indeterminate'` checks the box.

```tsx
<Checkbox
  checked={checked()}
  onCheckedChange={setChecked}
  label="Subscribe to product updates"
/>
<Checkbox trueValue="opted-in" falseValue="opted-out" label="Anonymous telemetry" />
```

### Layout

`label` and `description` render beside the control and link to it for assistive technology. Set
`variant="card"` to draw a bordered card whose whole surface toggles the checkbox, except for
interactive content inside it. `indicatorPosition` places the control at the `leading` (default) or
`trailing` edge, or hides it visually with `hidden`. `size` accepts `sm`, `md` (default), or `lg`.

```tsx
<Checkbox
  variant="card"
  indicatorPosition="trailing"
  label="Email alerts"
  description="Get a message when a build fails."
/>
```

### Read-only and disabled

`disabled` removes the control from normal interaction and native form submission. `readOnly`
preserves the value and focusability while preventing changes.

```tsx
<Checkbox disabled defaultChecked label="Disabled" />
<Checkbox readOnly defaultChecked label="Read-only" />
```
