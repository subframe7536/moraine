## Usage

Use Empty when a collection or search result is genuinely empty and the next action should be
visible. It does not inspect data; the page decides when to render it. Use
[Skeleton](/components/skeleton) while content is still loading.

```tsx
import { Empty } from 'moraine'

export function Example() {
  return (
    <Empty>
      <Empty.Title>No projects yet</Empty.Title>
      <Empty.Description>Create a project to organize your work.</Empty.Description>
    </Empty>
  )
}
```

### Parts

Compose only the parts you need. All parts belong inside `Empty`. `Media` accepts arbitrary JSX,
including Icon, Avatar, AvatarGroup, and images; it does not impose a fixed media size or background.

The root and its parts render a `div` by default, except `Empty.Description`, which renders a `p`.
Every part accepts `as`. Set a heading such as `as="h2"` on `Empty.Title` when the surrounding page
needs one. Empty adds no role or ARIA relationships automatically.

```tsx
<Empty>
  <Empty.Media>
    <Icon name="i-lucide:inbox" />
  </Empty.Media>
  <Empty.Title as="h2">Inbox is empty</Empty.Title>
  <Empty.Actions>
    <Button>New message</Button>
  </Empty.Actions>
</Empty>
```

### Sizes

The `sm`, `md` (default), and `lg` sizes change padding, spacing, typography, and action gaps
together. Use `sm` within a Card or table, `md` for ordinary content, and `lg` for a page-level
empty state. Set `size` on `Empty`; the parts inherit it. Vertical padding is larger than horizontal
padding, and media and actions get extra space around them. Size does not resize the content placed
inside `Media`.

```tsx
<Empty size="sm">
  <Empty.Title>No rows</Empty.Title>
</Empty>
```

`class` and `style`. A part's own `class` and `style` take precedence over the root `classes` and
