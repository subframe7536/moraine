## Usage

Use BoldSlider for dense settings such as inspector panels and animation controls, where each row
holds one number and the track doubles as its readout. Use [Slider](/components/slider) for
ranges, vertical layouts, or a thin track with a visible thumb.

```tsx
import { BoldSlider } from 'moraine'

export function Example() {
  return <BoldSlider label="Opacity" defaultValue={80} formatValue={(value) => `${value}%`} />
}
```

BoldSlider is built on Slider, so `value`, `defaultValue`, `min`, `max`, `step`, `marker`,
`inverted`, form props, keyboard interaction, and `translations` behave the same way.

### Label and value

`label` is drawn at the start of the track and is also the default `aria-label`. The value is
drawn at the end; set `showValue={false}` to hide it. By default the value is rounded to the
decimal places of `step`. Pass `formatValue` to add units or other formatting.

Both texts are drawn twice: once over the track and once clipped to the filled range. Each part of
the text uses the colors of the surface behind it, so it stays readable while the fill passes
through it.

### Subtle fill

Set `subtle` for a solid neutral fill instead of the primary color, like the controls in an
inspector panel. The label, value, and indicator then keep the same colors over the fill and the
track.

```tsx
<BoldSlider subtle label="Bounce" defaultValue={0.5} max={1} step={0.1} />
```

### Step and markers

Set `step` to snap pointer and keyboard input to increments. Without `step`, pointer movement is
continuous. Enable `marker` to draw a tick at each step. Ticks use `muted-foreground`, so they stay
visible in light and dark themes.

### Indicator

The indicator is a capsule just inside the edge of the fill. Its slot is a box clipped to the
fill, so the capsule always sits on the fill and slides out of view near the minimum. It stays dim
and shorter at rest, and brightens to full size while the track is hovered, the slider is dragged,
or the thumb has keyboard focus. Set the capsule color with a text color on the `indicator` slot.

These states use `peer-*` selectors on the track and thumb, so each slider reacts only to its own
interaction, even inside a parent with a `group` class.
