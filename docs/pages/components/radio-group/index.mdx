## Usage

Use RadioGroup for one choice from a small visible set. For a longer or space-constrained
collection, use [Select](/components/select). Use [CheckboxGroup](/components/checkbox-group) when
several options may be selected together.

```tsx
import { Field, RadioGroup } from 'moraine'

export function Example() {
  return (
    <Field label="Visibility">
      <RadioGroup
        items={[
          { value: 'public', label: 'Public' },
          { value: 'private', label: 'Private' },
        ]}
      />
    </Field>
  )
}
```

### Single selection

`items` takes strings (used as both `value` and `label`) or objects with `value`, `label`,
`description`, and `disabled`. The selected item is one string: use `defaultValue` for uncontrolled
state, or pair `value` with `onValueChange` for controlled state. `onValueChange` fires only when the
user selects a different item. Disabled items stay visible but cannot be selected or focused.
`variant` sets the layout (`list`, `card`, or `table`), and `orientation` sets the direction.

```tsx
<RadioGroup items={planOptions} value={plan()} onValueChange={setPlan} />
```

### Keyboard interaction

The group is one tab stop. The arrow keys that match `orientation` move focus to the next enabled
item and select it. `Home`, `End`, and `Shift` with an arrow key move focus without selecting.
`Space` selects the focused item. Navigation wraps unless `loop={false}`.

### Forms

Set `name` for native form submission. For schema binding and validation, place the group inside
`form.Field` from [createForm](/components/form). Standalone [Field](/components/field) supplies
labels and messages without binding a form store.

```tsx
<RadioGroup name="environment" items={envOptions} defaultValue="staging" />
```

### Indicator

`indicatorPosition` places the radio mark at the `leading` or `trailing` edge, or hides it with
`hidden`.

```tsx
<RadioGroup indicatorPosition="trailing" items={items} />
<RadioGroup indicatorPosition="hidden" items={items} />
```
