## Usage

Use HoverCard to preview the destination of a link on hover or keyboard focus. The trigger
defaults to an anchor element, so compose it directly inside prose. Use
[Tooltip](/components/tooltip) for a brief, non-interactive hint and
[Popover](/components/popover) for content the user must reach and operate.

```tsx
import { HoverCard } from 'moraine'

export function Example() {
  return (
    <HoverCard>
      <HoverCard.Trigger href="/u/alex.morgan">@alex.morgan</HoverCard.Trigger>
      <HoverCard.Content>Author profile preview</HoverCard.Content>
    </HoverCard>
  )
}
```

### Delays and anchoring

`openDelay` (default 600 ms) keeps the card from opening on a passing pointer, and `closeDelay`
(default 300 ms) keeps it open while the pointer travels from the trigger into the content. The
card anchors to the line the pointer entered, so it stays attached when the trigger wraps across
multiple lines. `placement` defaults to `'bottom'`, and `gutter` defaults to 4 px.

```tsx
<HoverCard openDelay={200} closeDelay={100} placement="top" align="start">
  <HoverCard.Trigger href="/releases/v2">v2 release notes</HoverCard.Trigger>
  <HoverCard.Content>Ships December 15.</HoverCard.Content>
</HoverCard>
```

### Dismissal and accessibility

Escape and a pointer press outside close the card; hover or keyboard focus reopens it. Control the
open state with `open` and `onOpenChange`, or start open with `defaultOpen`. `disabled` keeps the
card closed. `forceMount` keeps the content in the DOM while closed.

Hover card content is supplementary: keyboard users cannot reach it and screen readers do not
announce it, so it must never be the only place the information lives. Make the same content
available at the link destination.

```tsx
<HoverCard>
  <HoverCard.Trigger href="/u/alex.morgan">@alex.morgan</HoverCard.Trigger>
  <HoverCard.Content>Profile summary also shown on the author page.</HoverCard.Content>
</HoverCard>
```

### Keyboard interaction

Moving keyboard focus to the trigger opens the card after `openDelay`, and blurring the trigger
closes it after `closeDelay`. Only keyboard (focus-visible) focus opens the card, and touch hover
is ignored. The card itself is not keyboard reachable; keep interactive content in a
[Popover](/components/popover) instead.
