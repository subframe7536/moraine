## Usage

Use CheckboxGroup for several choices submitted as one array. Use individual
[Checkbox](/components/checkbox) controls when the fields are independent. Use
[RadioGroup](/components/radio-group) when only one option may be selected.

```tsx
import { CheckboxGroup } from 'moraine'

export function Example() {
  return (
    <CheckboxGroup
      aria-label="Preferences"
      items={[
        { value: 'email', label: 'Email' },
        { value: 'sms', label: 'SMS' },
      ]}
    />
  )
}
```

### Selection model

The group value is an array of item values. Pair `value` with `onValueChange` for controlled
selection, or set `defaultValue` when the group owns its initial state. `onValueChange` receives the
complete next array and fires only for user toggles.

A disabled group disables all items; an item can also be disabled independently. `items` accepts
objects with `value`, `label`, `description`, `disabled`, `indeterminate`, `checkedIcon`, and
`indeterminateIcon`, or a string shorthand whose `value` and `label` are that string. Item `value`
is required and must be unique within the group.

```tsx
<CheckboxGroup
  legend="Notification preferences"
  items={options}
  value={selected()}
  onValueChange={setSelected}
/>
<CheckboxGroup legend="Toppings" items={['cheese', 'olives']} />
```

### Forms

Give the group a `name` for native form submission, or place it inside `form.Field` from
[createForm](/components/form) for schema binding. Standalone [Field](/components/field) supplies
labels and messages without validation.

With `required`, the group is valid when at least one enabled item is selected. Each checkbox keeps
its own tab stop; the group does not use radio-style arrow navigation.

```tsx
<CheckboxGroup name="permissions" items={roleOptions} defaultValue={['read']} />
```

### Layout and indicator

`variant` is `list` (default), `card`, or `table`. `card` draws each item as a bordered card that
toggles when clicked, and `table` joins bordered cards into one connected block. `orientation`
(`vertical` by default, or `horizontal`) sets the layout direction, and `size` accepts `sm`, `md`
(default), or `lg`.

`indicatorPosition` places each item's checkbox control at the `leading` (default) or `trailing`
edge, or hides it visually with `hidden`.

```tsx
<CheckboxGroup indicatorPosition="trailing" items={items} />
<CheckboxGroup indicatorPosition="hidden" items={items} />
```
