## Usage

Use Popover for anchored interactive content that does not need a labeled modal surface. Use
[Tooltip](/components/tooltip) for a brief, non-interactive hint. Use
[DropdownMenu](/components/dropdown-menu) for a compact action list from a visible trigger. Use
[Dialog](/components/dialog) or [Sheet](/components/sheet) when the task should take over the
page. Use [BaseDialog](/components/base-dialog) to compose backdrop and content yourself.

```tsx
import { Button, Popover } from 'moraine'

export function Example() {
  return (
    <Popover>
      <Popover.Trigger as={Button}>Details</Popover.Trigger>
      <Popover.Content>More information</Popover.Content>
    </Popover>
  )
}
```

### Trigger modes and state

Click toggles the popover by default. `openOnHover` opens it when a mouse pointer enters the
trigger or the trigger receives keyboard focus, and closes it `closeDelay` ms after the pointer or
focus leaves the trigger and content (`openDelay` and `closeDelay` default to `100`). With
`openOnHover`, clicking the trigger only opens the popover, touch hover is ignored, outside focus
no longer dismisses the content, and focus is not restored to the trigger on close unless
`finalFocus` is set. Use controlled `open` state when the application coordinates
visibility.

```tsx
<Popover>
  <Popover.Trigger as={Button}>Filter</Popover.Trigger>
  <Popover.Content>Click stays open while you choose filters.</Popover.Content>
</Popover>
<Popover openOnHover openDelay={150} closeDelay={100}>
  <Popover.Trigger as={Button}>Profile</Popover.Trigger>
  <Popover.Content>Hover or focus to preview.</Popover.Content>
</Popover>
```

### Placement

`placement` chooses the side of the trigger (`top`, `right`, `bottom`, or `left`; default
`bottom`), and `align` lines the content up with the trigger edge (`start`, `center`, or `end`;
default `center`). `gutter` sets the gap to the trigger in pixels, and `overflowPadding` the
minimum distance from the viewport edge (both default to `4`). By default, the content moves to
another side when `placement` does not fit (`flip`; `false` keeps the side fixed) and slides along
the trigger edge to stay in the viewport (`slide`). Read the rendered side from `data-side` on the
content.

```tsx
<Popover placement="right" align="start" gutter={8}>
  <Popover.Trigger as={Button}>Details</Popover.Trigger>
  <Popover.Content>Opens to the right of the trigger.</Popover.Content>
</Popover>
```

### Dismissal and accessibility

Escape and outside interaction close a popover. Closing restores focus to the trigger, except after
an outside press or focus move, where focus has already gone elsewhere. Give `Popover.Content` an
accessible name with `aria-label` when it has no visible label.

`modal` defaults to `false`. With `modal={true}` and a composed `Popover.Close`, focus stays inside
the content, outside content is hidden from assistive technology, and body scroll is locked.
Without a Close, the popover stays non-modal so users retain a dismissal route, and development
builds log a warning.

`modal={false}` does not disable Escape or outside dismissal; `closeOnEscape` and
`closeOnOutsideClick` control them independently. `preventScroll` can lock body scroll
independently of `modal`.

```tsx
<Popover>
  <Popover.Trigger as={Button}>Filter</Popover.Trigger>
  <Popover.Content aria-label="Filter settings">Press Escape or click outside.</Popover.Content>
</Popover>
<Popover closeOnEscape={false} closeOnOutsideClick={false} onClosePrevented={onBlocked}>
  <Popover.Trigger as={Button}>Keep open</Popover.Trigger>
  <Popover.Content>Outside click and Escape are blocked.</Popover.Content>
</Popover>
```

### Keyboard interaction

Keyboard behavior depends on the trigger element and whether the popover is modal. Escape requests
dismissal when `closeOnEscape` allows it; focusable controls inside non-modal content participate
in normal document focus order. Modal content contains focus. With `openOnHover`, Tab from the
last control in the content moves to the next focusable element after the trigger, and
Shift+Tab from the first control returns to the trigger.
