## Usage

Use Popover for anchored interactive content that does not need a labeled modal surface. Use
[Tooltip](/components/tooltip) for a brief, non-interactive hint. Use
[DropdownMenu](/components/dropdown-menu) for a compact action list from a visible trigger. Use
[Dialog](/components/dialog) or [Sheet](/components/sheet) when the task should take over the
page. Use [Modal](/components/modal) to compose backdrop and content yourself.

```tsx
import { Button, Popover } from 'moraine'

export function Example() {
  return (
    <Popover>
      <Popover.Trigger as={Button}>Details</Popover.Trigger>
      <Popover.Content>More information</Popover.Content>
    </Popover>
  )
}
```

### Trigger modes and state

Click mode is the default. Hover mode also opens on focus and closes on blur, and accepts
`openDelay` and `closeDelay`. Use controlled `open` state when the application coordinates
visibility.

```tsx
<Popover>
  <Popover.Trigger as={Button}>Filter</Popover.Trigger>
  <Popover.Content>Click stays open while you choose filters.</Popover.Content>
</Popover>
<Popover mode="hover" openDelay={150} closeDelay={100}>
  <Popover.Trigger as={Button}>Profile</Popover.Trigger>
  <Popover.Content>Hover or focus to preview.</Popover.Content>
</Popover>
```

### Dismissal and accessibility

Escape and outside interaction close a dismissible popover. Give `Popover.Content` an accessible
name with `aria-label` when it has no visible label.

`modal` defaults to `false`. With `modal={true}` and a composed `Popover.Close`, focus stays inside
the content, outside content is hidden from assistive technology, and body scroll is locked.
Without a Close, the popover stays non-modal so users retain a dismissal route.

`modal={false}` does not disable Escape or outside dismissal; use `dismissible` for that.
`preventScroll` can lock body scroll independently of `modal`.

```tsx
<Popover>
  <Popover.Trigger as={Button}>Filter</Popover.Trigger>
  <Popover.Content aria-label="Filter settings">Press Escape or click outside.</Popover.Content>
</Popover>
<Popover dismissible={false} onClosePrevent={onBlocked}>
  <Popover.Trigger as={Button}>Keep open</Popover.Trigger>
  <Popover.Content>Outside click and Escape are blocked.</Popover.Content>
</Popover>
```

### Keyboard interaction

Keyboard behavior depends on the trigger element and whether the popover is modal. Escape requests
dismissal when the popover is dismissible; focusable controls inside non-modal content participate
in normal document focus order. Modal content contains focus.
