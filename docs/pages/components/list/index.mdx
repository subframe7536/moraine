## Usage

Use List when the caller owns each row's markup and needs a stable collection surface. Pass `items`
and an `itemRender` component; List does not take row content through `children`. Add a
`virtualizer` for large collections only when ordinary rendering becomes costly.

```tsx
import { List } from 'moraine'

export function Example() {
  return <List items={['Alpha', 'Beta']} itemRender={(item) => <li>{item.item}</li>} />
}
```

### Rows

- `itemRender`: receives `{ item, index, rowProps }`. When using a `virtualizer`, spread `rowProps` onto the outer row element for positioning and measurement.
- `as`: the root defaults to `<ul>` and always carries `role="list"`, so render list-item semantics in each row or select another root element with `as`. TypeScript infers item and root element types from `items` and `as`.
- `emptyRender`: renders when `items` is empty or `undefined`.

```tsx
<List
  items={rows()}
  emptyRender={<li>No items</li>}
  itemRender={(item) => <li>{item.item.label}</li>}
/>
```

### Virtualization

`createListVirtualizer` is an optional adapter from `moraine/virtualizer` (requires `@tanstack/virtual-core`). The `List` root is the scroll container, so give it a bounded height and `overflow-y-auto`. Row count and scroll behavior follow the estimated or measured row sizes.

```tsx
import { createListVirtualizer } from 'moraine/virtualizer'

const virtualizer = createListVirtualizer<Item>({
  estimateSize: () => 36,
  getItemKey: (item) => item.id,
})

<List
  as="div"
  class="h-80 overflow-y-auto"
  items={items}
  virtualizer={virtualizer}
  itemRender={(context) => (
    <div {...context.rowProps} role="listitem">
      {context.item.label}
    </div>
  )}
/>
```

Read the [Virtualization guide](/docs/virtualization) for setup, row measurements, stable keys, and keyboard navigation.

### Edge loading

`onTopReached` and `onBottomReached` fire once each time scrolling reaches the top or bottom edge of an overflowing list; neither fires for the initial scroll position. Combine `onBottomReached` with `scrollThreshold` to request the next page shortly before the end.

```tsx
<List
  class="h-80 overflow-y-auto"
  items={rows()}
  scrollThreshold={48}
  onBottomReached={loadMore}
  itemRender={(context) => <li>{context.item.label}</li>}
/>
```

### Drag to reorder

`createListSortable` is an optional adapter from `moraine/dnd` (requires `@dnd-kit/dom`). `List` has no drag props; the sortable composes through `itemRender`:

1. Wrap the list in `sortable.Provider`.
2. Call `sortable.useRow(context)` inside `itemRender` and spread `row.props` onto the row element.
3. Update your list state from `onReorder`.

```tsx
import { createListSortable } from 'moraine/dnd'

const sortable = createListSortable({ items, onReorder: (event) => setItems(event.items) })

<sortable.Provider>
  <List
    items={items()}
    itemRender={(context) => {
      const row = sortable.useRow(context)
      return (
        <li {...row.props}>
          <button ref={row.handleRef} aria-label="Reorder">⋮⋮</button>
          {context.item.label}
        </li>
      )
    }}
  />
</sortable.Provider>
```

`row.props` preserves `context.rowProps` and adds the drag ref, `data-dragging`, and `data-drop-position`.

When combining with a `virtualizer`, pass `rangeExtractor: sortable.rangeExtractor` to `createListVirtualizer` so the dragged row stays mounted while scrolled out of view. Read the [Drag and drop guide](/docs/drag-and-drop) for handles, keyboard dragging, and options.
