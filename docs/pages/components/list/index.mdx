## Usage

Use List when the caller owns each row's markup and needs a stable collection surface. Pass `items`
and an `itemRender` component; List does not take row content through `children`. Add a virtual
renderer for large collections only when ordinary rendering becomes costly.

```tsx
import { List } from 'moraine'

export function Example() {
  return <List items={['Alpha', 'Beta']} itemRender={(item) => <li>{item.item}</li>} />
}
```

### Row ownership

`itemRender` receives the item, its index, and row props. Apply those props to the final row element
when using `virtualizer`; the virtualizer needs them for positioning and measurement. The default
root is a `<ul>` with `role="list"`, so render list-item semantics in each row or choose a different
root with `as` for another structure. TypeScript infers the item and root element types from `items`
and `as`. `fallback` renders when the collection is empty.

```tsx
<List
  items={rows()}
  fallback={<li>No items</li>}
  itemRender={(item) => <li>{item.item.label}</li>}
/>
```

### Virtualization

`createListVirtualizer` is an optional adapter from `moraine/virtualizer` and needs
`@tanstack/virtual-core`. The visible row count and scroll behavior depend on your estimated or
measured row sizes.

```tsx
import { createListVirtualizer } from 'moraine/virtualizer'

const virtualizer = createListVirtualizer<Item>({
  estimateSize: () => 36,
  getItemKey: (item) => item.id,
})

<List
  as="div"
  items={items}
  virtualizer={virtualizer}
  itemRender={(context) => <div {...context.props}>{context.item.label}</div>}
/>
```

Read the [Virtualization guide](/docs/virtualization) for setup, row measurements, stable keys, and
keyboard navigation.

### Drag to reorder

`createSortable` is an optional adapter from `moraine/dnd` and needs `@dnd-kit/solid`. Pass it to
`sortable` and update `items` from `onReorder`. Spread `context.props` onto the row element, and
pass `context.handleRef` to a grip button to start drags only from that button. Without a handle,
a drag starts anywhere on the row once the pointer moves a few pixels, so clicks still work.

```tsx
import { createSortable } from 'moraine/dnd'

;<List
  items={items()}
  sortable={createSortable()}
  onReorder={(event) => setItems(event.items)}
  itemRender={(context) => (
    <li {...context.props}>
      <button ref={context.handleRef} aria-label="Reorder">
        ⋮⋮
      </button>
      {context.item.label}
    </li>
  )}
/>
```

Rows stay in place while dragging. The row under the pointer gets `data-drop-position="before"` or
`"after"`, and the dragged row gets `data-dragging`; style the drop indicator from those
attributes. `sortable` works together with `virtualizer`: the dragged row stays mounted while it
is scrolled out of view. Read the [Drag and drop guide](/docs/drag-and-drop) for keyboard dragging
and options.
