## Usage

Use List when the caller owns each row's markup and needs a stable collection surface. Pass `items`
and an `itemRender` component; List does not take row content through `children`. Add a virtual
renderer for large collections only when ordinary rendering becomes costly.

```tsx
import { List } from 'moraine'

export function Example() {
  return <List items={['Alpha', 'Beta']} itemRender={(item) => <li>{item.item}</li>} />
}
```

### Row ownership

`itemRender` receives the item, its index, and row props. Apply those props to the final row element
when using `virtualizer`; the virtualizer needs them for positioning and measurement. The default
root is a `<ul>` with `role="list"`, so render list-item semantics in each row or choose a different
root with `as` for another structure. TypeScript infers the item and root element types from `items`
and `as`. `fallback` renders when the collection is empty.

```tsx
<List
  items={rows()}
  fallback={<li>No items</li>}
  itemRender={(item) => <li>{item.item.label}</li>}
/>
```

### Virtualization

`createListVirtualizer` is an optional adapter from `moraine/virtualizer` and needs
`@tanstack/virtual-core`. The List root is the scroll container, so give it a bounded height and
`overflow-y-auto`. Row count and scroll behavior follow the estimated or measured row sizes.

```tsx
import { createListVirtualizer } from 'moraine/virtualizer'

const virtualizer = createListVirtualizer<Item>({
  estimateSize: () => 36,
  getItemKey: (item) => item.id,
})

<List
  as="div"
  items={items}
  virtualizer={virtualizer}
  itemRender={(context) => <div {...context.props}>{context.item.label}</div>}
/>
```

Read the [Virtualization guide](/docs/virtualization) for setup, row measurements, stable keys, and
keyboard navigation.

### Drag to reorder

`createListSortable` is an optional adapter from `moraine/dnd` and needs `@dnd-kit/solid`. List has
no drag props; the sortable composes through `itemRender`. Wrap the list in `sortable.Provider`,
call `sortable.useRow(context)` in `itemRender`, and spread `row.props` onto the row element.
Update the items from `onReorder`.

```tsx
import { createListSortable } from 'moraine/dnd'

const sortable = createListSortable({ items, onReorder: (event) => setItems(event.items) })

<sortable.Provider>
  <List
    items={items()}
    itemRender={(context) => {
      const row = sortable.useRow(context)
      return (
        <li {...row.props}>
          <button ref={row.handleRef} aria-label="Reorder">⋮⋮</button>
          {context.item.label}
        </li>
      )
    }}
  />
</sortable.Provider>
```

`row.props` keeps the virtual row props from `context.props` and adds the drag ref,
`data-dragging`, and `data-drop-position`. With a `virtualizer`, also pass
`rangeExtractor: sortable.rangeExtractor` to `createListVirtualizer` so the dragged row stays
mounted while it is scrolled out of view. Read the [Drag and drop guide](/docs/drag-and-drop) for
handles, keyboard dragging, and options.
