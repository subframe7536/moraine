## Usage

Use Switch for an on/off setting whose state is immediately meaningful. For an independent form
choice that may be part of a set, use [Checkbox](/components/checkbox). For a pressed command
button, use [ToggleButton](/components/toggle-button).

```tsx
import { Switch } from 'moraine'

export function Example() {
  return <Switch label="Notifications" />
}
```

### Checked state and forms

The focusable button has `role="switch"`; a hidden checkbox handles native form submission. Use
`checked` with `onCheckedChange` for controlled state, or `defaultChecked` for an initial value.
`onCheckedChange` fires only when the user toggles the switch, not for programmatic `checked`
changes or while the switch is `disabled`, `readOnly`, or `loading`.

`trueValue` and `falseValue` map checked state to domain values for `checked`, callbacks, and
schema-bound forms. Native form submission sends the `value` prop under `name` only while checked;
an unchecked switch contributes no entry. `value` defaults to a string or number `trueValue`,
otherwise `'on'`.

```tsx
<Switch
  checked={enabled()}
  onCheckedChange={setEnabled}
  label="Airplane mode"
/>
<Switch trueValue="enabled" falseValue="disabled" label="Deployment gate" />
```

### Loading

While `loading` is set, the switch is non-interactive and shows `loadingIcon` on the thumb in place
of `checkedIcon` or `uncheckedIcon`. Drive `loading` from the application; the switch does not start
or track the async operation itself.

```tsx
<Switch
  checked={checked()}
  onCheckedChange={handleToggle}
  loading={pending()}
  label="Auto-deploy changes"
/>
```
