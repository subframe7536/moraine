## Usage

Use AvatarGroup to show a small set of people in a bounded space. It truncates the visible stack at
`max`. Keep the full membership available elsewhere when users need every name. For a single person,
use [Avatar](/components/avatar).

```tsx
import { AvatarGroup } from 'moraine'

export function Example() {
  return <AvatarGroup items={[{ src: '/alex.png', alt: 'Alex', text: 'A' }]} />
}
```

### Overflow count

AvatarGroup renders no root for an empty `items` array. Items keep input order in the DOM. Omit `max`
to show every avatar. Set `max` to `0` to show only `+N`. A positive `max` uses its floored count.
The overflow count follows the visible items.

```tsx
<AvatarGroup max={3} items={reviewers} />
<AvatarGroup max={0} items={reviewers} />
```
