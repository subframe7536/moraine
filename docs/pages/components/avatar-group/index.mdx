## Usage

Use AvatarGroup to show a small set of people in a bounded space. It truncates the visible stack at
`maxVisible`. Keep the full membership available elsewhere when users need every name. For a single person,
use [Avatar](/components/avatar).

```tsx
import { AvatarGroup } from 'moraine'

export function Example() {
  return <AvatarGroup items={[{ src: '/alex.png', alt: 'Alex', text: 'A' }]} />
}
```

### Overflow count

Each entry in `items` accepts the [Avatar](/components/avatar) props. The group
`size` (default `md`) overrides an entry's `size`. AvatarGroup renders nothing for an empty `items`
array, and items keep input order in the DOM.

Omit `maxVisible` to show every avatar. A positive `maxVisible` is rounded down. Set `maxVisible` to `0` (or any negative
value) to show only the `+N` count. `N` is the number of hidden items.

```tsx
<AvatarGroup maxVisible={3} items={reviewers} />
<AvatarGroup maxVisible={0} items={reviewers} />
```
