## Usage

Use Progress for measurable task completion or for work whose end is not yet known. Choose a
determinate value only when it represents real progress. For a loading placeholder of content
structure, use [Skeleton](/components/skeleton).

```tsx
import { Progress } from 'moraine'

export function Example() {
  return <Progress value={40} max={100} aria-label="Upload progress" />
}
```

### Progress models

Pass a numeric `value` from `0` to `max` for determinate progress; `max` defaults to `100`, and a
`value` outside the range is clamped. Omit `value` for indeterminate progress, which sets no
`aria-valuenow` and takes its `aria-valuetext` from the `progress.indeterminate` message. Use
`animation` (`carousel`, `reverse`, `swing`, or `elastic`) to change the indeterminate motion.

```tsx
<Progress value={65} aria-label="Uploading design.fig" />
<Progress aria-label="Scanning for malware" />
```

### Label and value

Supply `aria-label` or a labelling relationship when the surrounding context does not name the
operation. `label` fills the label slot, and a string `label` is also the default `aria-label`. An
explicit `aria-label` takes precedence. `valueLabel` shows the percentage in the value slot; pass a
formatter to customize both the displayed text and `aria-valuetext`. Without `valueLabel`,
`aria-valuetext` is still the formatted percentage. Indeterminate progress keeps the label and hides
the value.

```tsx
<Progress value={82} label="Downloading installation bundle" valueLabel aria-label="Download" />
<Progress value={40} valueLabel={({ percent }) => `${percent}% complete`} aria-label="Export" />
```

### Orientation

Progress fills left to right by default. Set `orientation="vertical"` for a bar that fills from the
bottom, for example a battery or level meter. The vertical bar grows to its container height with a
minimum of 9rem.

```tsx
<Progress value={72} orientation="vertical" aria-label="Battery level" />
```

### Number format

`formatOptions` accepts `Intl.NumberFormat` options and formats the displayed value and
`aria-valuetext` with the provider locale. Like [Slider](/components/slider), it formats the raw
`value`, not the completed fraction, so a `percent` style needs a `max` of `1`. Without
`formatOptions`, the text is the completed percentage rounded to two decimals. A `valueLabel`
formatter takes precedence.

```tsx
<Progress value={0.75} max={1} valueLabel formatOptions={{ style: 'percent' }} aria-label="Setup" />
<Progress value={42} valueLabel formatOptions={{ style: 'unit', unit: 'megabyte' }} aria-label="Upload" />
```
