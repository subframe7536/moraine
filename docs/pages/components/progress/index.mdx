## Usage

Use Progress for measurable task completion or for work whose end is not yet known. Choose a
determinate value only when it represents real progress. For a loading placeholder of content
structure, use [Skeleton](/components/skeleton).

```tsx
import { Progress } from 'moraine'

export function Example() {
  return <Progress value={40} max={100} aria-label="Upload progress" />
}
```

### Progress models

Pass a numeric `value` for determinate progress. Omit `value` for indeterminate progress.
`valueLabel` supplies `aria-valuetext` for a determinate value. Indeterminate progress sets
`aria-valuetext` from the `progress.indeterminate` message.

```tsx
<Progress value={65} aria-label="Uploading design.fig" />
<Progress aria-label="Scanning for malware" />
```

### Label and value

Supply `aria-label` or a labelling relationship when the surrounding context does not name the
operation. `label` fills the label slot. `showValue` shows the percentage in the value slot, and
`valueRender` replaces that percentage. Indeterminate progress keeps the label and hides the value.

```tsx
<Progress value={82} label="Downloading installation bundle" showValue aria-label="Download" />
<Progress value={40} valueRender={(ctx) => `${ctx.percent}% complete`} aria-label="Export" />
```
