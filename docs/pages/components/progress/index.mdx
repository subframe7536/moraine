## Usage

Use Progress for measurable task completion or for work whose end is not yet known. Choose a
determinate value only when it represents real progress. For a loading placeholder of content
structure, use [Skeleton](/components/skeleton).

```tsx
import { Progress } from 'moraine'

export function Example() {
  return <Progress value={40} max={100} aria-label="Upload progress" />
}
```

### Progress models

- **Determinate**: pass a numeric `value` from `0` to `max` (default `100`); values outside the range are clamped.
- **Indeterminate**: omit `value` when total progress is unknown. Indeterminate bars omit `aria-valuenow`, set `aria-valuetext` from the `progress.indeterminate` locale message, and support `animation` (`'carousel'`, `'reverse'`, `'swing'`, or `'elastic'`).

```tsx
<Progress value={65} aria-label="Uploading design.fig" />
<Progress aria-label="Scanning for malware" />
```

### Label and value

Supply `aria-label` (or a labelling relationship) when surrounding context does not name the operation:

- `label`: fills the `label` slot. A string `label` also serves as the default `aria-label` unless an explicit `aria-label` is passed.
- `valueLabel`: renders the formatted percentage in the `value` slot (hidden while indeterminate). Pass a function `({ value, max, percent }) => string` to customize both the displayed text and `aria-valuetext`. Without `valueLabel`, `aria-valuetext` still reports the formatted percentage.

```tsx
<Progress value={82} label="Downloading installation bundle" valueLabel aria-label="Download" />
<Progress value={40} valueLabel={({ percent }) => `${percent}% complete`} aria-label="Export" />
```

### Orientation

Progress fills horizontally from left to right by default. Set `orientation="vertical"` for a bar that fills from the bottom (such as a battery or level meter), growing to its container height with a `9rem` minimum.

```tsx
<Progress value={72} orientation="vertical" aria-label="Battery level" />
```

### Number format

`formatOptions` accepts `Intl.NumberFormat` options and formats both the displayed value and `aria-valuetext` using the provider locale:

- Without `formatOptions`, the text defaults to the completed percentage rounded to two decimal places.
- With `formatOptions`, it formats the raw `value` (like [Slider](/components/slider)) rather than the completed fraction, so `{ style: 'percent' }` expects `max={1}`.
- A custom `valueLabel` formatter function takes precedence over `formatOptions`.

```tsx
<Progress value={0.75} max={1} valueLabel formatOptions={{ style: 'percent' }} aria-label="Setup" />
<Progress value={42} valueLabel formatOptions={{ style: 'unit', unit: 'megabyte' }} aria-label="Upload" />
```
