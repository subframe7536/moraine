## Usage

Use Button for commands and explicit navigation. Render a native button for an action on this page.
Use `as="a"` with `href` for a destination. Use [ToggleButton](/components/toggle-button) when the
control stays pressed.

```tsx
import { Button } from 'moraine'

export function Example() {
  return <Button>Save</Button>
}
```

### Variant, tone, and size

`variant` selects the surface: `solid` (default), `soft`, `outline`, `ghost`, or `link`. `tone` sets
the color. It defaults to `primary` and accepts the shared tones such as `neutral`, `danger`, and
`success`. `size` runs from `xs` to `xl` (default `md`). Inside a
[ButtonGroup](/components/button-group), a button inherits the group's `size`, `variant`, and `tone`
unless it sets its own.

```tsx
<Button variant="outline" tone="danger" size="sm">
  Delete
</Button>
```

### Press motion

`pressEffect` controls the press motion. The default `move-down` shifts the button down by one pixel.
`zoom-in` scales it down slightly. Both skip the motion when the button has `aria-haspopup`, so overlay
triggers stay still. Use `none` to disable the motion, or pass a function that receives the rendered
element and returns a class string.

```tsx
<Button pressEffect="zoom-in">Compress</Button>
<Button pressEffect="none">Static</Button>
```

### Loading

Use `loading` when application state owns the pending operation. `autoLoading` is opt-in: when
`onClick` returns a promise, the button loads until the promise settles. A handler that calls
`event.preventDefault()` does not start loading. While loading, the button sets `aria-busy` and
ignores clicks and keyboard activation, but does not apply native `disabled`, so a focused button
keeps its keyboard position. An explicit `disabled` still uses native disabled semantics where
available.

The loading icon replaces `leading`, or `trailing` when only `trailing` is set. With no icons, it is
added before the label. Set `loadingIcon` to change it. `children` can also be a function that
receives `{ loading }`. Declare its parameter even when unused.

```tsx
<Button loading={saving()}>Save</Button>
<Button autoLoading onClick={() => submit()}>
  {(state) => (state.loading ? 'Saving...' : 'Save')}
</Button>
```

### Icons and polymorphism

`leading` and `trailing` accept icon names, elements, or components. Icon-only buttons use the square
sizes `icon-xs` to `icon-xl` and need an `aria-label` or another accessible name. Polymorphic roots without native link semantics receive the
button role and keyboard activation; anchors with `href` keep native link behavior. When `disabled`
is set on such a root, it gets `aria-disabled` and leaves the tab order. When a custom component
forwards its root ref, Moraine resolves native button semantics from the rendered DOM element.

```tsx
<Button leading="i-lucide:plus">Create</Button>
<Button as="a" href="/docs" trailing="i-lucide:arrow-right">
  Docs
</Button>
<Button size="icon-sm" aria-label="Settings" leading="i-lucide:settings" />
```
