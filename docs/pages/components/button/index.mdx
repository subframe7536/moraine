## Usage

Use Button for commands and explicit navigation. Render a native button for an action on this page.
Use `as="a"` with `href` for a destination. Use [ToggleButton](/components/toggle-button) when the
control stays pressed.

```tsx
import { Button } from 'moraine'

export function Example() {
  return <Button>Save</Button>
}
```

### Press motion

`activeEffect` controls the press motion. The default `move-down` shifts the button down by one pixel.
`zoom-in` scales it down slightly. Both skip the motion when the button has `aria-haspopup`, so overlay
triggers stay still. Use `none` to disable the motion, or pass a function that returns a class string
from the rendered element.

```tsx
<Button activeEffect="zoom-in">Compress</Button>
<Button activeEffect="none">Static</Button>
```

### Loading

Use `loading` when application state owns the pending operation. `loadingAuto` is opt-in: a promise
returned by `onClick` drives the visual loading state. Loading suppresses additional activation
without applying native `disabled`, so a focused button keeps its keyboard position. Explicit
`disabled` still uses native disabled semantics where available.

```tsx
<Button loading={saving()}>Save</Button>
<Button loadingAuto onClick={() => submit()}>
  Save
</Button>
```

### Icons and polymorphism

Leading and trailing content can be icons or custom elements. Icon-only buttons need `aria-label` or
another accessible name. Polymorphic roots without native link semantics receive button role and
keyboard activation; anchors with `href` keep native link behavior. When a custom component forwards
its root ref, Moraine resolves native button semantics from the rendered DOM element.

```tsx
<Button leading="i-lucide:plus">Create</Button>
<Button as="a" href="/docs" trailing="i-lucide:arrow-right">
  Docs
</Button>
<Button size="icon-sm" aria-label="Settings" leading="i-lucide:settings" />
```

### Icon sizes

Icon-only buttons support dedicated square sizes from `icon-xs` to `icon-xl`.

```tsx
<Button size="icon-md" aria-label="Search" leading="i-lucide:search" />
```
