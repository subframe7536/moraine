## Usage

Use Separator to divide related regions with a visible line. Choose its orientation to match the
layout boundary. For a divider inside [ButtonGroup](/components/button-group), use
`ButtonGroup.Separator` so orientation follows the group.

```tsx
import { Separator } from 'moraine'

export function Example() {
  return <Separator />
}
```

### Semantic orientation

Every `Separator` sets `role="separator"`, `aria-orientation`, and `data-orientation`. The default
orientation is `horizontal`, a full-width line. Use `vertical` between items in a row; it draws a
full-height line, so give the row a height.

```tsx
<Separator />
<Separator orientation="vertical" />
```

### Root styling

`Separator` has one `<div>` root. Use `class` and `style` for a local override, or configure
`separator.base.root` in your Theme for application defaults. `root` is the only slot, so `classes`
and `styles` only duplicate `class` and `style`.

```tsx
<Separator class="bg-blue-500" style={{ height: '3px' }} />
```
