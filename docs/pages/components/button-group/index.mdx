The group owns its separators; the caller supplies the child Buttons and their content.

## Usage

Use ButtonGroup when adjacent actions should read as one control set. Each child remains its own
interactive control; the group supplies layout and shared presentation. Use
[ToggleButton](/components/toggle-button) inside the group for independently pressed actions. ButtonGroup
does not coordinate selection or add toolbar keyboard navigation.

```tsx
import { Button, ButtonGroup } from 'moraine'

export function Example() {
  return (
    <ButtonGroup>
      <Button>Copy</Button>
      <Button variant="outline">Share</Button>
    </ButtonGroup>
  )
}
```

### Composition

Root `variant`, `tone`, `size`, and `orientation` set defaults for every child Button. A child can
override any of them. Compose a menu or popover trigger as a child when an action needs an overlay.

```tsx
<ButtonGroup variant="outline" size="sm" aria-label="Document actions">
  <Button>Copy link</Button>
  <Button>Duplicate</Button>
  <Button>Archive</Button>
</ButtonGroup>
```

### Separator

Insert `ButtonGroup.Separator` only where an explicit boundary is useful. Its orientation is
perpendicular to the group axis: vertical in a horizontal group and horizontal in a vertical group.
An explicit `orientation` on the separator overrides that default.

```tsx
<ButtonGroup aria-label="Clipboard actions">
  <Button>Copy</Button>
  <ButtonGroup.Separator />
  <Button>Paste</Button>
</ButtonGroup>
```
