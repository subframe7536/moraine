The group owns its separators; the caller supplies the child Buttons and their content.

## Usage

Use ButtonGroup when adjacent actions should read as one control set. Each child remains its own
interactive control; the group supplies layout and shared presentation. Use
[ToggleButton](/components/toggle-button) inside the group for independently pressed actions.
ButtonGroup does not coordinate selection or add toolbar keyboard navigation.

```tsx
import { Button, ButtonGroup } from 'moraine'

export function Example() {
  return (
    <ButtonGroup>
      <Button>Copy</Button>
      <Button variant="outline">Share</Button>
    </ButtonGroup>
  )
}
```

### Composition

Root `size` (`sm`, `md`, `lg`; default `md`), `variant` (default `solid`), and `tone` (default
`primary`) set defaults for every descendant Button. A Button can override any of them. `orientation`
(`horizontal` by default, or `vertical`) sets the layout direction. Compose a menu or popover trigger
as a child when an action needs an overlay.

The root renders a `div` with `role="group"`, so give it an `aria-label`. Set `role="toolbar"` only
if you also provide the toolbar keyboard behavior.

```tsx
<ButtonGroup variant="outline" size="sm" aria-label="Document actions">
  <Button>Copy link</Button>
  <Button>Duplicate</Button>
  <Button>Archive</Button>
</ButtonGroup>
```

### Separator

Insert `ButtonGroup.Separator` only where an explicit boundary is useful. Its orientation is
perpendicular to the group axis: vertical in a horizontal group and horizontal in a vertical group.
It renders a `div` with `role="separator"`.

```tsx
<ButtonGroup aria-label="Clipboard actions">
  <Button>Copy</Button>
  <ButtonGroup.Separator />
  <Button>Paste</Button>
</ButtonGroup>
```
