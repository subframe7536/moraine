## Usage

Use KbdGroup to display keys pressed together, such as Ctrl + K. It renders notation only; the
application owns the shortcut listener. For a single keycap, use [Kbd](/components/kbd).

```tsx
import { KbdGroup } from 'moraine'

export function Example() {
  return <KbdGroup items={['Ctrl', 'K']} />
}
```

### Key labels

Each item is a key string, resolved like the `value` of [Kbd](/components/kbd), or an object with
`value`. Known aliases resolve to symbol notation and spoken names. Use an object to set `ariaLabel`
or `symbol` for one key. The group's `size` and `variant` apply to every key.

```tsx
<KbdGroup items={['meta', 's']} />
<KbdGroup items={[{ value: 'meta', ariaLabel: 'Command' }, 'K']} />
```

### Separator

`separator` defaults to `"+"` and accepts a string for inline notation. For custom JSX,
pass a component that receives the `index` of the key it follows; each position mounts its own
instance. It is unrelated to the layout [Separator](/components/separator).

```tsx
<KbdGroup items={['Ctrl', 'Shift', 'K']} separator="/" />
<KbdGroup items={['Ctrl', 'K']} separator={() => <span class="text-muted-foreground">then</span>} />
```
