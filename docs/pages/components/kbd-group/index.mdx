## Usage

Use KbdGroup to display keys pressed together, such as Ctrl + K. It renders notation only; the
application owns the shortcut listener. For a single keycap, use [Kbd](/components/kbd).

```tsx
import { KbdGroup } from 'moraine'

export function Example() {
  return <KbdGroup items={['Ctrl', 'K']} />
}
```

### Key labels

Each item in `items` is either a key string (resolved like the `value` of [Kbd](/components/kbd)) or an object `{ value, ariaLabel?, symbol? }`.

Known aliases resolve to symbol notation and spoken names. The group's `size` and `variant` apply to every key.

```tsx
<KbdGroup items={['meta', 's']} />
<KbdGroup items={[{ value: 'meta', ariaLabel: 'Command' }, 'K']} />
```

### Separator

- **String**: `separator` defaults to `"+"` and renders strings as plain text rather than an icon name.
- **Component**: pass a component receiving `{ index }` (the index of the preceding key) to render custom JSX such as an icon; each position mounts its own instance.

`separator` is inline notation and is unrelated to the layout [Separator](/components/separator).

```tsx
<KbdGroup items={['Ctrl', 'Shift', 'K']} separator="/" />
<KbdGroup items={['Ctrl', 'K']} separator={() => <Icon name="i-lucide:plus" />} />
```
