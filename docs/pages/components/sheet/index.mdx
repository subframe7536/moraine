## Usage

Use Sheet for a focused drawer from a viewport edge, such as mobile navigation or an inspector. Use
[Drawer](/components/drawer) when the surface needs swipe-to-dismiss gestures or snap points. Use
[Dialog](/components/dialog) for a centered labeled task. Use [BaseDialog](/components/base-dialog) to compose
backdrop and content yourself. Use [Popover](/components/popover) for anchored content that should
not take over the page. Use [DropdownMenu](/components/dropdown-menu) for a compact action list.

Sheet shares modal dismissal and focus behavior with Dialog.

```tsx
import { Button, Sheet } from 'moraine'

export function Example() {
  return (
    <Sheet>
      <Sheet.Trigger as={Button}>Open</Sheet.Trigger>
      <Sheet.Content title="Details">
        <Sheet.Body>Sheet content</Sheet.Body>
        <Sheet.Footer>
          <Sheet.Close as={Button}>Done</Sheet.Close>
        </Sheet.Footer>
      </Sheet.Content>
    </Sheet>
  )
}
```

### Content composition

Use Content `title` and `description` for simple cases:

```tsx
<Sheet>
  <Sheet.Content title="Settings" description="Update your account.">
    <Sheet.Body>...</Sheet.Body>
    <Sheet.Footer>...</Sheet.Footer>
  </Sheet.Content>
</Sheet>
```

For a custom header layout, compose the anatomy parts:

```tsx
<Sheet.Content>
  <Sheet.Header>
    <Sheet.Title>Settings</Sheet.Title>
    <Sheet.Description>Update your account.</Sheet.Description>
  </Sheet.Header>
  <Sheet.Body>...</Sheet.Body>
  <Sheet.Footer>...</Sheet.Footer>
</Sheet.Content>
```

An explicit `Sheet.Header` replaces the header generated by Content's `title` and `description`.
`Sheet.Title` and `Sheet.Description` connect their IDs to the surface's accessible name and
description. Without a visible title, set `aria-label` or `aria-labelledby` on Content.

`Sheet.Close` is an explicit close control you can place inside the root; it is separate from
Content's automatic corner close button. Set root `closable={false}` to hide the corner button, or
`closeIcon` to replace its icon. Its accessible label comes from the `close` message; override it
with root `translations`. See [Localization](/docs/localization). Root `transition={false}` turns
off the enter and exit animations, so content and overlay unmount as soon as the sheet closes.

### Focus and dismissal

`modal` defaults to `true`: focus stays inside the surface, outside content is hidden from assistive
technology, and native outside pointer actions are prevented. Closing restores focus to the trigger.
Use `initialFocus` to choose the element that receives focus on open, or `false` to skip the move,
and `finalFocus` to choose where focus returns. Both apply only while `modal` is `true`.

Setting `modal={false}` allows focus to leave the surface, but does not disable Escape or outside
dismissal. `closeOnOutsideClick` and `closeOnEscape` control those close requests. Both default to
`true`. Scroll locking is independent: `preventScroll` defaults to `true`. For interaction with the
background page, also set `preventScroll={false}` and `overlay={false}`.

### Styling and portal

Apply `class` and object `style` directly to each rendered part. Root `classes` and `styles` set
slot defaults for every part: `trigger`, `overlay`, `content`, `header`, `title`, `description`,
`contentClose`, `body`, and `footer`. See
[Customization](/docs/customization#the-4-layer-override-hierarchy) for precedence.

Set root `mount` to place Content in a chosen container. This also works for controlled
surfaces without a Trigger.

### Structured drawer

Choose the viewport edge with root `side` (`top`, `right`, `bottom`, or `left`; default `right`), and set `inset` when the sheet needs space around it.
Compose body and footer regions to keep the task content separate from its actions.

```tsx
<Sheet side="right">
  <Sheet.Trigger as={Button}>Open settings</Sheet.Trigger>
  <Sheet.Content title="Settings" description="Fields in the body, actions in the footer.">
    <Sheet.Body>...</Sheet.Body>
    <Sheet.Footer>
      <Sheet.Close as={Button}>Done</Sheet.Close>
    </Sheet.Footer>
  </Sheet.Content>
</Sheet>
```

### State and dismissal

Use controlled open state when a layout owns visibility. Disable normal dismissal only when the
sheet has a clear explicit close action; `onClosePrevented` receives blocked outside or Escape
attempts.

```tsx
<Sheet open={open()} onOpenChange={setOpen}>
  <Sheet.Content title="Controlled sheet">
    <Sheet.Footer>
      <Button onClick={() => setOpen(false)}>Done</Button>
    </Sheet.Footer>
  </Sheet.Content>
</Sheet>
<Sheet closeOnOutsideClick={false} closeOnEscape={false} onClosePrevented={onBlocked}>
  <Sheet.Content title="Persistent sheet">
    <Sheet.Footer>
      <Button onClick={() => setOpen(false)}>Close</Button>
    </Sheet.Footer>
  </Sheet.Content>
</Sheet>
```

### Keyboard interaction

| Key                    | Description                                             |
| ---------------------- | ------------------------------------------------------- |
| <kbd>Escape</kbd>      | Requests dismissal when `closeOnEscape` is not `false`. |
| <kbd>Tab</kbd>         | Moves focus forward; modal sheets contain focus.        |
| <kbd>Shift + Tab</kbd> | Moves focus backward; modal sheets contain focus.       |
