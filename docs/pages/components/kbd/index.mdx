## Usage

Use Kbd to display one key in a shortcut hint. Combine keys with [KbdGroup](/components/kbd-group).
Showing a shortcut does not register a keyboard handler.

```tsx
import { Kbd } from 'moraine'

export function Example() {
  return <Kbd value="K" />
}
```

### Key aliases

Known aliases such as `meta`, `command`, `shift`, `escape`, and `arrowup` resolve case-insensitively to a symbol or short label (`⌘`, `⇧`, `Esc`, `↑`) and a spoken name from the locale messages. Any other value renders as written.

- `symbol={false}`: renders an alias as written without its spoken name.
- `translations`: overrides the spoken alias names per instance.
- `aria-label`: sets a custom accessible name and takes precedence over the alias name.

```tsx
<Kbd value="meta" />
<Kbd value="escape" symbol={false} />
<Kbd value="K" aria-label="Search" />
```

### Root styling

`Kbd` renders a single `<kbd>` root. Use `variant` (`'default'`, `'outline'`, or `'invert'`) and `size` (`'sm'`, `'md'`, or `'lg'`) for built-in treatments.

Use `class` and `style` for an individual keycap, or configure `kbd.base.root` in your Theme for shared defaults. Because `root` is the only slot, `classes` and `styles` duplicate `class` and `style`.

```tsx
<Kbd value="K" class="text-blue-600" />
```
