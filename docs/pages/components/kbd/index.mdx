## Usage

Use Kbd to display one key in a shortcut hint. Combine keys with [KbdGroup](/components/kbd-group).
Showing a shortcut does not register a keyboard handler.

```tsx
import { Kbd } from 'moraine'

export function Example() {
  return <Kbd value="K" />
}
```

### Key aliases

Known aliases such as `meta`, `command`, `shift`, `escape`, and `arrowup` resolve to a symbol or
short label (`⌘`, `⇧`, `Esc`, `↑`), matched case-insensitively. Any other value renders as written.
Pass `symbol={false}` to render the value as written instead. An alias also gets a spoken name from
the locale messages; `translations` overrides it per instance. Set `ariaLabel` when assistive
technology needs a different name than the visible keycap. It takes precedence over the alias name.

```tsx
<Kbd value="meta" />
<Kbd value="escape" symbol={false} />
<Kbd value="K" ariaLabel="Search" />
```

### Root styling

`Kbd` renders one `<kbd>` root, so use `class` and `style` for an individual keycap. Configure
`kbd.base.root` in your Theme to share keycap presentation. `variant` (`default`, `outline`,
`invert`) and `size` (`sm`, `md`, `lg`) select the built-in treatments. `root` is the only slot, so
`classes` and `styles` only duplicate `class` and `style`.

```tsx
<Kbd value="K" class="text-blue-600" />
```
