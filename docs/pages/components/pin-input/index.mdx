## Usage

Use `PinInput` for verification codes, OTPs, or numeric PINs. It renders one single-character input
per slot.

```tsx
import { PinInput } from 'moraine'

export function Example() {
  return <PinInput length={6} onComplete={(code) => console.log(code)} />
}
```

### Values and completion

`length` sets the number of slots (default `5`). `value` and `defaultValue` accept a joined string
(`'123456'`) or an array with one character per slot, and are filtered by `validationType` and
truncated to `length`. `onValueChange` always receives an array of `length` entries with `''` for
empty slots; use `.join('')` for the string. `onComplete` receives the joined string once every slot
is filled. Set `name` to submit the joined value through a hidden input, and `form` to associate
the control with a `<form>` outside its ancestors. A native form reset restores `defaultValue`.

```tsx
<PinInput length={4} value={code()} onValueChange={(chars) => setCode(chars.join(''))} />
```

### Validation type and mask

`validationType` controls which characters a slot accepts: `'number'` (digits), `'alpha'` (letters),
`'alphanumeric'`, or `'text'` (any non-whitespace character, the default). It also picks the default
`inputMode`; set `inputMode` to override it. Use `mask` to render the slots as password inputs and
conceal the entered characters.

```tsx
<PinInput validationType="number" mask length={4} />
```

### OTP autofill

Use `otp` to set `autocomplete="one-time-code"`, so mobile devices can fill codes from SMS messages.

```tsx
<PinInput otp length={6} />
```

The hidden input, rendered when `name` is set, also accepts pasted or autofilled full codes and
distributes them across the slots.

### Normalization and invalid input

Use `normalizeValue` to transform proposed values after `validationType` filtering, and
`onValueInvalid` to observe refused characters, with a `reason` of
`'patternMismatch'` or `'tooLong'`. `normalizeValue` runs on string
`value` and `defaultValue` and on typed, pasted, or autofilled text; it must be idempotent.

```tsx
<PinInput
  length={6}
  validationType="alphanumeric"
  normalizeValue={(value) => value.toUpperCase()}
  onValueInvalid={({ value, reason }) => console.warn(reason, value)}
/>
```

### Auto-submit

Use `autoSubmit` to call `requestSubmit()` on the owning form right after `onComplete`, which runs
native validation and fires a `submit` event. The form comes from `form`, the inputs, or the closest
ancestor `<form>`; nothing happens without one.

```tsx
<form>
  <PinInput name="code" length={6} autoSubmit />
</form>
```

### Placeholder

Use `placeholder` to show a character hint in empty slots that are not focused:

```tsx
<PinInput length={6} placeholder="○" />
```

### Separators

Use `groupSize` to insert separators between groups of slots. Pass `true` to split the slots in
half, a number for fixed-size groups, or an array of consecutive group sizes. Use `separatorRender`
to replace the default `•` separator.

```tsx
<PinInput length={6} groupSize />
<PinInput length={6} groupSize={3} />
<PinInput length={7} groupSize={[3, 1, 3]} />
```

### Keyboard interaction

| Key                                        | Description                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------------- |
| <kbd>ArrowLeft</kbd>                       | Moves focus to the previous input (in RTL, the next).                           |
| <kbd>ArrowRight</kbd>                      | Moves focus to the next input (in RTL, the previous).                           |
| <kbd>Ctrl/Cmd</kbd> + arrow                | Moves focus to the first input (previous) or the first empty input (next).      |
| <kbd>Home</kbd> / <kbd>ArrowUp</kbd>       | Moves focus to the first input.                                                 |
| <kbd>End</kbd> / <kbd>ArrowDown</kbd>      | Moves focus to the first empty input (the last when all are filled).            |
| <kbd>Backspace</kbd>                       | Clears the focused slot, or the previous slot when it is empty, and moves back. |
| <kbd>Ctrl/Cmd</kbd> + <kbd>Backspace</kbd> | Clears all inputs and moves to the first.                                       |
| <kbd>Delete</kbd>                          | Clears the focused slot.                                                        |

Backspace and Delete have no effect when the control is read-only. Pasted text fills the slots
from the focused one.
