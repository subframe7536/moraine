## Usage

Use Stepper to show progress through a fixed sequence of steps. Decide whether users may jump ahead
before enabling clickable navigation. Use [Tabs](/components/tabs) for peer panels that are not a
sequence. Use [Pagination](/components/pagination) for a result set with a known page count.

```tsx
import { Stepper } from 'moraine'

export function Example() {
  return (
    <Stepper
      items={[
        { value: 'details', title: 'Details' },
        { value: 'review', title: 'Review' },
      ]}
    />
  )
}
```

### Linear and clickable steps

`linear` (default `true`) locks later steps until earlier ones are reached. `clickable` (default
`false`) lets users activate a step from its trigger; `onValueChange` fires only on those trigger
activations. To drive the flow from your own Previous and Next buttons, control `value` and update
it in those handlers.

```tsx
<Stepper items={STEPS} value={step()} onValueChange={setStep} linear clickable />
```

### Panels and orientation

Step labels and panels use tab-like relationships. Put panel JSX on `item.content`. Vertical
orientation changes the layout and the arrow-key directions. Stepper marks every step before the
active one as completed from its index; supply `item.icon` to replace the default step number.

```tsx
<Stepper
  defaultValue="details"
  orientation="vertical"
  items={[
    { value: 'details', title: 'Project details', content: <ProjectForm /> },
    { value: 'target', title: 'Deploy target', content: <TargetForm /> },
  ]}
/>
```

### Keyboard interaction

`activationMode` controls whether keyboard focus selects a step immediately (`automatic`, the default navigation mode) or selection waits for activation (`manual`). Disabled or linear-locked steps are skipped.

| Key                                          | Description                                              |
| -------------------------------------------- | -------------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Moves toward the next enabled step where applicable.     |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Moves toward the previous enabled step where applicable. |
| <kbd>Enter</kbd> / <kbd>Space</kbd>          | Activates the focused step in manual activation mode.    |
