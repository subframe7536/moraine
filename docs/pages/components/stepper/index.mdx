## Usage

Use Stepper to show progress through a fixed sequence of steps. Decide how far users may jump ahead
with `navigation`. Use [Tabs](/components/tabs) for peer panels that are not a
sequence. Use [Pagination](/components/pagination) for a result set with a known page count.

```tsx
import { Stepper } from 'moraine'

export function Example() {
  return (
    <Stepper
      items={[
        { value: 'details', title: 'Details' },
        { value: 'review', title: 'Review' },
      ]}
    />
  )
}
```

### Navigation modes

`navigation` (default `'none'`) controls which steps users can activate from their triggers:

- `none` enables only the active step, so the flow moves through your own controls.
- `linear` enables completed steps and the next step, so later steps stay locked until earlier ones
  are reached.
- `free` enables every enabled step.

`onValueChange` fires only on trigger activations in `linear` and `free`. To drive the flow from
your own Previous and Next buttons, control `value` and update it in those handlers.

```tsx
<Stepper items={STEPS} value={step()} onValueChange={setStep} navigation="linear" />
```

### Panels and orientation

Step labels and panels use tab-like relationships. Every item requires a unique `value`; a later item that repeats an earlier value renders disabled and logs a DEV warning. Pass a
component as `item.content`; Stepper renders it with `{ value, active, completed, index }` only for
the active step. Vertical orientation changes the layout and the arrow-key directions. Stepper marks every step before the
active one as completed from its index; supply `item.icon` to replace the default step number.

```tsx
<Stepper
  defaultValue="details"
  orientation="vertical"
  items={[
    { value: 'details', title: 'Project details', content: () => <ProjectForm /> },
    { value: 'target', title: 'Deploy target', content: () => <TargetForm /> },
  ]}
/>
```

### Keyboard interaction

`activationMode` controls whether keyboard focus selects a step immediately (`automatic`, the default navigation mode) or selection waits for activation (`manual`). Disabled and navigation-locked steps are skipped.

| Key                                          | Description                                              |
| -------------------------------------------- | -------------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Moves toward the next enabled step where applicable.     |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Moves toward the previous enabled step where applicable. |
| <kbd>Enter</kbd> / <kbd>Space</kbd>          | Activates the focused step in manual activation mode.    |
