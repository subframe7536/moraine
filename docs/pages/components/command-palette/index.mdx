## Usage

Use CommandPalette for searchable commands or navigation targets on an inline surface. The
application decides when to open it and registers any global shortcut. Wrap it in a
[Dialog](/components/dialog) or [Modal](/components/modal) when the palette should occupy a focused
overlay. Use [NavigationMenu](/components/navigation-menu) for persistent site destinations.

```tsx
import { CommandPalette } from 'moraine'

export function Example() {
  return (
    <CommandPalette
      groups={[{ id: 'pages', label: 'Pages', items: [{ value: 'settings', label: 'Settings' }] }]}
    />
  )
}
```

### Groups, filtering, and selection

Pass groups and items from application state. The palette filters the supplied collection and
invokes `onSelect` or an item's own `onSelect`. Fetching commands, routing, and global shortcuts
remain application-owned. Set `disableFilter` when the collection is already filtered.

```tsx
<CommandPalette
  placeholder="Find a workspace section..."
  groups={COMMAND_GROUPS}
  onSelect={(item) => setSection(item.value)}
/>
```

### Custom item layout and states

Use `itemRender` when a row needs extra fields such as owner or status. Provide `emptyRender` when
an empty query or miss needs explanation. Set `loading` while results are still arriving.

```tsx
<CommandPalette
  groups={groups}
  itemRender={(ctx) => <span>{ctx.item.label}</span>}
  emptyRender={() => <p>No commands found.</p>}
  loading={isLoading()}
/>
```

Sub-navigation is a short, deliberate branch of commands. Swap the `groups` prop from application
state rather than treating the palette as an application shell. Set `closeOnSelect={false}` while
the branch stays open.

### Keyboard interaction

| Key                  | Description                            |
| -------------------- | -------------------------------------- |
| <kbd>ArrowDown</kbd> | Moves to the next enabled command.     |
| <kbd>ArrowUp</kbd>   | Moves to the previous enabled command. |
| <kbd>Enter</kbd>     | Activates the highlighted command.     |

Navigation wraps from the last command back to the first. Escape and other dismissal keys belong to
the enclosing Dialog or Modal, not the palette itself.
