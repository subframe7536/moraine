## Usage

Use CommandPalette for searchable commands or navigation targets on an inline surface. The
application decides when to open it and registers any global shortcut. Wrap it in a
[Dialog](/components/dialog) or [BaseDialog](/components/base-dialog) when the palette should occupy a focused
overlay; the wrapper also owns Escape dismissal. Use [NavigationMenu](/components/navigation-menu)
for persistent site destinations.

```tsx
import { CommandPalette } from 'moraine'

export function Example() {
  return (
    <CommandPalette
      items={[{ type: 'group', label: 'Pages', items: [{ value: 'settings', label: 'Settings' }] }]}
    />
  )
}
```

### Groups, filtering, and selection

Pass items and groups from application state. The palette filters the supplied collection and calls
the item's `onSelect`, then the palette's `onSelect`. Fetching commands, routing, and global
shortcuts stay with the application. The default `filterMethod` is `'contains'`; it matches the
item's label, value, description, and `keywords` ignoring case and accents. Pass `'startsWith'`,
`'endsWith'`, or a predicate for custom matching, or `false` to skip filtering when you already
filter the collection. Set `alwaysShow` on an item to keep it visible for any query.

```tsx
<CommandPalette
  placeholder="Find a workspace section..."
  items={COMMAND_GROUPS}
  onSelect={(item) => setSection(item.value)}
/>
```

By default, selecting an enabled item also calls `onClose`. The palette never hides itself: use
`onClose` to close the surrounding Dialog or BaseDialog. Set `closable` to show a close button that calls
`onClose`. The search input takes focus on mount unless the palette sits inside an element with
`role="dialog"`; set `autofocus={false}` to disable it. Control the query with `searchValue` and
`onSearchValueChange`, or start from `defaultSearchValue`.

### Custom item layout and states

Use `itemRender` when a row needs extra fields such as owner or status; it replaces the default row
content, so the items' `leadingRender` and `trailingRender` no longer apply. Provide `emptyRender`
when an empty query or a miss needs explanation, and `footerRender` for a footer such as keyboard
hints. Set `loading` while results are still arriving: it swaps the leading icon for `loadingIcon`,
and items stay selectable.

```tsx
<CommandPalette
  items={groups}
  itemRender={(ctx) => <span>{ctx.item.label}</span>}
  emptyRender={() => <p>No commands found.</p>}
  loading={isLoading()}
/>
```

Sub-navigation is a short, deliberate branch of commands. Swap the `items` prop from application
state rather than treating the palette as an application shell. Set `closeOnSelect={false}` while
the branch stays open.

### Keyboard interaction

| Key                  | Description                              |
| -------------------- | ---------------------------------------- |
| <kbd>ArrowDown</kbd> | Highlights the next enabled command.     |
| <kbd>ArrowUp</kbd>   | Highlights the previous enabled command. |
| <kbd>Enter</kbd>     | Selects the highlighted command.         |

Focus stays in the search input while the highlight moves. Navigation wraps from the last command to
the first. Escape and other dismissal keys belong to the enclosing Dialog or BaseDialog, not the
palette.
