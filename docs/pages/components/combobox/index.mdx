## Usage

Use Combobox when users should type to find one item in a collection. Use [Select](/components/select)
for a non-editable choice, [MultiSelect](/components/multi-select) for several collection values, or
[BaseSelect](/components/base-select) to compose the listbox yourself.

```tsx
import { Field, Combobox } from 'moraine'

export function Example() {
  return (
    <Field label="Fruit">
      <Combobox
        items={[
          { label: 'Apple', value: 'apple' },
          { label: 'Pear', value: 'pear' },
        ]}
        placeholder="Search fruit"
      />
    </Field>
  )
}
```

### String items

Pass strings when the label and value are identical. You can mix strings and objects at the root
or inside a group. Whitespace is preserved, and an empty string is a valid value.

```tsx
<Combobox items={['Apple', 'Banana']} defaultValue="Apple" />
<Combobox
  items={[
    'Apple',
    { value: 'pear', label: 'Pear' },
    { type: 'group', label: 'More fruit', children: ['Banana'] },
  ]}
/>
```

String items are converted to the same item shape used by callbacks: `'Apple'` becomes
`{ value: 'Apple', label: 'Apple' }`. Object items keep their identity and custom fields.
`ComboboxT.NormalizedItem<TItem>` is the callback item type. Item values must be unique. When two
items share a value, the first one wins (including a string that collides with an object), and
development builds log an error.

### Value and query

Pair `value` with `onValueChange` for controlled selection, or use `defaultValue` for an initial
uncontrolled choice. `value={undefined}` keeps the selection uncontrolled; `value={null}` keeps it
controlled and empty. `onValueChange` receives `null` when the selection is cleared, and inside a
form field, clearing writes `null`.

While open, the input displays the query; while closed, it displays the selected item label.
Query text is never committed as a value, and filtering never changes the selection. Use `value` /
`onValueChange` for selection and `searchValue` / `onSearchValueChange` for query text. The query
resets to `''` when the popup finishes closing and after a native form reset; in controlled mode,
`onSearchValueChange('')` reports these resets and you decide whether to apply them.

```tsx
<Combobox
  items={frameworks}
  value={selected()}
  onValueChange={setSelected}
  searchValue={query()}
  onSearchValueChange={setQuery}
/>
```

### Clear and loading

`clearable` shows a clear button while there is a selected value or query text. Clearing resets the
selection and the query, calls `onValueChange(null)` if a value existed, then `onClear`, and returns
focus to the input. `loading` replaces the toggle icon with `loadingIcon`, marks the toggle button
`aria-busy`, and hides the clear button. It does not disable the input or the toggle button.

### Pointer opening

By default, clicking inside the control focuses the input without opening the popup. The trailing
chevron button toggles the popup, and typing non-blank text or pressing ArrowDown opens it. Set
`openOnControlClick` to open the popup on any click on the control outside its buttons.

```tsx
<Combobox items={items} placeholder="Click the chevron to open" />
<Combobox items={items} openOnControlClick placeholder="Click the field to open" />
```

### Keyboard interaction

Focus stays in the input; the highlighted option is exposed through `aria-activedescendant`.

| Key                 | Behavior                                                                          |
| ------------------- | --------------------------------------------------------------------------------- |
| ArrowDown / ArrowUp | Open the popup and move the highlight through enabled options                     |
| PageUp / PageDown   | Move the highlight by one page of options while open                              |
| Enter               | Open the popup, or commit the highlighted option while open                       |
| Escape              | Close the popup; with the popup closed and `clearable`, clear the value and query |
| Backspace / Delete  | With an empty input and `clearable`, clear the value                              |
| Tab                 | Close the popup and move focus on                                                 |
| Home / End          | Move the text cursor; they never move the highlight                               |

### Virtualization

Pass a `virtualizer` from `createListVirtualizer` when rendering the full collection makes opening
or scrolling slow. Type it over `ComboboxT.Row`. Read the [Virtualization guide](/docs/virtualization)
for setup, row measurement, stable keys, and keyboard navigation.

```tsx
<Combobox items={items} virtualizer={virtualizer} />
```

`filterMethod` defaults to `'contains'`, which matches the query anywhere in the label. Set
`'startsWith'` or `'endsWith'` to match only at that end of the label, or pass a predicate for
custom matching.

### Form

Use `form.Field` from `createForm` when the selected value needs schema validation and error
display. `required` is satisfied by any selected item, including a disabled one. In that case the
combobox passes constraint validation but submits no value, as a native `<select>` does with a
disabled selected option.
