Combobox renders the portaled popup collection internally; its content and item names are style slots, rather than attached child parts.

## Usage

Use Combobox when users should type to find one item in a collection. Use [Select](/components/select)
for a non-editable choice, [MultiSelect](/components/multi-select) for multiple collection values, or
[BaseSelect](/components/base-select) to compose the listbox yourself.

```tsx
import { Field, Combobox } from 'moraine'

export function Example() {
  return (
    <Field label="Fruit">
      <Combobox
        items={[
          { label: 'Apple', value: 'apple' },
          { label: 'Pear', value: 'pear' },
        ]}
        placeholder="Search fruit"
      />
    </Field>
  )
}
```

### String items

Pass strings when the label and value are identical. Strings and objects can be mixed at the
root or inside a group. Whitespace is preserved, and an empty string is a valid value.

```tsx
<Combobox items={['Apple', 'Banana']} defaultValue="Apple" />
<Combobox
  items={[
    'Apple',
    { value: 'pear', label: 'Pear' },
    { type: 'group', label: 'More fruit', items: ['Banana'] },
  ]}
/>
```

String items are converted to the same item shape used by callbacks: `'Apple'` becomes
`{ value: 'Apple', label: 'Apple' }`. Object items retain their identity and custom fields.
`ComboboxT.NormalizedItem<TItem>` names the callback item type. Duplicate values use the first
occurrence, including collisions between strings and objects.

### Value and query

Pair `value` with `onValueChange` for controlled selection, or use `defaultValue` for an initial
uncontrolled choice. `null` means no selection; an empty string is a valid item value.

While open, the input displays the query; while closed, it displays the selected item label.
Arbitrary query text is never committed as a value. Use `value` / `onValueChange` for selection and
`searchValue` / `onSearch` for query text.

```tsx
<Combobox
  items={frameworks}
  value={selected()}
  onValueChange={setSelected}
  searchValue={query()}
  onSearch={setQuery}
/>
```

### Pointer opening

By default, clicking inside the input focuses the field without opening the popup immediately. The
trailing chevron button toggles the dropdown, while typing or pressing ArrowDown opens it. Set
`openOnControlClick={true}` if you want any click on the field to open the options list.

```tsx
<Combobox items={items} placeholder="Click the chevron to open" />
<Combobox items={items} openOnControlClick placeholder="Click the field to open" />
```

### Keyboard interaction

| Key                 | Behavior                                                                    |
| ------------------- | --------------------------------------------------------------------------- |
| ArrowDown / ArrowUp | Open the popup or navigate through matched options                          |
| Enter               | Commit the currently highlighted option                                     |
| Escape              | Revert query text or close the dropdown                                     |
| Home / End          | Move text cursor within input (or navigate options when listbox is focused) |

### Virtualization

Add `createListVirtualizer` when rendering the full collection makes opening or scrolling slow.
Read the [Virtualization guide](/docs/virtualization) for setup, row measurements, stable keys, and
keyboard navigation.

```tsx
<Combobox items={items} virtualizer={virtualizer} />
```
