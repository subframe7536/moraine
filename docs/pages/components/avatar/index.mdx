## Usage

Use Avatar where a person or resource needs a compact identity cue. Supply a meaningful `alt` for
identity images. Stack several people with [AvatarGroup](/components/avatar-group).

```tsx
import { Avatar } from 'moraine'

export function Example() {
  return <Avatar src="/avatar.png" alt="Alex" text="A" />
}
```

### Image fallbacks

The fallback shows while the image is loading, missing, or failed. `text` sets the fallback text,
typically initials. When `text` is blank or omitted, the fallback shows up to two initials taken from
`alt`. `icon` is an icon name that replaces the text, for a generic placeholder. Avatar renders the
real `<img src>` during server rendering and uses native load and error events to switch between
image and fallback. `size` accepts `sm`, `md` (default), or `lg`.

```tsx
<Avatar src="/alex.png" alt="Alex Rivera" text="AR" />
<Avatar alt="Guest" icon="i-lucide:user" />
```

### Loading status

The image status is `loading`, `loaded`, or `error`. An empty or missing `src` is `error`. Use
`onStatusChange` when surrounding UI must react to a source change. It fires after mount with the
initial status and on every change, and never on the server. Pair it with a status label owned by the
page.

```tsx
<Avatar src={src()} alt="Alex" onStatusChange={setStatus} />
```

### Badge

`badge` accepts an icon name. `badgePosition` places it in a corner: `top-left`, `top-right`,
`bottom-left`, or `bottom-right` (default). The badge icon is hidden from assistive technology, so
state the status in text when it matters.

```tsx
<Avatar alt="Alex" text="A" badge="i-lucide:check" badgePosition="bottom-right" />
```
