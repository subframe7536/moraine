## Usage

Use Alert for inline feedback that stays in the page flow. Choose [Toast](/components/toast) for
transient notifications and [Modal](/components/modal) for feedback that must block the page. Alert
sets `role="alert"` with `aria-live="assertive"` for the `warning` and `error` types, and
`role="status"` with `aria-live="polite"` for the rest.

```tsx
import { Alert } from 'moraine'

export function Example() {
  return <Alert type="info" title="System update available" />
}
```

### Type and variant

`type` selects the semantic role: `primary`, `secondary`, `info`, `success`, `warning`, and `error`.
The `info`, `success`, `warning`, and `error` types render a matching status icon; `primary` and
`secondary` render none. `variant` selects the surface treatment: `subtle`, `soft`, `outline`, and
`solid`.

### Description layout

Pass `description` for a supporting line below the title. With a description, the root uses larger
padding and the title turns bold.

```tsx
<Alert type="warning" title="Storage almost full" description="You have used 85% of your quota." />
```
