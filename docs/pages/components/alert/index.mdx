## Usage

Use Alert for inline feedback that stays in the page flow. Choose [Toast](/components/toast) for
transient notifications and [BaseDialog](/components/base-dialog) for feedback that must block the page. Alert
sets `role="alert"` with `aria-live="assertive"` for the `warning` and `error` types, and
`role="status"` with `aria-live="polite"` for the rest.

```tsx
import { Alert } from 'moraine'

export function Example() {
  return <Alert type="info" title="System update available" />
}
```

### Type and variant

`type` selects the semantic status: `default`, `info`, `success`, `warning`, and `error`. The
`info`, `success`, `warning`, and `error` types render a matching status icon; `default` renders
none. `variant` selects the surface treatment: `subtle` (default), `soft`, `outline`, and `solid`.

### Description layout

Pass `description` for a supporting line below the title. With a description, the root uses larger
padding and the title turns bold. `children` render after the title and description.

```tsx
<Alert type="warning" title="Storage almost full" description="You have used 85% of your quota." />
```

### Dismissal

Set `closable` to render a dismiss button. Clicking it closes the alert, plays the exit animation,
and removes the alert from the DOM. Use `open` with `onOpenChange` to control visibility, or
`defaultOpen` to start closed. `onOpenChange` fires only for user dismissal, and `onExitComplete`
fires after the alert leaves the DOM. Override the button's accessible label (`Close alert`) with
`translations={{ close: '...' }}`.

```tsx
const [open, setOpen] = createSignal(true)

<Alert closable open={open()} onOpenChange={setOpen} title="Changes saved" />
```
