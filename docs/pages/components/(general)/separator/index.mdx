## Usage

Use Separator to divide related regions with a visible line. Choose its orientation to match the
layout boundary. For a divider inside [ButtonGroup](/components/button-group), use
`ButtonGroup.Separator` so orientation follows the group.

```tsx
import { Separator } from 'moraine'

export function Example() {
  return <Separator />
}
```

### Semantic orientation

Every `Separator` exposes `role="separator"`, `aria-orientation`, and `data-orientation`. The default
orientation is horizontal. Use `vertical` between items in a row.

```tsx
<Separator />
<Separator orientation="vertical" />
```

### Root styling

`Separator` has one `<div>` root. Use direct `class` and `style` for a local override, or configure
`separator.base.root` in your Theme for application defaults. It does not accept instance `classes`
or `styles` maps.

```tsx
<Separator class="bg-blue-500" style={{ height: '3px' }} />
```
