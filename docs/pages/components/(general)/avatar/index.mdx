## Usage

Use Avatar where a person or resource needs a compact identity cue. Supply a meaningful `alt` for
identity images. Stack several people with [AvatarGroup](/components/avatar-group).

```tsx
import { Avatar } from 'moraine'

export function Example() {
  return <Avatar src="/avatar.png" alt="Alex" text="A" />
}
```

### Image fallbacks

`text` shows initials when the image is missing or fails. `fallback` is an icon name for a generic
placeholder. Status is `loading`, `loaded`, or `error`. Avatar renders the real `<img src>` during
server rendering and uses native load and error events to switch between image and fallback.

```tsx
<Avatar src="/alex.png" alt="Alex Rivera" text="AR" />
<Avatar alt="Guest" fallback="i-lucide:user" />
```

### Loading status

Use `onStatusChange` when surrounding UI must react to a source change. Pair it with a status label
owned by the page.

```tsx
<Avatar src={src()} alt="Alex" onStatusChange={setStatus} />
```

### Badge

`badge` accepts an icon name. `badgePosition` places it in a corner; the default is `bottom-right`.

```tsx
<Avatar alt="Alex" text="A" badge="i-lucide:check" badgePosition="bottom-right" />
```
