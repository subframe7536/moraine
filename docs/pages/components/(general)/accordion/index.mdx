## Usage

Use Accordion for several related disclosures that share one open-item policy. For a single independent
disclosure, use [Collapsible](/components/collapsible).

```tsx
import { Accordion } from 'moraine'

export function Example() {
  return (
    <Accordion items={[{ value: 'shipping', label: 'Shipping', content: 'Ships in two days.' }]} />
  )
}
```

### Open items

`value`, `defaultValue`, and `onChange` always use an array of item values. Single mode opens at most
one item. Set `multiple` to allow several. Pair `value` with `onChange` when the page owns the open
set. `collapsible` controls whether the currently open item may close.

```tsx
const [open, setOpen] = createSignal<string[]>(['shipping'])

<Accordion items={items} value={open()} onChange={setOpen} collapsible />
<Accordion multiple defaultValue={['general', 'security']} items={items} />
```

### Content lifetime

The content shell stays mounted so each trigger's `aria-controls` always points to a real element.
`unmountOnHide` controls only the user content inside that shell. Keep content mounted when hidden
fields must preserve local state.

```tsx
<Accordion unmountOnHide={false} defaultValue={['notes']} items={items} />
```

### Keyboard interaction

| Key                                 | Description                                  |
| ----------------------------------- | -------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Toggles the focused trigger when enabled.    |
| <kbd>ArrowDown</kbd>                | Moves focus to the next enabled trigger.     |
| <kbd>ArrowUp</kbd>                  | Moves focus to the previous enabled trigger. |
| <kbd>Home</kbd>                     | Moves focus to the first enabled trigger.    |
| <kbd>End</kbd>                      | Moves focus to the last enabled trigger.     |
