## Usage

Use Alert to deliver static or dismissible feedback within a page or section. Unlike Toast or Modal,
Alert sits inline in the page flow and is rendered by default with `role="status"` or `role="alert"`.

```tsx
import { Alert } from 'moraine'

export function Example() {
  return <Alert type="info" title="System update available" />
}
```

### Semantic status feedback

Use `type` to indicate the nature of the message (`default`, `info`, `success`, `warning`, `error`).
The `'default'` type displays neutral surface styling without an icon, while status types automatically
render their corresponding semantic icons.

### Multi-line message density

Pass `description` to add explanatory content below the title. Alert automatically adapts its layout
with enlarged, top-aligned status icons and generous vertical padding.
