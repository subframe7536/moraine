## Usage

Use Kbd to display one key in a shortcut hint. Combine keys with [KbdGroup](/components/kbd-group).
Showing a shortcut does not register a keyboard handler.

```tsx
import { Kbd } from 'moraine'

export function Example() {
  return <Kbd value="K" />
}
```

### Key aliases

Known aliases such as `meta`, `command`, `ctrl`, `shift`, `alt`, and `escape` resolve to symbols
when `symbol` is true (the default). Pass `symbol={false}` to keep the textual label. Use `label` when
assistive technology needs a name different from the visible keycap.

```tsx
<Kbd value="meta" />
<Kbd value="escape" symbol={false} />
<Kbd value="K" label="Search" />
```

### Root styling

`Kbd` renders one `<kbd>` root, so use direct `class` and `style` for an individual keycap. Configure
`kbd.base.root` in your Theme to share keycap presentation; `classes` and `styles` are reserved for
components with multiple rendered slots.

```tsx
<Kbd value="K" class="text-blue-600" />
```
