import { Progress } from '@src'

Use Progress for measurable task completion or for work whose end is not yet known. Choose a determinate value only when it represents real progress.

## Basic usage

```tsx
import { Progress } from 'moraine'

export function Example() {
  return <Progress value={40} max={100} />
}
```

## Usage

### Progress models

Provide a value for determinate progress and omit it for indeterminate progress. Step mode represents a discrete sequence rather than continuous completion; choose the model that matches the work being described.

<Preview path="./models" />

### Semantics and animation

The component exposes progressbar metadata. Supply a meaningful label or relationship when visual context alone does not identify the operation. Animation settings affect presentation, not progress ownership.
