## Usage

Use Progress for measurable task completion or for work whose end is not yet known. Choose a
determinate value only when it represents real progress. For a loading placeholder of content
structure, use [Skeleton](/components/skeleton).

```tsx
import { Progress } from 'moraine'

export function Example() {
  return <Progress value={40} max={100} aria-label="Upload progress" />
}
```

### Progress models

Provide a numeric `value` for determinate progress. Omit `value` or pass `null` for indeterminate
progress. `valueLabel` supplies `aria-valuetext` for determinate values. Indeterminate progress
reads `aria-valuetext` from the `progress.indeterminate` message.

```tsx
<Progress value={65} aria-label="Uploading design.fig" />
<Progress aria-label="Scanning for malware" />
```

### Label and value

The component exposes progressbar metadata. Supply `aria-label` or a relationship when visual
context alone does not identify the operation. `label` fills the label slot. `showValue` shows the
percentage in the value slot, and `valueRender` replaces that percentage. Indeterminate progress
keeps the label and hides the value. Animation settings affect presentation, not progress ownership.

```tsx
<Progress value={82} label="Downloading installation bundle" showValue aria-label="Download" />
<Progress value={40} valueRender={(ctx) => `${ctx.percent}% complete`} aria-label="Export" />
```
