## Usage

Use Progress for measurable task completion or for work whose end is not yet known. Choose a
determinate value only when it represents real progress. For a loading placeholder of content
structure, use [Skeleton](/components/skeleton).

```tsx
import { Progress } from 'moraine'

export function Example() {
  return <Progress value={40} max={100} aria-label="Upload progress" />
}
```

### Progress models

Provide a numeric `value` for determinate progress. Omit `value` or pass `null` for indeterminate
progress. Pass a string array as `max` for a discrete sequence; `value` is then the active step
index. `getValueLabel` supplies `aria-valuetext` for determinate values. Indeterminate progress
uses `aria-valuetext="indeterminate progress"`.

```tsx
<Progress value={65} aria-label="Uploading design.fig" />
<Progress aria-label="Scanning for malware" />
<Progress value={1} max={['Waiting', 'Cloning', 'Done']} aria-label="Clone repository" />
```

### Semantics and status

The component exposes progressbar metadata. Supply `aria-label` or a relationship when visual
context alone does not identify the operation. `status` shows the percentage label. `statusRender`
replaces that label. Animation settings affect presentation, not progress ownership.

```tsx
<Progress value={82} status aria-label="Downloading installation bundle" />
<Progress value={40} statusRender={(ctx) => `${ctx.percent}% complete`} aria-label="Export" />
```
