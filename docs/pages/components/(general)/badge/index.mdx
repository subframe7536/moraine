## Usage

Use Badge for compact status or metadata beside content. It is presentational by default. An action
needs a semantic interactive root and an accessible name.

```tsx
import { Badge } from 'moraine'

export function Example() {
  return <Badge>Active</Badge>
}
```

### Presentational status

Place Badge beside a separately labeled control or heading. It does not replace an accessible status
announcement where one is required. Variants (`solid`, `subtle`, `surface`, `outline`) and sizes
(`sm`, `md`, `lg`) change appearance only.

```tsx
<Badge variant="subtle">In progress</Badge>
<Badge variant="outline" size="sm">
  v2.4.0
</Badge>
```

### Interactive root

For a clickable badge, set `as` to a semantic element and pass that element's required attributes.

```tsx
<Badge as="button" type="button" onClick={onFilter}>
  Needs review
</Badge>
```
