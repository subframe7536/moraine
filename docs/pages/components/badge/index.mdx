## Usage

Use Badge for compact status or metadata beside content. It renders a presentational `span` by default.
For an action, render a semantic interactive element with an accessible name.

```tsx
import { Badge } from 'moraine'

export function Example() {
  return <Badge>Active</Badge>
}
```

### Presentational status

Place Badge beside a separately labeled control or heading. It does not replace an accessible status
announcement where one is required. `variant` (`solid`, `soft` by default, `subtle`, `outline`),
`tone`, and `size` (`sm`, `md` by default, `lg`) change appearance only.

```tsx
<Badge variant="soft">In progress</Badge>
<Badge variant="outline" tone="success" size="sm">
  v2.4.0
</Badge>
```

### Label and icons

Badge text always comes from `children`. `leading` and `trailing` take icon names and render
before and after the label. A badge with no children and exactly one icon renders as a square
icon badge.

```tsx
<Badge variant="soft" leading="i-lucide:eye">Needs review</Badge>
<Badge leading="i-lucide:check" />
```

### Interactive root

For a clickable badge, set `as` to a semantic element and pass the attributes that element requires.

```tsx
<Badge as="button" type="button" onClick={onFilter}>
  Needs review
</Badge>
```
