## Usage

Use Resizable to split space into draggable, keyboard-accessible panels for multi-pane layouts. For a
single expandable disclosure or a drawer, see [Collapsible](/components/collapsible) or
[Sheet](/components/sheet).

The root owns the size of every panel. `Resizable.Panel` sets each panel's `min`, `max`, and
collapse constraints. Place `Resizable.Handle` between two panels to add pointer dragging, keyboard
resizing, and collapse toggles.

```tsx
import { Resizable } from 'moraine'

export function Example() {
  return (
    <div class="h-64 w-full border border-border rounded-xl overflow-hidden">
      <Resizable defaultValue={['30%', '70%']}>
        <Resizable.Panel min="20%">
          <div class="p-4">Sidebar</div>
        </Resizable.Panel>
        <Resizable.Handle />
        <Resizable.Panel min="30%">
          <div class="p-4">Content</div>
        </Resizable.Panel>
      </Resizable>
    </div>
  )
}
```

### Panel constraints

Give the root `defaultValue` for initial sizes and set `min` or `max` on each panel. A value is a
pixel number (`240`) or a percentage string relative to the root (`'25%'`). Dragging a handle grows
one panel and shrinks its neighbor, stopping at each panel's `min` and `max`. A panel with
`resizable={false}` stays at its current size.

```tsx
<Resizable defaultValue={['32%', '68%']}>
  <Resizable.Panel min="25%" max="45%">
    Inspector
  </Resizable.Panel>
  <Resizable.Handle />
  <Resizable.Panel min="35%">Viewport</Resizable.Panel>
</Resizable>
```

### Collapsible panels

Set `collapsible` on a panel to let it collapse to `collapsibleMin` (default `0`). Set
`action="collapse"` on the adjacent `Resizable.Handle` so clicking the grip or pressing <kbd>Enter</kbd>
toggles the panel. A handle's children can be a render function that receives `collapsed`, `dragging`,
and `active` to switch the icon. `onCollapse` and `onExpand` report the panel's pixel size when it
toggles.

```tsx
<Resizable.Panel collapsible collapsibleMin={56} onCollapse={onCollapse} onExpand={onExpand}>
  Sidebar
</Resizable.Panel>
<Resizable.Handle action="collapse">
  {(state) => <Icon name={state.collapsed ? 'i-lucide:panel-left-open' : 'i-lucide:panel-left-close'} />}
</Resizable.Handle>
```

### Controlled state and persistence

Use `value` with `onValueChange` when the application coordinates layout presets, resets, or persists
splits to storage. `onValueChange` receives exact pixel sizes. Sizes that do not match the panel count
or fall outside each panel's bounds are normalized to fit the available space.

```tsx
<Resizable value={sizes()} onValueChange={setSizes}>
  <Resizable.Panel min={150}>Logs</Resizable.Panel>
  <Resizable.Handle />
  <Resizable.Panel min={150}>Output</Resizable.Panel>
</Resizable>
```

### Keyboard interaction

Handles render semantic separator elements with `tabIndex={0}`, `role="separator"`, and standard
ARIA boundary values.

| Key                                          | Description                                                        |
| -------------------------------------------- | ------------------------------------------------------------------ |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Decreases the active separator by `keyboardDelta` (default `10%`). |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Increases the active separator by `keyboardDelta` (default `10%`). |
| <kbd>Shift</kbd> + <kbd>Arrow</kbd>          | Jumps the active separator to its minimum or maximum limit.        |
| <kbd>Home</kbd>                              | Snaps the adjacent panel to its minimum permitted size.            |
| <kbd>End</kbd>                               | Snaps the adjacent panel to its maximum permitted size.            |
| <kbd>Enter</kbd>                             | Toggles the nearest collapsible panel when `action="collapse"`.    |
| <kbd>Alt</kbd> + drag                        | Distributes delta symmetrically across adjacent panels.            |
