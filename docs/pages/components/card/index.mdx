## Usage

Use Card to group related content and actions on a neutral surface. Its parts are structural and add
no interactive behavior or ARIA relationships. The root, `Card.Title`, and the other parts render a
`div` by default (`Card.Description` renders a `p`); set `as` to change the element, such as a
heading for the title or `article` for the root.

```tsx
import { Card } from 'moraine'

export function Example() {
  return (
    <Card>
      <Card.Header>
        <Card.Title>Project</Card.Title>
      </Card.Header>
      <Card.Body>Project details</Card.Body>
    </Card>
  )
}
```

### Variants and sizes

`variant` sets the surface; the header always looks the same as the body. `outline` (default) draws
the outer border and shadow and a top border on the footer. `subtle` adds a muted footer background.
`none` drops the outer border, shadow, and footer divider and keeps only the background and part
spacing, for a card nested inside another bordered surface. The `sm`, `md` (default), and `lg` sizes
change the density of the header, body, footer, title, and description together. Set `variant` and
`size` on `Card`; the parts inherit them.

```tsx
<Card variant="subtle" size="sm">
  <Card.Header>
    <Card.Title as="h2">Seats</Card.Title>
    <Card.Description>8 of 10 used</Card.Description>
  </Card.Header>
</Card>
```

### Parts

Compose the parts you need inside `Card`. Header and body provide horizontal insets, while the root
spaces the sections. Direct children can still span the card's full width. Place a control for the
whole card in `Card.Action`, which sits at the end of the header beside the title and description.
Place other actions in `Card.Footer`.

```tsx
<Card>
  <Card.Header>
    <Card.Title as="h2">Invoice</Card.Title>
    <Card.Action>
      <Button size="sm">Download</Button>
    </Card.Action>
  </Card.Header>
  <Card.Body>Due 12 May</Card.Body>
  <Card.Footer>
    <Button>Pay</Button>
  </Card.Footer>
</Card>
```

### Semantics

Card does not choose a heading level. Set `as` on `Card.Title` to the level that fits the page, such
as `h2`, and set `as="article"` on `Card` when the card is a standalone story.

only if the image must follow the card radius.
