## Usage

Use CopyButton to copy a string or `ClipboardItem` to the clipboard from a single control. It writes
through `navigator.clipboard` and falls back to `document.execCommand('copy')` when the Clipboard API
is missing or the write fails. After a successful copy it shows a copied state, then returns to idle.

```tsx
import { CopyButton } from 'moraine'

export function Example() {
  return <CopyButton value="https://moraine.subf.dev" />
}
```

### With text and icons

Pass children to render a labeled button. Without children, CopyButton renders a square icon-only
button at the matching icon size.

```tsx
<CopyButton value="npm i moraine">Copy Install Command</CopyButton>
```

### Feedback duration and icons

`copiedDuration` sets how long the copied state holds in milliseconds; it defaults to 2000. Set `icon`
for the idle glyph and `copiedIcon` for the copied glyph.

```tsx
<CopyButton
  value="https://example.com"
  copiedDuration={3000}
  icon="i-lucide:clipboard"
  copiedIcon="i-lucide:check-check"
/>
```

### Headless hook: `createCopy`

`createCopy` from `moraine/utils` runs the same copy logic without a button. It returns `copy`,
`reset`, and the `isCopied`, `isError`, `state`, and `isSupported` accessors.

```tsx
import { createCopy } from 'moraine/utils'

const copy = createCopy({
  copiedDuration: 2500,
  onCopy: (value) => console.log('Copied:', value),
})

// Trigger programmatically:
copy.copy('Hello world')
```
