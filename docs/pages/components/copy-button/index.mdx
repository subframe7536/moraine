## Usage

Use CopyButton to copy a string or `ClipboardItem` to the clipboard from a single control. It writes
through `navigator.clipboard` and falls back to `document.execCommand('copy')` when the Clipboard API
is missing or the write fails. After a copy it holds a `copied` or `error` state for `resetDelay`,
then returns to `idle`.

```tsx
import { CopyButton } from 'moraine'

export function Example() {
  return <CopyButton value="https://moraine.subf.dev" />
}
```

### Value

`value` accepts a string, a `ClipboardItem`, a `ClipboardItem[]`, a promise of either, or a function
that returns one. A function runs on every click, and a promise is awaited first. If either fails,
the copy fails and `onCopyError` receives the error. The `execCommand` fallback copies text only.

```tsx
<CopyButton value={async () => (await fetch('/api/share-link')).text()}>Copy share link</CopyButton>
```

### Label and icons

Pass children to render a labeled button. Without children, CopyButton renders a square icon-only
button at the matching icon size. `iconPosition` places the icon before (`leading`, default) or after
(`trailing`) the label. Children can also be a function that receives the copy state, including
`copied`, `error`, `status`, `supported`, and `copy`.

```tsx
<CopyButton value="npm i moraine">Copy Install Command</CopyButton>
```

### Accessible name

The button's `aria-label` is `Copy to clipboard`, and `Copied to clipboard` while copied. Override
the wording through the provider messages, or set `aria-label` to name what is copied. After a failed
copy the button sets `aria-invalid` until `resetDelay` elapses.

### Variant, tone, and size

`variant` (`solid`, `soft`, `outline`, `ghost`), `tone`, and `size` work as on
[Button](/components/button), but CopyButton defaults to the `ghost` variant and `neutral` tone.
Inside a [ButtonGroup](/components/button-group), it inherits the group's `size`, `tone`, and
`variant` (except `link`).

### Feedback

`resetDelay` sets how long the `copied` or `error` state holds, in milliseconds; it defaults to 2000. Set `icon` for the idle glyph and `copiedIcon` for the copied glyph. Pass `icon={false}` to hide
the icon. Use `onCopySuccess`, `onCopyError`, and `onStatusChange` (which receives the new status) to react
to the result.

```tsx
<CopyButton
  value="https://example.com"
  resetDelay={3000}
  icon="i-lucide:clipboard"
  copiedIcon="i-lucide:check-check"
/>
```

### `createCopy` hook

[createCopy](/hooks/create-copy) from `moraine/utils` runs the same copy logic without a button. It
returns `copy` and `reset`, plus the `isCopied`, `isError`, `status`, `error`, and `isSupported`
accessors.

```tsx
import { createCopy } from 'moraine/utils'

const copy = createCopy({
  resetDelay: 2500,
  onCopySuccess: (value) => console.log('Copied:', value),
})

// Trigger programmatically:
copy.copy('Hello world')
```
