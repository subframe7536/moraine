## Usage

Use CopyButton to let users copy text snippets, tokens, or clipboard items to their clipboard with built-in feedback states and automatic fallback from modern Clipboard API to legacy execCommand.

```tsx
import { CopyButton } from 'moraine'

export function Example() {
  return <CopyButton value="https://moraine.subf.dev" />
}
```

### With text and icons

CopyButton renders an icon by default when sized to icon sizes (`icon-md`), or can include a label and custom icons.

```tsx
<CopyButton value="npm i moraine">Copy Install Command</CopyButton>
```

### Copied variants and tones

Customize the appearance specifically for the copied state using `copiedVariant` and `copiedTone`.

```tsx
<CopyButton
  value="secret_key"
  variant="outline"
  tone="neutral"
  copiedVariant="solid"
  copiedTone="success"
/>
```

### Custom feedback duration and icons

Configure the feedback display duration with `copiedDuration` in milliseconds (defaults to 2000ms), and customize the idle and copied icons.

```tsx
<CopyButton
  value="https://example.com"
  copiedDuration={3000}
  icon="i-lucide:clipboard"
  copiedIcon="i-lucide:check-check"
/>
```

### Headless hook: `createCopy`

Use `createCopy` for custom clipboard interactions without UI constraints:

```tsx
import { createCopy } from 'moraine'

const copy = createCopy({
  copiedDuration: 2500,
  onCopy: (value) => console.log('Copied:', value),
})

// Trigger programmatically:
copy.copy('Hello world')
```
