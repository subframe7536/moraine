## Usage

Use Pagination when a result set has a known page count. The application owns data fetching and the
mapping from page numbers to URLs or controlled state. Do not use Pagination for a wizard; use
[Stepper](/components/stepper) for a fixed sequence of steps.

```tsx
import { Pagination } from 'moraine'

export function Example() {
  return <Pagination total={100} pageSize={10} defaultPage={1} />
}
```

### Current page

Use `page` with `onPageChange` for controlled navigation, or `defaultPage` to start uncontrolled.
`total` is the number of records, not the page count; the component derives the page count,
`ceil(total / pageSize)`, from `pageSize`. The page count is at least 1. A page outside that range
is clamped for display, so reset the page when `pageSize` changes. `onPageChange` also fires in
controlled mode, so write the value back to `page`.

```tsx
<Pagination total={100} pageSize={10} page={page()} onPageChange={setPage} />
```

### Page window and controls

`siblingCount` (default `2`) sets how many page numbers show on each side of the current page. The
first and last pages always show, with ellipses for skipped ranges. Every page shows without
ellipses when `2 * siblingCount + 5` reaches the page count. Set `controls={false}` to hide Previous
and Next. `prevText` and `nextText` add visible text to those controls; their accessible names still
come from `translations`.

```tsx
<Pagination total={500} pageSize={10} siblingCount={1} prevText="Previous" nextText="Next" />
```

### Rendering links

Use `getPageHref(page)` by itself to render page controls as anchors. The current page stays a button.
For router integration, use `itemAs` for numbered items and `controlAs` for Previous/Next; these
props are independent and `getPageHref` still only generates the destination. Clicking a link also calls
`onPageChange`. Previous on the first page and Next on the last page remain disabled buttons even
when `controlAs` is set, and `disabled` turns every control into a disabled button.

```tsx
<Pagination
  itemAs={A}
  controlAs={A}
  total={50}
  pageSize={10}
  page={page()}
  getPageHref={(page) => `/results?page=${page}`}
/>
```

### Keyboard interaction

Pagination adds no arrow-key navigation across controls. Each page control keeps the keyboard
semantics of the button or link it renders. A visually hidden live region announces the current
page after each change.
