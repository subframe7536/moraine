## Usage

Use Pagination when a result set has a known page count. The application owns data fetching and the
mapping from page numbers to URLs or controlled state. Do not use Pagination for a wizard; use
[Stepper](/components/stepper) for a fixed sequence of steps.

```tsx
import { Pagination } from 'moraine'

export function Example() {
  return <Pagination total={100} itemsPerPage={10} defaultPage={1} />
}
```

### Current page

Use `page` with `onPageChange` for controlled navigation. `total` is the number of records, not the
page count; the component derives the page count from `itemsPerPage`. Keep the requested page inside
the new page count when `itemsPerPage` changes.

```tsx
<Pagination total={100} itemsPerPage={10} page={page()} onPageChange={setPage} />
```

### Rendering links

Use `to(page)` by itself to render enabled page controls as anchors. For router integration, use
`itemAs` for numbered items and `controlAs` for Previous/Next; these props are independent and `to`
still only generates the destination. Boundary Previous/Next controls remain native disabled buttons
even when `controlAs` is set.

```tsx
<Pagination
  itemAs={A}
  controlAs={A}
  total={50}
  itemsPerPage={10}
  page={page()}
  to={(page) => `/results?page=${page}`}
/>
```

### Keyboard interaction

Pagination adds no arrow-key navigation across controls. Each page control keeps the keyboard
semantics of the button or link it renders.
