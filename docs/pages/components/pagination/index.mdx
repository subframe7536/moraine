## Usage

Use Pagination when a result set has a known page count. The application owns data fetching and the
mapping from page numbers to URLs or controlled state. Do not use Pagination for a wizard; use
[Stepper](/components/stepper) for a fixed sequence of steps.

```tsx
import { Pagination } from 'moraine'

export function Example() {
  return <Pagination total={100} pageSize={10} defaultPage={1} />
}
```

### Current page

- `page`, `defaultPage`, and `onPageChange`: use `page` with `onPageChange` for controlled navigation, or `defaultPage` to start uncontrolled. `onPageChange` also fires in controlled mode, so write the value back to `page`.
- `total` and `pageSize`: `total` is the record count (not the page count). `Pagination` derives the page count as `Math.max(1, Math.ceil(total / pageSize))`.
- Clamping: a `page` outside the derived range is clamped for display, so reset `page` when `pageSize` changes.

```tsx
<Pagination total={100} pageSize={10} page={page()} onPageChange={setPage} />
```

### Page window and controls

- `siblingCount` (default `2`): sets how many page numbers appear on each side of the current page. The first and last pages always render, with ellipses for skipped ranges; every page shows without ellipses when `2 * siblingCount + 5` reaches the page count.
- `controls`: set `controls={false}` to hide the Previous and Next buttons.
- `prevText` and `nextText`: add visible text to the Previous and Next controls (hidden below the `sm` breakpoint) and replace `translations.prev` and `translations.next` as their accessible names.

```tsx
<Pagination total={500} pageSize={10} siblingCount={1} prevText="Previous" nextText="Next" />
```

### Rendering links

- `getPageHref(page)`: renders numbered page controls and available Previous/Next controls as `<a>` elements with the returned `href`. Clicking a link still calls `onPageChange`.
- `itemRender` and `controlRender`: accept a component receiving native anchor props (`PaginationT.ItemRenderProps`) for router integration on numbered items and Previous/Next controls respectively. Spread the received props onto your router link.
- Button fallbacks: the current page has no `href` and stays a button (handle missing `href` in `itemRender`). Previous on the first page, Next on the last page, and all controls when `disabled` is set render as disabled buttons even when `controlRender` is provided.

```tsx
<Pagination
  itemRender={RouterLink}
  controlRender={RouterLink}
  total={50}
  pageSize={10}
  page={page()}
  getPageHref={(page) => `/results?page=${page}`}
/>
```

### Keyboard interaction

Pagination adds no arrow-key navigation across controls. Each page control keeps the keyboard
semantics of the button or link it renders. A visually hidden live region announces the current
page after each change.
