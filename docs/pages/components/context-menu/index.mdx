## Usage

Use ContextMenu for actions tied to a specific surface or item at the pointer location. Keep
essential actions reachable through another visible path.

- Use [DropdownMenu](/components/dropdown-menu) when the same actions open from a visible trigger.
- Use [Popover](/components/popover) when the content is not a list of commands.
- Use [Dialog](/components/dialog) when the user must complete or confirm a modal task.

```tsx
import { ContextMenu } from 'moraine'

export function Example() {
  return (
    <ContextMenu>
      <ContextMenu.Trigger>Right-click here</ContextMenu.Trigger>
      <ContextMenu.Content items={[{ label: 'Copy' }]} />
    </ContextMenu>
  )
}
```

### Trigger

Wrap the target with `ContextMenu.Trigger`. The menu opens at the pointer on right-click or a touch
or pen long press (700 ms), and at the center of the trigger when opened from the keyboard.

The trigger renders a `div`; pass `as` to render another element. With `disabled` on the root, the
native browser menu shows instead.

```tsx
<ContextMenu>
  <ContextMenu.Trigger as="div" class="flex h-32 items-center justify-center">
    Right-click or long-press inside this area
  </ContextMenu.Trigger>
  <ContextMenu.Content
    items={[
      { label: 'Back', icon: 'i-lucide:arrow-left' },
      { label: 'Forward', icon: 'i-lucide:arrow-right', disabled: true },
      { label: 'Reload', icon: 'i-lucide:rotate-cw' },
    ]}
  />
</ContextMenu>
```

### Items

The `items` array describes the whole menu. An item has `type` `'item'` (the default), `'checkbox'`,
`'radio-group'`, `'group'`, or `'separator'`; an item with `children` opens a submenu. An entry that
is an array of items forms its own group, and the menu draws a separator between groups.

Items accept `icon`, `description`, `kbds`, `disabled`, and `danger`; a separator takes no other
options. `kbds` only displays keycaps and does not register a shortcut.

Checkbox and radio state is controlled with `checked` / `onCheckedChange` and with `value` /
`onValueChange` on the `radio-group` (not on each radio). Omit them to let the item manage its own
state from `defaultChecked` or `defaultValue`. Selecting a checkbox or radio keeps the menu open;
selecting a regular item runs `onSelect` and closes it.

A parent item with `children` can take `open` and `onOpenChange` to control its submenu.
`onOpenChange` reports every open or close request from pointer, keyboard, or click interaction. With
a controlled `open`, the submenu stays at the prop value until you update it.

```tsx
<ContextMenu.Content
  items={[
    {
      type: 'checkbox',
      label: 'Pin item',
      checked: pinned(),
      onCheckedChange: setPinned,
    },
    { type: 'separator' },
    {
      type: 'radio-group',
      value: priority(),
      onValueChange: setPriority,
      children: [{ type: 'radio', label: 'High priority', value: 'high' }],
    },
  ]}
/>
```

`ContextMenu.Content` also takes `headerRender` and `footerRender` components to add a header (such
as the target's metadata) or a footer around the item groups. The root menu and every open submenu
mount their own copy, and each receives `{ sub }`.

`itemRender` replaces the inner content of every item row; the row keeps its role, keyboard
handling, and selection.

### Dismissal and scrolling

Escape and outside presses close the menu. Set `closeOnEscape` or `closeOnOutsideClick` to `false` to
block them, and use `onClosePrevented` to react to the blocked attempt. While the menu is open, body
scroll is locked by default; set `preventScroll` to `false` to keep the page scrollable.

### Keyboard interaction

| Key                                             | Description                                                               |
| ----------------------------------------------- | ------------------------------------------------------------------------- |
| <kbd>Shift + F10</kbd> / <kbd>ContextMenu</kbd> | Toggles the menu from the focused trigger.                                |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>       | Moves focus to the next or previous item.                                 |
| <kbd>Home</kbd> / <kbd>End</kbd>                | Moves focus to the first or last item.                                    |
| Printable characters                            | Moves focus to the next item whose text starts with the typed characters. |
| <kbd>ArrowRight</kbd>                           | Opens the submenu of the focused item.                                    |
| <kbd>ArrowLeft</kbd>                            | Closes the current submenu and returns to its parent item.                |
| <kbd>Enter</kbd> / <kbd>Space</kbd>             | Activates the focused item, or opens its submenu.                         |
| <kbd>Escape</kbd>                               | Closes the current menu layer and restores focus.                         |
| <kbd>Tab</kbd>                                  | Closes the menu.                                                          |
