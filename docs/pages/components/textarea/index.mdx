## Usage

Use Textarea for multi-line native text entry. Use [Input](/components/input) for a single line.
Use [InputGroup](/components/input-group) to put controls around it without changing which element
receives typing and focus.

```tsx
import { Field, Textarea } from 'moraine'

export function Example() {
  return (
    <Field label="Message">
      <Textarea placeholder="Write a message" />
    </Field>
  )
}
```

### Native attributes

`Textarea` forwards native textarea attributes and works with controlled or uncontrolled values.
Pair `value` with `onValueChange` for controlled text, or use `defaultValue`; a native form reset
restores `defaultValue`. A controlled textarea restores its displayed text to `value` after every
edit, so update `value` from `onValueChange`. Use `readOnly` to preserve selection and focus without
edits, or `disabled` to prevent interaction.

```tsx
<Textarea value={bio()} onValueChange={setBio} rows={3} />
```

`modifiers` works as on [Input](/components/input#value-modifiers): `trim`, `lazy`, `number`, and
`empty` transform the text before `onValueChange` and form state. In Textarea, `trim` and `lazy`
apply on `change` (blur).

### Size and composition

`rows` sets the visible height (default `3`). Set `autoResize` to grow the textarea with its content:
it never shrinks below `rows`, and `maxRows` caps the growth before it scrolls (`0`, the default, is
unlimited). `autoResizeDelay` postpones the first resize after mount. Use
`InputGroup orientation="vertical"` with `Leading` and `Trailing` for header and footer regions.
Your application owns counters, submit buttons, and keyboard shortcuts.

```tsx
<InputGroup orientation="vertical">
  <Textarea placeholder="Write a comment..." autoResize rows={2} maxRows={6} />
  <InputGroup.Trailing>
    <span>Markdown supported</span>
    <Button size="xs">Comment</Button>
  </InputGroup.Trailing>
</InputGroup>
```
