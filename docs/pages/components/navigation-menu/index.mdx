## Usage

Use NavigationMenu for website destinations, with direct links and expandable link panels. Use
[DropdownMenu](/components/dropdown-menu) for a menu of actions. Use [Tabs](/components/tabs) for
peer panels that stay on the same page.

```tsx
import { NavigationMenu } from 'moraine'

export function Example() {
  return (
    <NavigationMenu aria-label="Main navigation">
      <NavigationMenu.List>
        <NavigationMenu.Item value="products">
          <NavigationMenu.Trigger>Products</NavigationMenu.Trigger>
          <NavigationMenu.Content>
            <NavigationMenu.Link href="/overview" closeOnSelect>
              Overview
            </NavigationMenu.Link>
          </NavigationMenu.Content>
        </NavigationMenu.Item>
        <NavigationMenu.Item>
          <NavigationMenu.Link href="/docs">Documentation</NavigationMenu.Link>
        </NavigationMenu.Item>
      </NavigationMenu.List>
    </NavigationMenu>
  )
}
```

### Panels and direct links

Combine expandable panels with direct links. Use `NavigationMenu.Content` for each panel and
`NavigationMenu.Link` for its destinations; a link can also sit directly in a `NavigationMenu.Item`.
`active` marks the current page with `aria-current="page"`. `closeOnSelect` defaults to `false`;
enable it to close the panel on activation. A click handler that calls `preventDefault()` cancels
the close. A disabled link loses its `href` and gets `aria-disabled`.

```tsx
<NavigationMenu.Item value="products">
  <NavigationMenu.Trigger>Products</NavigationMenu.Trigger>
  <NavigationMenu.Content>
    <NavigationMenu.Link href="/overview" closeOnSelect>
      Overview
    </NavigationMenu.Link>
  </NavigationMenu.Content>
</NavigationMenu.Item>
<NavigationMenu.Item>
  <NavigationMenu.Link href="/docs" active>
    Documentation
  </NavigationMenu.Link>
</NavigationMenu.Item>
```

The root renders a navigation landmark. Give it an accessible name when the page has several
navigation landmarks. This version supports one level of panels.

### Controlled state

Give each item a stable `value`, then control the open item with `value` and `onValueChange`.
`onValueChange` receives the value of the item to open, or `undefined` to close, and you write it
back to `value`. A value that matches no enabled item with content leaves the menu closed, so
disabled or removed items cannot keep a panel open. For uncontrolled state, `defaultValue` opens an
item after hydration. `disabled` on the root disables every trigger and link and closes the
open panel; on an `Item` it disables only that item's trigger or direct links.

```tsx
<NavigationMenu value={value()} onValueChange={setValue} disabled={disabled()}>
  <NavigationMenu.List>
    <NavigationMenu.Item value="account">
      <NavigationMenu.Trigger>Account</NavigationMenu.Trigger>
      <NavigationMenu.Content>...</NavigationMenu.Content>
    </NavigationMenu.Item>
  </NavigationMenu.List>
</NavigationMenu>
```

### Orientation

Set `orientation="vertical"` for a vertical list. Use `placement="right"` to place its panels beside
the triggers.

```tsx
<NavigationMenu aria-label="Docs navigation" orientation="vertical" placement="right">
  <NavigationMenu.List>...</NavigationMenu.List>
</NavigationMenu>
```

### Hover timing and positioning

Panels open on hover after `openDelay` (default `50` ms) while no panel is open; hovering another
trigger while a panel is open switches immediately, and click or keyboard activation never waits.
The open panel closes `closeDelay` (default `50` ms) after the pointer leaves the menu, and stays
open while focus is inside it. `placement` (default `'bottom'`), `align` (default `'center'`),
`gutter` (default `8`), `shift`, `flip`, and `slide` position the shared panel relative to the
active trigger.

### RTL

Set `dir="rtl"` on a surrounding container for right-to-left navigation. Arrow keys follow that
direction, including the key that opens a panel from a vertical menu.

```tsx
<div dir="rtl">
  <NavigationMenu aria-label="Main navigation">
    <NavigationMenu.List>...</NavigationMenu.List>
  </NavigationMenu>
</div>
```

### Custom links

Use `linkRender` for a router's link component. Forward the supplied attributes, events, children,
object style, and ref to the anchor.

```tsx
<NavigationMenu.Link linkRender={RouterLink} href="/components/button">
  Button
</NavigationMenu.Link>
```

### Keyboard interaction

Arrow keys along the list axis move focus without opening a panel. Home and End focus the first and last enabled navigation controls. Enter and Space activate a trigger. ArrowDown opens a horizontal menu and enters its content; ArrowRight does the same for a vertical LTR menu, and ArrowLeft for RTL.

Tab and Shift+Tab preserve the order between the trigger, its portaled content and the following navigation control. Arrow keys and Home/End move between panel links, while inputs retain their editing keys. Escape closes the panel and returns focus to its trigger. Outside click and focus close the panel without taking focus away from the destination.
