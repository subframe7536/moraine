## Usage

Use NavigationMenu for website destinations, with direct links and expandable link panels. Use
[DropdownMenu](/components/dropdown-menu) for a menu of actions. Use [Tabs](/components/tabs) for
peer panels that stay on the same page.

```tsx
import { NavigationMenu } from 'moraine'

export function Example() {
  return (
    <NavigationMenu aria-label="Main navigation">
      <NavigationMenu.List>
        <NavigationMenu.Item value="products">
          <NavigationMenu.Trigger>Products</NavigationMenu.Trigger>
          <NavigationMenu.Content>
            <NavigationMenu.Link href="/overview">Overview</NavigationMenu.Link>
          </NavigationMenu.Content>
        </NavigationMenu.Item>
        <NavigationMenu.Item>
          <NavigationMenu.Link href="/docs">Documentation</NavigationMenu.Link>
        </NavigationMenu.Item>
      </NavigationMenu.List>
    </NavigationMenu>
  )
}
```

### Panels and links

Combine expandable panels with direct links:

- `NavigationMenu.Content`: holds an item's expandable panel.
- `NavigationMenu.Link`: renders a destination inside `Content` or directly inside `NavigationMenu.Item`.
- `active`: marks the current page with `aria-current="page"`.
- `closeOnSelect`: clicking a link closes the open panel by default. Set `closeOnSelect={false}` to keep it open, or call `preventDefault()` in a click handler to cancel closing.
- `disabled`: removes `href` from a link and sets `aria-disabled`.

```tsx
<NavigationMenu.Item value="products">
  <NavigationMenu.Trigger>Products</NavigationMenu.Trigger>
  <NavigationMenu.Content>
    <NavigationMenu.Link href="/overview">
      Overview
    </NavigationMenu.Link>
  </NavigationMenu.Content>
</NavigationMenu.Item>
<NavigationMenu.Item>
  <NavigationMenu.Link href="/docs" active>
    Documentation
  </NavigationMenu.Link>
</NavigationMenu.Item>
```

The root renders a `<nav>` landmark. Give it an `aria-label` when the page has multiple navigation landmarks. `NavigationMenu` supports one level of panels.

### Controlled state

Give each item with content a stable `value`:

- `value` and `onValueChange`: control the open item. `onValueChange` receives the item `value` to open or `null` to close; write it back to `value`.
- `null` vs `undefined`: pass `value={null}` to keep a controlled menu closed; `value={undefined}` leaves it uncontrolled. A value matching no enabled item with content also leaves the menu closed.
- `defaultValue`: opens an initial item after hydration in uncontrolled mode.
- `disabled`: on the root, disables every trigger and link and closes any open panel; on an `Item`, disables only that item's trigger or direct links.

```tsx
<NavigationMenu value={value()} onValueChange={setValue} disabled={disabled()}>
  <NavigationMenu.List>
    <NavigationMenu.Item value="account">
      <NavigationMenu.Trigger>Account</NavigationMenu.Trigger>
      <NavigationMenu.Content>...</NavigationMenu.Content>
    </NavigationMenu.Item>
  </NavigationMenu.List>
</NavigationMenu>
```

### Orientation

Set `orientation="vertical"` for a vertical list. Use `placement="right"` to place its panels beside the triggers.

```tsx
<NavigationMenu aria-label="Docs navigation" orientation="vertical" placement="right">
  <NavigationMenu.List>...</NavigationMenu.List>
</NavigationMenu>
```

### Hover and positioning

- `openDelay` (default `50` ms): delays hover opening when no panel is open. Hovering another trigger while a panel is open switches immediately, and click or keyboard activation never waits.
- `closeDelay` (default `50` ms): delays closing after the pointer leaves the menu. The panel stays open while focus is inside it.
- Positioning: `placement` (default `'bottom'`), `align` (default `'center'`), `gutter` (default `8`), `shift`, `flip`, and `slide` position the shared panel relative to the active trigger.

### RTL

Set `dir="rtl"` on a surrounding container for right-to-left navigation. Arrow keys follow that direction, including the key that opens a panel from a vertical menu.

```tsx
<div dir="rtl">
  <NavigationMenu aria-label="Main navigation">
    <NavigationMenu.List>...</NavigationMenu.List>
  </NavigationMenu>
</div>
```

### Custom links

Use `linkRender` for a router's link component. Forward the supplied attributes, events, children, object style, and ref to the anchor.

```tsx
<NavigationMenu.Link linkRender={RouterLink} href="/components/button">
  Button
</NavigationMenu.Link>
```

### Keyboard interaction

- **Trigger list**: arrow keys along the list axis move focus without opening a panel. Home and End focus the first and last enabled navigation controls. Enter and Space activate a trigger.
- **Opening panels**: ArrowDown opens a horizontal menu and enters its content; ArrowRight does the same for a vertical LTR menu, and ArrowLeft for RTL.
- **Inside panels**: Tab and Shift+Tab preserve focus order between the trigger, its portaled content, and the next navigation control. Arrow keys and Home/End move between panel links, while inputs retain their editing keys.
- **Dismissal**: Escape closes the panel and returns focus to its trigger. Outside click and focus close the panel without stealing focus from the destination.
