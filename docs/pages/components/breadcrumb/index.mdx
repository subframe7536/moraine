## Usage

Use Breadcrumb to show where a resource sits in a navigation hierarchy. Keep ancestor destinations
as links and render the current page as a non-link item. For in-page section switching, use
[Tabs](/components/tabs) instead.

```tsx
import { Breadcrumb } from 'moraine'

export function Example() {
  return <Breadcrumb items={[{ label: 'Home', href: '/' }, { label: 'Settings' }]} />
}
```

### Items and current page

Use `href` for navigable ancestors, with `target`, `rel`, and `onClick` as needed. The last item is
the current page by default; set `active` on another item to mark it instead (the first `active` item
wins). The current page renders as a `span` with `aria-current="page"`. Disabled ancestors render
without `href` or `onClick` and expose `aria-disabled="true"`. `disabled` has no effect on the
current page.

```tsx
<Breadcrumb
  items={[
    { label: 'Home', href: '/' },
    { label: 'Components', href: '/button' },
    { label: 'Breadcrumb' },
  ]}
/>
```

```tsx
<Breadcrumb
  items={[
    { label: 'Home', href: '/', icon: 'i-lucide:home' },
    { label: 'Private workspace', href: '/workspace', disabled: true },
    { label: 'Activity', active: true },
    { label: 'Archived' },
  ]}
/>
```

`separator` accepts an icon name, an element, or a component, and defaults to `icon-chevron-right`.
It is hidden from assistive technology. `wrap` (default `true`) lets a long trail break onto extra
lines in a narrow column; with `wrap={false}`, the trail stays on one line and clips any overflow.
The `<nav>` is labeled `breadcrumb` by default. Set `aria-label`, or `translations={{ label }}`, to
change it.

Pass `itemRender` to replace each item's link or page element, for example with a router link. The
component receives `{ item, index, current, disabled }` and is responsible for `aria-current` and
disabled handling.

```tsx
<Breadcrumb
  items={items}
  itemRender={(ctx) => (
    <A href={ctx.item.href ?? '#'} aria-current={ctx.current ? 'page' : undefined}>
      {ctx.item.label}
    </A>
  )}
/>
```
