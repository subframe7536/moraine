## Usage

Use Breadcrumb to show where a resource sits in a navigation hierarchy. Keep ancestor destinations
as links and render the current page as a non-link item. For in-page section switching, use
[Tabs](/components/tabs) instead.

```tsx
import { Breadcrumb } from 'moraine'

export function Example() {
  return <Breadcrumb items={[{ label: 'Home', href: '/' }, { label: 'Settings' }]} />
}
```

### Items and current page

Use `href` or `to` for navigable ancestors. The last item is the current page by default; set
`active` to mark another item instead. The current page renders as a `span` with
`aria-current="page"`. Disabled ancestors stay non-interactive and expose `aria-disabled="true"`.

```tsx
<Breadcrumb
  items={[
    { label: 'Home', href: '/' },
    { label: 'Components', href: '/button' },
    { label: 'Breadcrumb' },
  ]}
/>
```

```tsx
<Breadcrumb
  items={[
    { label: 'Home', href: '/', icon: 'i-lucide:home' },
    { label: 'Private workspace', href: '/workspace', disabled: true },
    { label: 'Activity', active: true },
    { label: 'Archived' },
  ]}
/>
```

`separator` accepts an icon name or a render function. `wrap` lets a long trail break onto extra
lines in a narrow column.
