## Usage

Use Tabs to switch between peer panels while staying in the same page context. Use navigation links
when each destination needs its own URL and document state. Use [Stepper](/components/stepper) for a
fixed sequence. Use [NavigationMenu](/components/navigation-menu) for website destinations with
expandable panels.

```tsx
import { Tabs } from 'moraine'

export function Example() {
  return <Tabs items={[{ value: 'account', label: 'Account', content: 'Profile settings' }]} />
}
```

### Selected value

Use `value` with `onValueChange` for controlled tabs, or `defaultValue` for an initial local selection.
Disabled items are skipped during selection and keyboard navigation.

For JSX panel content, use an item `content` getter. Tabs reads it lazily, so a panel is built only
when its tab is selected. This matters in SSR and MDX, where building an unselected panel eagerly
can emit markup the hydrated tree does not expect.

```tsx
<Tabs
  value={tab()}
  onValueChange={setTab}
  items={[
    {
      value: 'overview',
      label: 'Overview',
      get content() {
        return <OverviewPanel />
      },
    },
  ]}
/>
```

### Activation and keyboard navigation

`activationMode="automatic"` selects a tab as arrow navigation moves focus. In manual mode, arrows
move focus and Enter or Space selects. `loop` wraps navigation at the first and last enabled items.
Arrow keys follow the list orientation.

```tsx
<Tabs items={TABS} activationMode="automatic" defaultValue="overview" />
<Tabs items={TABS} activationMode="manual" defaultValue="overview" />
```

| Key                                 | Description                                          |
| ----------------------------------- | ---------------------------------------------------- |
| <kbd>Arrow keys</kbd>               | Moves focus among enabled tabs by orientation.       |
| <kbd>Home</kbd> / <kbd>End</kbd>    | Moves focus to the first or last enabled tab.        |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused tab in manual mode.            |
| <kbd>Tab</kbd>                      | Leaves the tab list according to normal focus order. |
