Portal owns the mounted Overlay and Content subtree and preserves it through exit motion.

## Usage

Use BaseDialog when you compose trigger, backdrop, and content yourself. [Dialog](/components/dialog),
[Sheet](/components/sheet), and [Drawer](/components/drawer) wrap this primitive; their Content parts
include a Portal internally.

- Use [Dialog](/components/dialog) for a structured title, description, body, and footer.
- Use [Sheet](/components/sheet) or [Drawer](/components/drawer) for a panel from a viewport edge.
- Use [Popover](/components/popover) for anchored interactive content.

```tsx
import { Button, BaseDialog } from 'moraine'

export function Example() {
  return (
    <BaseDialog>
      <BaseDialog.Trigger as={Button}>Open</BaseDialog.Trigger>
      <BaseDialog.Portal>
        <BaseDialog.Overlay />
        <BaseDialog.Content aria-label="Details">
          Modal content
          <BaseDialog.Close as={Button}>Close</BaseDialog.Close>
        </BaseDialog.Content>
      </BaseDialog.Portal>
    </BaseDialog>
  )
}
```

### Composition

Place `BaseDialog.Overlay` and `BaseDialog.Content` inside the same `BaseDialog.Portal`. The Portal mounts them
when open and keeps them present through exit animations. Without it, both parts render in place
and your application controls their mounting. One root owns one active Content; use a nested
BaseDialog root for a second surface.

To scroll content taller than the viewport inside the backdrop, set `scrollable` on `BaseDialog.Overlay`
and nest `BaseDialog.Content` inside it. To render without a backdrop, omit `BaseDialog.Overlay`.

```tsx
<BaseDialog>
  <BaseDialog.Trigger as={Button}>Open</BaseDialog.Trigger>
  <BaseDialog.Portal>
    <BaseDialog.Overlay />
    <BaseDialog.Content aria-label="Custom surface">
      {(context) => (
        <div>
          Custom surface
          <Button onClick={context.close}>Close</Button>
        </div>
      )}
    </BaseDialog.Content>
  </BaseDialog.Portal>
</BaseDialog>
```

`BaseDialog.Content` children may be JSX or a function that receives `close`. Give `BaseDialog.Content` an
accessible name with `aria-label` or `aria-labelledby`.

### Focus and dismissal

`modal` defaults to `true`: focus stays inside the surface, outside content is hidden from assistive
technology, and native outside pointer actions are prevented. Closing restores focus to the trigger.

Use `initialFocus` to choose the element that receives focus on open, or `false` to skip the move,
and `finalFocus` to choose where focus returns. Both apply only while `modal` is `true`.

Setting `modal={false}` allows focus to leave, but Escape and outside interactions still request
closure. `closeOnOutsideClick` controls outside pointer dismissal and `closeOnEscape` controls
Escape. Both default to `true`; a `false` value blocks that gesture and reports it through
`onClosePrevented`.

`preventScroll` locks body scroll and defaults to the value of `modal`. To allow background page
interaction, set `modal={false}` and omit `BaseDialog.Overlay`.

### Styling and portal

The root renders no element. Apply `class` and object `style` to rendered parts; root `classes`
and `styles` set their slot defaults. See [Customization](/docs/customization#the-4-layer-override-hierarchy).

Set root `mount` for a chosen container, including controlled surfaces without a Trigger.
`BaseDialog.Portal mount` overrides that default.

### Exit lifecycle

Use `open` with `onOpenChange` for controlled visibility. `onExitComplete` waits for the overlay
and content exit animations to finish. Root `transition={false}` skips those animations, so the
surfaces unmount as soon as the modal closes and `onExitComplete` runs at once.

```tsx
<BaseDialog open={open()} onOpenChange={setOpen} onExitComplete={() => setLog('Exit complete')}>
  <BaseDialog.Portal>
    <BaseDialog.Overlay />
    <BaseDialog.Content aria-label="Lifecycle">
      {(context) => <Button onClick={context.close}>Dismiss</Button>}
    </BaseDialog.Content>
  </BaseDialog.Portal>
</BaseDialog>
```

### Keyboard interaction

| Key                    | Description                                             |
| ---------------------- | ------------------------------------------------------- |
| <kbd>Escape</kbd>      | Requests dismissal when `closeOnEscape` is not `false`. |
| <kbd>Tab</kbd>         | Moves focus forward within the modal focus scope.       |
| <kbd>Shift + Tab</kbd> | Moves focus backward within the modal focus scope.      |
