Configure [UnoCSS](/styling/unocss) or [Tailwind CSS v4](/styling/tailwind) before rendering components. Both integrations generate Moraine's utility classes from the published package; Moraine does not ship precompiled component CSS.

Use [Design](/styling/design) to set the CSS variables Moraine reads, inspect z-index values, and browse all built-in icons. [Animations](/styling/animations) covers duration variables. [Override component styles](/styling/overrides) shows where to apply classes and inline styles. [Advanced](/styling/advanced) covers class merging, Themes, Providers, and how overrides combine.
