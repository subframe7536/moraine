Moraine exports a suite of headless interaction engines, reactive primitives, and low-level utilities from the dedicated `moraine/utils` entry point. These helpers power Moraine's internal components and are available for building custom primitives and bespoke UI controls.

## Import

Import headless helpers directly from the dedicated subpath:

```tsx
import {
  createBaseSelectSearchInput,
  createControllableValue,
  createDisclosureState,
  createEventListener,
  createEventListenerMap,
  createId,
  createMediaQuery,
  createSelectableCollectionNavigation,
  createSlider,
  createTransitionPresence,
} from 'moraine/utils'
```

Styling helpers such as `cn`, `createCn`, and `useCn` are exported from both `moraine` and `moraine/utils`.

## Headless Hooks

Moraine provides dedicated, headless interaction hooks that implement robust accessible keyboard, pointer, and state behaviors:

- [createControllableValue](/hooks/create-controllable-value) - Bridge controlled and uncontrolled component state with a single reactive accessor and setter pair.
- [createDisclosureState](/hooks/create-disclosure-state) - Manage disclosure lifecycle, expanded attributes, and measured content heights.
- [createEventListener](/hooks/create-event-listener) - Type-safe DOM event listeners with automatic lifecycle cleanup.
- [createId](/hooks/create-id) - Generate stable, SSR-safe identifiers for accessibility attributes.
- [createMediaQuery](/hooks/create-media-query) - Reactive boolean accessors from CSS media query strings.
- [createSelectableCollectionNavigation](/hooks/create-selectable-collection-navigation) - Keyboard roving navigation for menus, listboxes, and collections.
- [createSlider](/hooks/create-slider) - Pointer capture, keyboard stepping, and thumb position math for sliders.
- [createTransitionPresence](/hooks/create-transition-presence) - Keep elements mounted during CSS exit animations.
- [createBaseSelectSearchInput](/hooks/create-base-select-search-input) - Type-ahead and search input binding for select primitives.

Browse the full collection in the [Hooks](/hooks) catalog.
