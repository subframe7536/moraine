## Import

```tsx
import { InputNumber } from 'moraine'
import type { InputNumberT } from 'moraine'
```

Use InputNumber for a numeric field with step controls and constrained committed values. Choose a plain [Input](/input) when free-form numeric text is required.

## Anatomy

```text
root (horizontal layout)
├── decrement (optional)
├── input
└── increment (optional)
```

### Vertical layout

```text
root (vertical layout)
├── input
└── controls (optional)
    ├── increment (optional)
    └── decrement (optional)
```

The input is the spinbutton keyboard target. Vertical controls appear when either step button is shown. The increment and decrement buttons can repeat while pressed.

## Usage

### Values and boundaries

Use `rawValue` with `onRawValueChange` when numeric state is application-owned; `value` and `onChange` expose the locale-formatted string. The component preserves partial typed input until commit, then applies `minValue` and `maxValue`. Decimal steps are calculated to avoid typical floating-point display noise.

<Preview path="./boundaries" />

### Stepping and repeat

`step` controls increment and decrement buttons, while `largeStep` controls PageUp and PageDown. Hold-to-repeat is enabled by default and can be tuned with the repeat timing props.

<Preview path="./stepping" />

### Keyboard interaction

| Key                  | Description                                             |
| -------------------- | ------------------------------------------------------- |
| <kbd>ArrowUp</kbd>   | Increments the value by `step`.                         |
| <kbd>ArrowDown</kbd> | Decrements the value by `step`.                         |
| <kbd>PageUp</kbd>    | Increments by `largeStep` (defaults to `step * 10`).    |
| <kbd>PageDown</kbd>  | Decrements by `largeStep` (defaults to `step * 10`).    |
| <kbd>Home</kbd>      | Sets the value to `minValue` when a minimum is defined. |
| <kbd>End</kbd>       | Sets the value to `maxValue` when a maximum is defined. |
| <kbd>Enter</kbd>     | Commits the current text input as a numeric value.      |
