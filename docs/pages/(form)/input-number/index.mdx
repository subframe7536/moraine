## Features

- **Boundary Clamping & Step Snapping**: Enforces `min`, `max`, and `step` values, automatically rounding to clean decimal precisions upon blur.
- **Horizontal & Vertical Stepper Modes**: Display decrement/increment buttons inline on left/right edges (`horizontal`) or stacked in a compact right rail (`vertical`).
- **Continuous Long-Press Acceleration**: Hold down the plus or minus buttons to smoothly and rapidly increment/decrement the numeric counter.
- **WAI-ARIA Spinbutton Pattern**: Full accessibility support with `role="spinbutton"`, `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`.
- **Keyboard Arrow Stepping**: Arrow keys increment and decrement with modifier key acceleration (`Shift` for 10x step).

## Anatomy

Hierarchical slot and element structure:

### Horizontal layout

```text
root
├── decrement (decrease button on left)
├── input (numeric HTML input)
└── increment (increase button on right)
```

### Vertical layout

```text
root
├── input (numeric HTML input)
└── controls (stepper rail on right)
    ├── increment (stacked increase button)
    └── decrement (stacked decrease button)
```

- `root`: Container wrapper applying border, variant styling, and focus outline.
- `input`: The text entry area with numeric regex formatting.
- `increment` / `decrement`: Interactive stepper buttons with long-press repeat handlers.

## Keyboard Interactions

| Key                          | Description                                  |
| ---------------------------- | -------------------------------------------- |
| <kbd>ArrowUp</kbd>           | Increments the numeric value by `step`.      |
| <kbd>ArrowDown</kbd>         | Decrements the numeric value by `step`.      |
| <kbd>Shift + ArrowUp</kbd>   | Increments by 10 × `step` for large jumps.   |
| <kbd>Shift + ArrowDown</kbd> | Decrements by 10 × `step`.                   |
| <kbd>Home</kbd>              | Sets value to `min` if defined.              |
| <kbd>End</kbd>               | Sets value to `max` if defined.              |
| <kbd>PageUp</kbd>            | Steps up by a larger interval (10 × step).   |
| <kbd>PageDown</kbd>          | Steps down by a larger interval (10 × step). |
