## Playground

<Playground
  controls={[
    {
      kind: 'select',
      prop: 'variant',
      label: 'Variant',
      defaultValue: 'default',
      options: [
        { label: 'Default', value: 'default' },
        { label: 'Bold', value: 'bold' },
      ],
    },
    {
      kind: 'select',
      prop: 'size',
      label: 'Size',
      defaultValue: 'md',
      options: [
        { label: 'Small', value: 'sm' },
        { label: 'Medium', value: 'md' },
        { label: 'Large', value: 'lg' },
      ],
    },
    { kind: 'switch', prop: 'disabled', label: 'Disabled', defaultValue: false },
    { kind: 'switch', prop: 'inverted', label: 'Inverted', defaultValue: false },
  ]}
>
  {(props) => {
    const [value, setValue] = createSignal(65)

    return (
      <div class="space-y-3">
        <div class="text-xs text-muted-foreground flex items-center justify-between">
          <span>Volume level</span>
          <span class="text-foreground font-medium font-mono">{value()}%</span>
        </div>
        <Slider
          value={value()}
          onValueChange={(val) => {
            if (typeof val === 'number') {
              setValue(val)
            }
          }}
          variant={props.variant}
          size={props.size}
          disabled={props.disabled}
          inverted={props.inverted}
        />
      </div>
    )

}}

</Playground>

## Slot Structure

Track with a fill range and one or more draggable thumb handles.

```text
root
├── track
│   ├── range
│   └── divider (optional ×n)
└── thumb (×n)
```
