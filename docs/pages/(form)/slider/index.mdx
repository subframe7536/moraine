import { Slider } from '@src'
import { createSignal } from 'solid-js'

## Import

```tsx
import { Slider } from 'moraine'
import type { SliderT } from 'moraine'
```

Use Slider when a numeric value or range is best chosen spatially. Pair it with a labeled numeric field when users need precise text entry.

## Usage

### Single values and ranges

Use a scalar value for a single thumb and an ordered pair for a range. Pair `value` with `onChange` for controlled state; `onValueChange` is useful when the application needs immediate updates during drag.

<Preview path="./values" />

### Step and markers

Set `step` to snap pointer drag and keyboard navigation to fixed increments. Enable `marker` to render visual tick marks at each step interval across the track rail.

<Preview path="./step-marker" />

### Keyboard and forms

The thumb supports keyboard stepping, including page-sized increments. Add a `name` for native form participation or use `Field` when the slider belongs to a Formisch store.

<Preview path="./keyboard-forms" />

### Keyboard interaction

When `step` is omitted, keyboard stepping defaults to 1% of the configured range. Page-sized movement is approximately 10% of the range and is snapped to `step` when one is defined.

| Key                                         | Description                                             |
| ------------------------------------------- | ------------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowUp</kbd>  | Moves in the increasing direction by one keyboard step. |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowDown</kbd> | Moves in the decreasing direction by one keyboard step. |
| <kbd>Shift + Arrow</kbd>                    | Moves by the page-sized increment.                      |
| <kbd>PageUp</kbd> / <kbd>PageDown</kbd>     | Moves by the page-sized increment.                      |
| <kbd>Home</kbd>                             | Moves the focused thumb to its minimum permitted value. |
| <kbd>End</kbd>                              | Moves the focused thumb to its maximum permitted value. |
