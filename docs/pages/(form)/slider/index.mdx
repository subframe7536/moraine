## Features

- **Single & Dual Thumb Range Selection**: Supports scalar numeric values as well as `[min, max]` intervals with collision gap controls.
- **Horizontal & Vertical Orientations**: Use standard horizontal layout or switch to vertical faders for equalizers and audio mixer consoles.
- **Step Intervals & Visual Dividers**: Enable `divider` ticks along the track matching configured `step` intervals.
- **Inverted Direction Flow**: Flip value direction with `inverted` (e.g. right-to-left or top-to-bottom).
- **WAI-ARIA Slider Compliance**: Implements `role="slider"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, and full keyboard navigation.

## Anatomy

Hierarchical slot and element structure:

```text
root (slider track container)
├── track (background rail)
│   ├── range (active colored fill highlight)
│   └── divider (step tick markers ×n, optional)
└── thumb (draggable handle ×n)
```

- `root`: The touch/pointer tracking surface managing coordinate offsets.
- `track`: The inactive background bar.
- `range`: The colored segment indicating active progress.
- `thumb`: Focusable circular handle with active elevation and focus ring.

## Keyboard Interactions

| Key                                         | Description                                          |
| ------------------------------------------- | ---------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowUp</kbd>  | Increments the thumb value by `step`.                |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowDown</kbd> | Decrements the thumb value by `step`.                |
| <kbd>Shift + ArrowRight</kbd>               | Increments by a 10× step jump.                       |
| <kbd>Shift + ArrowLeft</kbd>                | Decrements by a 10× step jump.                       |
| <kbd>Home</kbd>                             | Snaps the focused thumb to the slider's `min` bound. |
| <kbd>End</kbd>                              | Snaps the focused thumb to the slider's `max` bound. |
| <kbd>PageUp</kbd> / <kbd>PageDown</kbd>     | Steps by a large interval (10× step).                |
