## Import

```tsx
import { Combobox } from 'moraine'
import type { ComboboxT } from 'moraine'
```

## Features

- **Independent value and query**: Query text filters options; only an option commit sets the selected value.
- **Single focus owner**: The editable input retains focus, combobox ARIA roles, and keyboard interaction.
- **Explicit secondary trigger**: The trailing button always exists and toggles the popup without stealing input focus.
- **Collection rendering**: Supports groups, custom items, filter strategies, external search, and virtualization.

## Anatomy

```text
control
├── leading (optional)
├── input
├── clear (optional)
└── trigger
```

Control is the visual field and floating anchor. Input is the sole combobox ARIA and focus owner.
Trigger is an always-present secondary button with `tabIndex={-1}` that toggles the dropdown without
creating competing focus targets.

## Usage

### Value and query

While open, the input displays the query; while closed, it displays the selected item label.
Arbitrary query text is never committed as a value. Use `value` / `onChange` for selection and
`searchValue` / `onSearch` for query text.

<Preview path="./usage-query" />

### Pointer opening

By default, clicking inside the input focuses the field without opening the popup immediately. The trailing
chevron button toggles the dropdown, while typing or pressing ArrowDown opens it. Set `openOnControlClick={true}`
if you want any click on the field to open the options list.

<Preview path="./explicit-trigger" />

### Keyboard interaction

| Key                 | Behavior                                                                    |
| ------------------- | --------------------------------------------------------------------------- |
| ArrowDown / ArrowUp | Open the popup or navigate through matched options                          |
| Enter               | Commit the currently highlighted option                                     |
| Escape              | Revert query text or close the dropdown                                     |
| Home / End          | Move text cursor within input (or navigate options when listbox is focused) |
