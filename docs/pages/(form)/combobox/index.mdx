
## Features

- **Independent value and query**: Query text filters; only an option commits a value.
- **One focus owner**: The editable input owns combobox ARIA and keyboard interaction.
- **Explicit secondary trigger**: The trailing button always exists and toggles the popup.
- **Collection rendering**: Supports groups, external filtering, custom items, and virtualization.

## Anatomy

```text
control
├── leading (optional)
├── input
├── clear (optional)
└── trigger
```

Control is the visual field and floating anchor. Input is the only combobox ARIA and focus owner.
Trigger is an always-present secondary button with `tabIndex={-1}`; it toggles without creating a
second combobox focus model.

## Usage

### Value and query

<Preview path="./basic" />

While open, the input displays the query; while closed, it displays the selected item label.
Arbitrary query text is never committed. Use `value` / `onChange` for selection and `searchValue` /
`onSearch` for query state.

### Controlled query and external filtering

<Preview path="./controlled-query" />

### Pointer opening

By default, ordinary input/control pointer clicks do not open the popup. The secondary trigger
still toggles, while typing and ArrowDown/ArrowUp still open normally. Set `openOnControlClick={true}`
to open on control click.
