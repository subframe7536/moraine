## Import

```tsx
import { Combobox } from 'moraine'
import type { ComboboxT } from 'moraine'
```

Use Combobox when users should type to find one item in a collection. Use [Select](/select) for a non-editable choice and [MultiSelect](/multi-select) for multiple collection values.

## Anatomy

```text
control
├── leading (optional)
├── input
├── clear (optional)
└── trigger
content (portaled while open)
└── listbox
    ├── group / groupLabel (optional)
    ├── item (×n)
    └── empty (optional)
```

Control is the visual field and floating anchor. Input is the sole combobox ARIA and focus owner.
Trigger is an always-present secondary button with `tabIndex={-1}` that toggles the dropdown without
creating competing focus targets.

Combobox renders the popup collection internally. Its content, listbox, and item names are style slots; customize item output with `itemRender` rather than composing attached child parts.

## Usage

### String items

Pass strings when the label and value are identical. Strings and objects can be mixed at the
root or inside a group. Whitespace is preserved, and an empty string is a valid value.

<Preview path="./string-items" />

String items are converted to the same item shape used by callbacks: `'Apple'` becomes
`{ value: 'Apple', label: 'Apple' }`. Object items retain their identity and custom fields.
`ComboboxT.NormalizedItem<TItem>` names the callback item type. Duplicate values use the first
occurrence, including collisions between strings and objects.

### Value and query

`value` is the selected item's value, or `null` when nothing is selected. Leave it undefined to use
uncontrolled selection with `defaultValue`. An empty string remains a valid item value. The exact
selection type is `ComboboxT.NormalizedItem<TItem>['value'] | null`, which `onChange` receives.

While open, the input displays the query; while closed, it displays the selected item label.
Arbitrary query text is never committed as a value. Use `value` / `onChange` for selection and
`searchValue` / `onSearch` for query text.

<Preview path="./usage-query" />

### Pointer opening

By default, clicking inside the input focuses the field without opening the popup immediately. The trailing
chevron button toggles the dropdown, while typing or pressing ArrowDown opens it. Set `openOnControlClick={true}`
if you want any click on the field to open the options list.

<Preview path="./explicit-trigger" />

### Keyboard interaction

| Key                 | Behavior                                                                    |
| ------------------- | --------------------------------------------------------------------------- |
| ArrowDown / ArrowUp | Open the popup or navigate through matched options                          |
| Enter               | Commit the currently highlighted option                                     |
| Escape              | Revert query text or close the dropdown                                     |
| Home / End          | Move text cursor within input (or navigate options when listbox is focused) |
