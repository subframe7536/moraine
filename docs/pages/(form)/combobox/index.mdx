## Import

```tsx
import { Combobox } from 'moraine'
import type { ComboboxT } from 'moraine'
```

Combobox keeps the committed value and query independent. While open, the input displays the query;
while closed, it displays the selected item label. Arbitrary query text is never committed.

## Anatomy

```text
control
├── leading (optional)
├── input
├── clear (optional)
└── trigger
```

Control is the visual field and floating anchor. Input is the only combobox ARIA and focus owner.
Trigger is an always-present secondary button with tabIndex={-1}; it toggles without creating a
second combobox focus model.

## Explicit pointer trigger

With openOnControlClick={false}, ordinary input/control pointer clicks do not open the popup. The
secondary trigger still toggles, while typing and ArrowDown/ArrowUp still open normally.
