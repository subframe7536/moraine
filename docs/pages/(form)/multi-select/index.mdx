
## Features

- **Removable Tags**: Selected values render as tags with individual removal controls; Backspace removes the last tag when the text input is empty.
- **Search & Creation**: Filter options as you type and enable `creatable` when user-entered values should become new selections.
- **Token Separators**: Configured delimiter keys can convert typed text into selections.
- **Selection & Display Limits**: `maxCount` limits selected values while `maxTagCount` limits visible tags and renders an overflow summary.
- **Virtualized Rendering**: Integrates with `useListVirtualizer` for caller-configured rendering of larger option sets.
- **Floating UI Positioning**: The listbox is positioned with Floating UI.

## Usage

### Values, search, and creation

The value is an array of selected option values. Control it with `value` and `onChange` when the application owns selection. Search state and creation behavior are separate from selection; token separators can turn pasted text into multiple values when the relevant options are enabled.

### Large option sets

Use groups to organize options and virtualization when rendering a large, stable list. Limits such as maximum selected values and displayed tags constrain selection or presentation; see the API reference for the individual limit props.

### Keyboard interaction

| Key                              | Description                                                              |
| -------------------------------- | ------------------------------------------------------------------------ |
| <kbd>ArrowDown</kbd>             | Opens the listbox or moves to the next option.                           |
| <kbd>ArrowUp</kbd>               | Moves to the previous option.                                            |
| <kbd>Enter</kbd>                 | Toggles the active option or creates a value when `creatable` allows it. |
| <kbd>Backspace</kbd>             | Removes the last selected tag when the text input is empty.              |
| <kbd>Escape</kbd>                | Closes the listbox.                                                      |
| <kbd>Home</kbd> / <kbd>End</kbd> | Moves to the first or last available option.                             |
