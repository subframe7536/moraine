## Import

```tsx
import { MultiSelect } from 'moraine'
import type { MultiSelectT } from 'moraine'
```

MultiSelect commits multiple values from a collection. It combines BaseSelect navigation,
Combobox query behavior, and tag-field editing while keeping one value owner, one query owner, one
physical input, and one form registration.

## Anatomy

```text
control
├── leading (optional)
├── tagsContainer
│   ├── tag
│   │   ├── tagLabel
│   │   └── tagRemove
│   ├── tagOverflow (optional)
│   └── input
├── clear (optional)
└── trigger
```

The trailing trigger is always a real secondary button and is never replaced by clear or loading.
Normal control clicks are open-only. Set openOnControlClick={false} to require the trailing button
for pointer opening; typing and Arrow keys still open normally.

## Editable behavior

- MultiSelect without search keeps its one input read-only and uses collection typeahead.
- search makes the input editable and filters the collection.
- createItem makes the input editable even when search is false.

createItem(input) explicitly constructs a valid TItem. MultiSelect reuses an existing canonical
item with the same value, rejects disabled or over-limit additions, then commits TItem.value.
This differs from TagsInput, which commits free-form strings directly.
