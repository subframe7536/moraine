## Import

```tsx
import { MultiSelect } from 'moraine'
import type { MultiSelectT } from 'moraine'
```

## Features

- **Collection-backed values**: Every committed value resolves through a canonical `TItem` source.
- **Interactive tag field**: Displays selected items as removable chips with optional overflow badge.
- **Optional search & creation**: `search` filters; `createItem` constructs a `TItem` for free-form input.
- **Unified tokenization**: Separators (comma, space) and paste reuse the same collection-aware creation path.
- **Separate limits**: `maxCount` limits total selections; `maxTagCount` collapses visual tags into a customizable `+N` summary.

## Anatomy

```text
control
├── leading (optional)
├── tagsContainer
│   ├── tag (×n)
│   │   ├── tagLabel
│   │   └── tagRemove
│   ├── tagOverflow (optional, renderable)
│   └── input
├── clear (optional)
└── trigger
```

The control slot wraps the interactive tags container and floating anchor. When non-editable, clicking the control opens the panel by default; when editable (`search` or `createItem`), clicking the control focuses the input without opening the panel so users can type immediately. Use `openOnControlClick` to explicitly override this default behavior.

## Usage

### Values and tag lifecycle

The committed selection is represented as an array of item values: `TItem['value'][]`.
Without `search`, printable keys trigger collection typeahead. Enabling `search={true}` allows
users to type directly in the field to filter available options.

<Preview path="./usage-tags" />

### Item creation and delimiters

Providing `createItem` transforms unmatched query text into a valid `TItem` on Enter or when a token
separator is encountered. Separator characters (like comma or space) and pasted strings are automatically
parsed through the same creation path.

<Preview path="./usage-creation" />

### Keyboard interaction

| Key                 | Behavior                                                                   |
| ------------------- | -------------------------------------------------------------------------- |
| Backspace           | When input is empty, deletes the immediately preceding tag                 |
| ArrowDown / ArrowUp | Open popup or move focus through the options list                          |
| Enter               | Commit the highlighted item (or create an item when input text is present) |
| Escape              | Close the dropdown or clear active query text                              |
