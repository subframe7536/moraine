## Features

- **Interactive Tag Badges**: Selected options render as dismissible tag chips with individual delete buttons and backspace removal.
- **Search & Tag Creation**: Typeahead search filters available options in real time. Enable `creatable` to allow on-the-fly tag generation.
- **Token Separators**: Convert input values to tags automatically upon typing configured delimiter keys (like commas or spaces).
- **Max Count & Max Tag Count**: Enforce maximum selectable values (`maxCount`) and collapse excessive visible tags into a summary badge (`maxTagCount={2}` -> `+3 more`).
- **High-Performance Virtualization**: Handles thousands of options with zero lag using TanStack Virtual integration via `useListVirtualizer`.

## Anatomy

Hierarchical slot and element structure:

### Control box

```text
control (input trigger box)
├── tagsContainer (wrap container for chips)
│   ├── tag (selected item chip ×n)
│   │   ├── label (tag name)
│   │   └── tagRemove (clear button)
│   ├── tagOverflow (summary badge "+N more")
│   └── input (inline search field)
├── clear (clear-all button, optional)
└── trigger (open/close chevron indicator)
```

### Floating Listbox (Portal)

```text
content (floating popover)
└── listbox (scrollable dropdown)
    ├── item (option row ×n)
    │   ├── itemLabel (text & icon)
    │   └── itemTrailing (check indicator)
    ├── group (optional grouped section)
    │   └── label (group heading)
    └── empty (fallback message when no results match)
```

- `control`: The main interactive container wrapping selected tags and the active typing cursor.
- `tagOverflow`: Badge displaying hidden items count when `maxTagCount` is exceeded.
- `listbox`: The floating options overlay positioning via Popper / Floating UI.

## Keyboard Interactions

| Key                              | Description                                                                   |
| -------------------------------- | ----------------------------------------------------------------------------- |
| <kbd>ArrowDown</kbd>             | Opens the listbox or highlights the next option.                              |
| <kbd>ArrowUp</kbd>               | Highlights the previous option.                                               |
| <kbd>Enter</kbd>                 | Selects / deselects the highlighted option or creates a new tag if creatable. |
| <kbd>Backspace</kbd>             | Deletes the last tag when the search input is empty.                          |
| <kbd>Escape</kbd>                | Closes the open listbox popover.                                              |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jumps highlight to the first or last available option.                        |
