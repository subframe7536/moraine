import { Button, createForm, Form, FormField, Input, Switch } from '@src'
import { Show, createSignal } from 'solid-js'
import * as v from 'valibot'

## Import

Import `Form` and `createForm` from the package root:

```tsx
import { createForm, Form, FormField, Input, Switch } from 'moraine'
import type { FormT } from 'moraine'
```

Define your schema with [Valibot](https://valibot.dev), create a reactive form store with `createForm`, and pass it to `Form`:

```tsx
export function NotificationForm() {
  const form = createForm({
    schema,
    initialInput: { email: '', enabled: false },
  })

  return (
    <Form of={form} onSubmit={(output) => console.log(output)}>
      <FormField name="email" label="Email Address">
        <Input leading="i-lucide:mail" />
      </FormField>
      <FormField name="enabled" label="Enable Notifications">
        <Switch />
      </FormField>
      <Button type="submit">Save Changes</Button>
    </Form>
  )
}
```

## Features

- **Formisch & Valibot Orchestration**: Built upon `@formisch/solid` for high-performance, fine-grained reactive form validation.
- **Contextual Store Propagation**: Child `FormField` components automatically read their values, errors, and validation states without boilerplate props.
- **Async Submission Handling**: Handles promise lifecycles, error boundaries, and auto-disabling during in-flight network requests.
- **Nested & Array Path Support**: Seamlessly validates arrays (`['members', 0, 'email']`) and deeply nested configuration objects.
- **Cascading Disabled States**: Disabling the top-level form automatically cascades to all child fields and controls.

## Anatomy

Hierarchical slot and element structure:

```text
root (HTML <form>)
└── fields (composed FormField instances)
    ├── FormField (name="email")
    │   ├── label
    │   ├── Input (reads store value)
    │   └── error (displays validation message)
    └── Button (type="submit")
```

- `root`: The `<form>` element intercepting native submit events and executing schema validations.
- `fields`: Composed `FormField` elements subscribing to the form store.

## Keyboard Interactions

| Key              | Description                                                                    |
| ---------------- | ------------------------------------------------------------------------------ |
| <kbd>Enter</kbd> | Submits the form when focused inside an `<input>` (unless multiline textarea). |
| <kbd>Tab</kbd>   | Sequentially navigates through form fields in logical DOM order.               |
