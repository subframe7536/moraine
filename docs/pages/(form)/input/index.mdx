## Features

- **Leading & Trailing Slots**: Easily embed icons, badges, dropdown triggers, copy buttons, keyboard shortcuts (`Kbd`), or currency symbols.
- **Multiple Visual Variants**: Supports `outline` (standard border), `subtle` (soft background), `ghost` (frameless inline editing), and `none` (custom container wrapping).
- **Interactive Action Enhancements**: Out-of-the-box support for password visibility eye toggles, clearable buttons, and copy-to-clipboard actions.
- **Built-in Async Loading Spinner**: Displays an animated loader in leading or trailing position during asynchronous searches or data fetching.
- **WAI-ARIA Accessibility**: Complies with native input accessibility, supporting `aria-invalid`, `aria-required`, and automatic field association.

## Anatomy

Hierarchical slot and element structure:

```text
root
├── leading (icon, text prefix, or spinner)
├── input (native HTML <input>)
└── trailing (icon, clear button, kbd shortcut, or action)
```

- `root`: Container wrapper applying border, focus ring, size height, and variant background.
- `leading`: Left adornment element aligned before the text cursor.
- `input`: The underlying native HTML `<input>` handling keyboard typing and focus.
- `trailing`: Right adornment element for interactive action buttons or indicators.

## Keyboard Interactions

| Key               | Description                                                      |
| ----------------- | ---------------------------------------------------------------- |
| <kbd>Tab</kbd>    | Moves focus to the input element or its trailing action buttons. |
| <kbd>Escape</kbd> | Clears the input when focused if clearable action is present.    |
| <kbd>Enter</kbd>  | Submits the enclosing form or triggers instant search.           |
