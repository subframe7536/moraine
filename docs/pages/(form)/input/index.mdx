## Import

```tsx
import { Input } from 'moraine'
import type { InputT } from 'moraine'
```

Use Input for native single-line text editing. Compose it with [Field](/field) for a label and validation message, or [InputGroup](/input-group) for adjacent controls.

## Anatomy

```text
root (native <input>)
```

`ref`, `class`, `style`, `classes.root`, and `styles.root` target the native input. Put container styling and refs on `InputGroup` when composing supporting content.

## Usage

### Native input behavior

`Input` forwards native input attributes. Use `value` with `onValueChange` for controlled text and `defaultValue` for an initial uncontrolled value. `readOnly` keeps the field focusable without allowing edits; `disabled` removes it from interaction.

<Preview path="./controlled-input" />

### Composed controls

Use `InputGroup.Leading` and `InputGroup.Trailing` for static context such as an icon or unit. Password visibility, clearing, copying, and loading remain application behavior: compose buttons and icons into these parts and provide their labels and handlers.

<Preview path="./composed-controls" />

### Keyboard interaction

`Input` keeps native input keyboard behavior. Escape-to-clear and search submission are application behavior.
