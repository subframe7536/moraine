## Features

- **Leading & Trailing Adornments**: Render icon names or custom content before or after the native input.
- **Visual Variants**: Supports `outline`, `subtle`, `ghost`, and `none` styling modes.
- **Loading Indicator**: `loading` replaces one adornment position with `loadingIcon`; it does not manage an asynchronous operation itself.
- **Composable Actions**: Add password visibility, clear, copy, or shortcut controls as caller-owned children or adjacent controls when needed.
- **FormField Integration**: Inherits field identity and state and applies generated validation/accessibility metadata to the native input.
- **Model Modifiers**: Supports value modifiers such as `trim`, `lazy`, and `number` through `modelModifiers`.

## Anatomy

```text
root
├── leading (optional)
├── input (native <input>)
├── children (optional caller content)
└── trailing (optional)
```

- `root`: Styled wrapper; pointer interaction on non-interactive wrapper space focuses the input.
- `input`: Native form control that owns text entry and focus.
- `leading` / `trailing`: Adornment slots; a loading icon can replace one of them.

## Keyboard Interactions

`Input` keeps native input keyboard behavior. Moraine does not add a built-in Escape-to-clear or search-submit shortcut.

| Key              | Description                                                               |
| ---------------- | ------------------------------------------------------------------------- |
| <kbd>Tab</kbd>   | Moves focus to the input according to normal document focus order.        |
| <kbd>Enter</kbd> | Participates in native form submission when the surrounding form allows.  |
