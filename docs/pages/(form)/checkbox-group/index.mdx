## Import

```tsx
import { CheckboxGroup } from 'moraine'
import type { CheckboxGroupT } from 'moraine'
```

Use CheckboxGroup for several choices submitted as one array. Use individual [Checkbox](/checkbox) controls when the fields are independent.

## Anatomy

```text
root (<div>)
└── fieldset
    ├── legend (optional)
    └── item (Checkbox root, ×n)
        ├── container
        │   ├── input (hidden native checkbox)
        │   └── control
        │       └── indicator (optional)
        │           └── icon
        └── wrapper (optional)
            ├── label (optional)
            └── description (optional)
```

The outer `root` owns styling and forwarded root props. The nested `<fieldset>` owns group semantics, disabled state, and the optional `<legend>` association.

## Usage

### Selection model

The group value is an array of item values. Pair `value` with `onChange` for controlled selection, or use a default value when the group owns its initial state. A disabled group disables all items; an item can also be disabled independently.

<Preview path="./selection-model" />

### Forms and keyboard behavior

The group renders a semantic fieldset and its items retain native checkbox tab order. Give it a `name` when the surrounding native form needs to participate in submission, and use `Field` for schema-bound fields.

<Preview path="./form-behavior" />

### Keyboard interaction

Each item keeps native checkbox keyboard behavior; the group does not implement radio-style roving focus.
