## Playground

<Playground
  controls={[
    {
      kind: 'select',
      prop: 'variant',
      label: 'Variant',
      defaultValue: 'card',
      options: [
        { label: 'Card', value: 'card' },
        { label: 'List', value: 'list' },
        { label: 'Table', value: 'table' },
      ],
    },
    {
      kind: 'select',
      prop: 'size',
      label: 'Size',
      defaultValue: 'md',
      options: [
        { label: 'Small', value: 'sm' },
        { label: 'Medium', value: 'md' },
        { label: 'Large', value: 'lg' },
      ],
    },
    {
      kind: 'select',
      prop: 'orientation',
      label: 'Orientation',
      defaultValue: 'vertical',
      options: [
        { label: 'Vertical', value: 'vertical' },
        { label: 'Horizontal', value: 'horizontal' },
      ],
    },
    { kind: 'switch', prop: 'disabled', label: 'Disabled', defaultValue: false },
  ]}
>
  {(props) => {
    const NOTIFICATION_OPTIONS = [
      { label: 'Email alerts', value: 'email', description: 'Weekly digests and critical updates' },
      {
        label: 'Push notifications',
        value: 'push',
        description: 'Instant alerts on mobile and desktop',
      },
      { label: 'SMS updates', value: 'sms', description: 'Security and login codes' },
    ]

    const [value, setValue] = createSignal(['email'])

    return (
      <div class="max-w-full w-96">
        <CheckboxGroup
          items={NOTIFICATION_OPTIONS}
          value={value()}
          onChange={setValue}
          variant={props.variant}
          size={props.size}
          disabled={props.disabled}
          orientation={props.orientation}
        />
      </div>
    )

}}

</Playground>

## Slot Structure

Fieldset with an optional legend grouping multiple Checkbox items.

```text
root
└── fieldset
    ├── legend (optional)
    └── root (Checkbox, ×n)
```
