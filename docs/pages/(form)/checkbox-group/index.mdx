## Features

- **Array Value Binding**: Seamlessly binds a `string[]` or `number[]` array of selected values in controlled and uncontrolled modes.
- **Card, List, and Table Variants**: Switch effortlessly between compact `list` items, interactive `card` grids, and bordered `table` rows.
- **Orientation Flow**: Supports `vertical` stacking for forms and `horizontal` layout for toolbars and filters.
- **Flexible Indicator Positioning**: Align check indicators at `start` (default), `end` (trailing toggle style), or `hidden` for button-like cards.
- **Per-Item Disable & Custom Metadata**: Individual items can be independently disabled, badged, or customized with leading icons.

## Anatomy

Hierarchical slot and element structure:

```text
root (fieldset)
├── legend (optional group title)
└── items (flex or grid container)
    └── item (individual Checkbox)
        ├── container
        │   ├── input (native hidden checkbox)
        │   └── control (styled check square)
        └── wrapper
            ├── label (item title)
            └── description (optional subtext)
```

- `root`: The outer `<fieldset>` managing semantic group role and disabled propagation.
- `legend`: Optional accessible title for the group of options.
- `items`: Layout container for stacking items according to `orientation` and `variant`.
- `item`: Composed `Checkbox` instance rendering individual option state and labels.

## Keyboard Interactions

| Key                    | Description                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| <kbd>Tab</kbd>         | Moves focus to the next checkbox item within the group.                                              |
| <kbd>Shift + Tab</kbd> | Moves focus to the previous checkbox item.                                                           |
| <kbd>Space</kbd>       | Toggles selection of the currently focused checkbox item without affecting other items in the group. |
