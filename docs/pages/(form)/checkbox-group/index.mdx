## Features

- **Array Value Binding**: Supports controlled and uncontrolled `string[]` selection values.
- **List, Card & Table Variants**: Reuses Checkbox presentation for standard lists, selectable cards, and bordered table-style rows.
- **Orientation**: Arrange grouped options vertically or horizontally.
- **Indicator Configuration**: Configure indicator placement and checked/indeterminate icons for the group.
- **Per-Item State**: Individual items can be disabled or indeterminate and can override their state icons.
- **FormField Integration**: The group propagates identity, required, disabled, and validation metadata through a semantic fieldset.

## Anatomy

```text
root (<div>)
└── fieldset
    ├── legend (optional)
    └── Checkbox item (×n)
        ├── container
        │   ├── input
        │   └── control
        └── wrapper
            ├── label
            └── description
```

The outer `root` owns styling and forwarded root props. The nested `<fieldset>` owns group semantics, disabled state, and the optional `<legend>` association.

## Keyboard Interactions

Each item keeps native checkbox keyboard behavior; the group does not implement radio-style roving focus.

| Key                    | Description                                                   |
| ---------------------- | ------------------------------------------------------------- |
| <kbd>Space</kbd>       | Toggles the focused checkbox item.                            |
| <kbd>Tab</kbd>         | Moves through enabled checkbox items in normal focus order.   |
| <kbd>Shift + Tab</kbd> | Moves backward in normal focus order.                         |
