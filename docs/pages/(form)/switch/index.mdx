## Import

```tsx
import { Switch } from 'moraine'
import type { SwitchT } from 'moraine'
```

Use Switch for an on/off setting whose state is immediately meaningful. For an independent form choice that may be part of a set, use [Checkbox](/checkbox).

```text
└── wrapper (optional)
    ├── label
    └── description
```

## Usage

### Checked state and forms

`Switch` has checkbox semantics and a hidden native input. Use `checked` with `onChange` for controlled state, or `defaultChecked` for an initial value. `trueValue` and `falseValue` map that state to domain values for form integration.

<Preview path="./state-forms" />

### Loading ownership

`loading` is visual state supplied by the application. It does not represent an asynchronous operation on its own; decide whether the switch should also be disabled while that operation is pending.
