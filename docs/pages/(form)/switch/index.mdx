## Import

```tsx
import { Switch } from 'moraine'
import type { SwitchT } from 'moraine'
```

## Features

- **Switch Semantics**: The visible control uses `role="switch"` and reflects its state through `aria-checked`.
- **Custom Thumb Icons**: `checkedIcon` and `uncheckedIcon` customize the thumb in each state.
- **Loading State**: `loading` displays the loading icon and makes the control non-interactive; asynchronous work remains caller-owned.
- **Domain Value Mapping**: `trueValue` and `falseValue` map checked state to application-specific values.
- **FormField Integration**: A hidden native checkbox participates in forms while the visible switch owns interaction and accessibility metadata.

## Usage

### Checked state and forms

`Switch` has checkbox semantics and a hidden native input. Use `checked` with `onChange` for controlled state, or `defaultChecked` for an initial value. `trueValue` and `falseValue` map that state to domain values for form integration.

### Loading ownership

`loading` is visual state supplied by the application. It does not represent an asynchronous operation on its own; decide whether the switch should also be disabled while that operation is pending.

### Keyboard interaction

The visible switch is a button, so native button activation applies.

| Key                                 | Description                                |
| ----------------------------------- | ------------------------------------------ |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Toggles the switch when it is interactive. |
| <kbd>Tab</kbd>                      | Moves focus to the visible switch control. |
