## Features

- **WAI-ARIA Switch Role**: Accessible `role="switch"` with automatic synchronization of `aria-checked` and label IDs.
- **Custom Thumb Icons**: Render distinct icons inside the moving thumb for checked (`checkedIcon`) and unchecked (`uncheckedIcon`) states (e.g. moon/sun for dark mode).
- **Built-in Async Loading Spinner**: Replaces the thumb icon with an animated loader during background async operations.
- **Domain Value Mapping**: Bind custom values like `'online'` / `'maintenance'` via `trueValue` and `falseValue` props.
- **Proportional Size Scale**: Three standard sizes (`sm`, `md`, `lg`) adjusting track radius, thumb padding, and label typography.

## Anatomy

Hierarchical slot and element structure:

```text
root (label wrapper)
├── container
│   ├── input (native hidden checkbox)
│   └── track (pill toggle background)
│       └── thumb (sliding circle)
│           ├── checkedIcon (rendered when checked)
│           └── uncheckedIcon (rendered when unchecked)
└── wrapper (optional)
    ├── label (title text)
    └── description (subtext note)
```

- `root`: Top-level interactive label container.
- `track`: The pill background transitioning color upon toggle.
- `thumb`: Smoothly animated circle handle with optional icons.

## Keyboard Interactions

| Key                                 | Description                                             |
| ----------------------------------- | ------------------------------------------------------- |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Toggles the switch state between checked and unchecked. |
| <kbd>Tab</kbd>                      | Moves focus to the switch element.                      |
