## Features

- **Fluid Auto-Resize**: Automatically expands height as the user types, eliminating awkward internal scrollbars.
- **Row Clamping**: Enforce minimum (`minRows`) and maximum (`maxRows`) height limits to prevent unbounded growth.
- **Header & Footer Composability**: Embed rich formatting toolbars in `header` and submit buttons, character counters, or markdown badges in `footer`.
- **Multiple Visual Styles**: Supports `outline`, `subtle`, `ghost`, and `none` variants for inline scratchpads, code reviews, and cards.
- **WAI-ARIA Accessibility**: Standard multi-line textbox accessibility, integrating seamlessly with `FormField` labels and validation errors.

## Anatomy

Hierarchical slot and element structure:

```text
root (outer container)
├── header (optional formatting toolbar)
├── input (native HTML <textarea>)
└── footer (optional submit button & counter)
```

- `root`: Container wrapper applying border, focus ring, and variant styling.
- `header`: Slot positioned above the text area (e.g. for markdown formatting buttons).
- `input`: The multi-line text input with dynamic height calculation.
- `footer`: Slot positioned below the text area (e.g. for character count or action buttons).

## Keyboard Interactions

| Key                                      | Description                                                                         |
| ---------------------------------------- | ----------------------------------------------------------------------------------- |
| <kbd>Enter</kbd>                         | Inserts a new line character in the textarea.                                       |
| <kbd>Cmd</kbd> / <kbd>Ctrl + Enter</kbd> | Standard convention for submitting the enclosing form or comment composer.          |
| <kbd>Tab</kbd>                           | Moves focus to the next focusable element (or inserts indentation when configured). |
