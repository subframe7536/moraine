## Features

- **Auto Resize**: `autoResize` grows the textarea with its content instead of keeping a fixed-height internal scroll area.
- **Row Limits**: Use `minRows` and `maxRows` to bound auto-resized height.
- **Header & Footer Content**: Compose formatting controls, counters, badges, or action buttons around the native textarea.
- **Visual Variants**: Supports `outline`, `subtle`, `ghost`, and `none`.
- **FormField Integration**: Uses the field context for identity, disabled/required state, validation metadata, and label/error associations.

## Usage

### Native text behavior

`Textarea` forwards native textarea attributes and works with controlled or uncontrolled values. Use `readOnly` to preserve selection and focus without edits, or `disabled` to prevent interaction.

### Size and composition

Enable autoresize and constrain it with `minRows` and `maxRows`. Header and footer regions are composition slots; counters, submit buttons, and keyboard shortcuts remain application-owned behavior.

### Keyboard interaction

Textarea preserves native keyboard behavior. Submit shortcuts such as Cmd/Ctrl+Enter and custom Tab indentation are application-level behaviors that callers can implement when needed.

| Key              | Description                                                                    |
| ---------------- | ------------------------------------------------------------------------------ |
| <kbd>Enter</kbd> | Inserts a line break in the textarea.                                          |
| <kbd>Tab</kbd>   | Moves focus according to normal browser behavior unless handled by the caller. |
