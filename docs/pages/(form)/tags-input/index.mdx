## Import

```tsx
import { TagsInput } from 'moraine'
import type { TagsInputT } from 'moraine'
```

## Features

- **Free-form strings**: Enter commits the trimmed draft directly.
- **Tokenization and paste**: Configured separators split complete values safely.
- **Tag keyboard behavior**: Backspace, arrow movement, and removal stay input-focused.
- **Direct reachability**: Every committed tag remains visible; there is no overflow summary.

## Anatomy

```text
control
├── leading (optional)
├── tagsContainer
│   ├── tag
│   │   ├── tagLabel
│   │   └── tagRemove
│   └── input
└── clear (optional)
```

All committed tags stay directly reachable. TagsInput has no `maxTagCount`, `tagOverflow`,
collection, listbox, popup, or trigger behavior.

Enter commits the trimmed draft. Configured token separators commit completed tokens, paste splits
using the same separators, duplicates are ignored, and partial IME composition is never submitted.
