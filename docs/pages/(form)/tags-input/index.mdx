## Import

```tsx
import { TagsInput } from 'moraine'
import type { TagsInputT } from 'moraine'
```

TagsInput commits free-form strings directly. It does not own collection items, filtering, a
listbox, a popup, item creation, or virtual rendering.

## Anatomy

```text
control
├── leading (optional)
├── tagsContainer
│   ├── tag
│   │   ├── tagLabel
│   │   └── tagRemove
│   └── input
└── clear (optional)
```

All committed tags stay directly reachable. TagsInput has no maxTagCount or tagOverflow behavior.

## Separators and paste

Enter commits the trimmed draft. Configured token separators commit completed tokens, paste splits
using the same separators, duplicates are ignored, and partial IME composition is never submitted.
