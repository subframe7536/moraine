## Import

```tsx
import { Field, Input } from 'moraine'
import type { FieldT } from 'moraine'
```

`Field` is a standalone presentational component with no form validation or form integration.
It is used only for rendering field UI, registering controls, inheriting state, and establishing ARIA relationships.

For form integration, use `form.Field` returned by `createForm()`.

## Features

- **Standalone by Default**: Works without `createForm()` or any form store.
- **Accessible Associations**: Connects labels, descriptions, help text, and errors to registered controls.
- **Inherited State**: Child Moraine controls inherit `size`, `required`, `disabled`, and `readOnly` unless explicitly overridden.
- **Flexible Messages**: Supports `description`, `hint`, `help`, and explicit `error` content.
- **Layouts**: Supports vertical and horizontal field presentation.
- **Control Agnostic**: Works with text inputs and non-text controls that participate in Field context.

## Anatomy

```text
root
├── wrapper
│   ├── labelWrapper
│   │   ├── label
│   │   └── hint
│   └── description
└── container
    ├── control content
    ├── help
    └── error
```
