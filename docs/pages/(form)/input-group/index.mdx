## Import

```tsx
import { Input, InputGroup, Textarea } from 'moraine'
import type { InputGroupT } from 'moraine'
```

## Anatomy

```text
InputGroup (root)
├── InputGroup.Leading (leading slot, repeat as needed)
├── Input or Textarea (independent native control, root slot)
└── InputGroup.Trailing (trailing slot, repeat as needed)
```

Place zero or more `Leading` parts first, then one `Input` or `Textarea`, then zero or more `Trailing` parts. `orientation` belongs to `InputGroup` and determines whether all parts sit beside or above/below the control. `Leading` and `Trailing` accept `compact` to remove the gap beside the control. Both parts accept ordinary JSX, including `Icon`, `Button`, and `Kbd`.

## Usage

### Direction and orientation

`Leading` renders at the logical start when horizontal and above the control when vertical. `Trailing` renders at the logical end when horizontal and below the control when vertical. Horizontal positions follow the document's writing direction. Configure the orientation default or styles through `inputGroup.defaults.orientation` and `inputGroup.variants.orientation` in your theme.

<Preview path="./alignment" />

### Compact

Set `compact` on a `Leading` or `Trailing` part when its content should sit directly beside the control text. The part keeps its outer-edge padding while removing only the padding on the side that faces the control. This is useful for URL protocols, domain suffixes, currency symbols, and similar inline text.

### Styling and forms

`InputGroup` owns the shared border, background, radius, and focus/invalid/disabled appearance. Set its `size` and `variant` to style the group. The native control's `variant` applies when it is outside a group.

Size precedence is the control's explicit size, group size, FormField size, then theme defaults. `classes.leading`, `classes.trailing`, and their style equivalents set group-wide presentation; each part's `class` and `style` override it.

Keep `name`, `value`, `onValueChange`, `required`, `disabled`, `readOnly`, and ARIA attributes on the control. InputGroup does not register a form field. Clicking non-interactive group space focuses the native control; buttons and links retain their own focus behavior.
