## Features

- **Optional Search**: Enable `search` to use the combobox input for filtering and typeahead interaction.
- **Grouped Options**: Options can be organized into labeled, non-selectable groups.
- **Incremental Loading**: Use the listbox loading hooks to append options as the user reaches the end of the list.
- **Virtualized Rendering**: Integrates with `useListVirtualizer` for caller-configured virtual rendering of larger option sets.
- **Clearable Selection**: `allowClear` adds a clear action when a value is selected.
- **Combobox/Listbox Semantics**: Exposes combobox/listbox roles, expanded state, active option metadata, and keyboard navigation appropriate to the current mode.

## Anatomy

### Trigger control

```text
control
├── leading (optional)
├── input
├── clear (optional)
└── trigger
```

### Floating listbox

```text
content
└── listbox
    ├── item (×n)
    ├── group (optional ×n)
    └── empty (optional)
```

## Usage

### Value and search state

Use `value` with `onChange` for controlled selection, or a default value for local state. Search, clear affordances, grouped options, and loading are separate concerns; provide the option collection and any incremental loading behavior from your application.

<Preview path="./basic-select" />

### Large and remote collections

Virtualization is appropriate for large, stable option lists. Infinite loading should be driven by application state and deterministic loading callbacks; the component does not fetch data itself.

<Preview path="./collections" />

### Keyboard interaction

| Key                              | Description                                                    |
| -------------------------------- | -------------------------------------------------------------- |
| <kbd>Enter</kbd>                 | Opens the listbox or selects the active option.                |
| <kbd>Space</kbd>                 | Opens/selects where the current trigger/input mode permits it. |
| <kbd>ArrowDown</kbd>             | Opens the listbox or moves to the next available option.       |
| <kbd>ArrowUp</kbd>               | Moves to the previous available option.                        |
| <kbd>Home</kbd> / <kbd>End</kbd> | Moves to the first or last available option.                   |
| <kbd>Escape</kbd>                | Closes the listbox without changing the selected value.        |
| <kbd>Tab</kbd>                   | Leaves the control according to normal document focus order.   |
