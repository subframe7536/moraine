```tsx
import { Select } from 'moraine'

```

## Features

- **Optional Search**: Enable `search` to use the combobox input for filtering and typeahead interaction.
- **Grouped items**: Items can be organized into labeled, non-selectable groups.
- **Incremental Loading**: Use the listbox loading hooks to append items as the user reaches the end of the list.
- **Virtualized Rendering**: Integrates with `useListVirtualizer` for caller-configured virtual rendering of larger item sets.
- **Clearable Selection**: `allowClear` adds a clear action when a value is selected.
- **Combobox/Listbox Semantics**: Exposes combobox/listbox roles, expanded state, active option metadata, and keyboard navigation appropriate to the current mode.

## Usage

### Value and search state

Use `value` with `onChange` for controlled selection, or a default value for local state. Search, clear affordances, grouped items, and loading are separate concerns; provide the item collection and any incremental loading behavior from your application.

<Preview path="./basic-select" />

`searchValue` is the actual query, and `onSearch` reports only query changes. A searchable Select displays the selected item's label string while closed and the query while open. Closing preserves the filtered options throughout the exit animation; the query resets to `''` only after exit completes. Selecting an item never publishes its label through `onSearch`.

Select owns source items, grouping, filtering, and canonical value lookup. Its value API remains `TItem['value'] | null`. Missing selected items display `String(value)` until the canonical item arrives.

Item values must be unique within a Select collection. Duplicate values are invalid consumer input.

### Complete item types

The generic parameter is the full item type. Custom fields remain available to filtering, rendering, text resolution, and virtualization:

```tsx
interface UserItem extends SelectT.Item<string> {
  department: string
}

function User() {
  return (
    <Select<UserItem>
      items={users}
      filterItem={(query, item) => item.department.includes(query)}
      itemRender={({ item }) => (
        <span>
          {item.label} — {item.department}
        </span>
      )}
    />
  )
}
```

Grouped input keeps the `{ type: 'group', label, items }` discriminator. `SelectT.Group<UserItem>` and `SelectT.Entry<UserItem>` preserve the full item type. Normal and virtual content share `SelectT.Row<UserItem>`; virtual `scrollToItem` receives the original item and its row index.

### Read-only selection

Use `readOnly` when users should be able to focus, open, and browse a selection without changing it. The selected value remains part of native form submission.

### Large and remote collections

Virtualization is appropriate for large, stable option lists. Infinite loading should be driven by application state and deterministic loading callbacks; the component does not fetch data itself.

### Keyboard interaction

| Key                              | Description                                                    |
| -------------------------------- | -------------------------------------------------------------- |
| <kbd>Enter</kbd>                 | Opens the listbox or selects the active option.                |
| <kbd>Space</kbd>                 | Opens/selects where the current trigger/input mode permits it. |
| <kbd>ArrowDown</kbd>             | Opens the listbox or moves to the next available option.       |
| <kbd>ArrowUp</kbd>               | Moves to the previous available option.                        |
| <kbd>Home</kbd> / <kbd>End</kbd> | Moves to the first or last available option.                   |
| <kbd>Escape</kbd>                | Closes the listbox without changing the selected value.        |
| <kbd>Tab</kbd>                   | Leaves the control according to normal document focus order.   |

For a bound single Select, `null` means no selection, while `undefined` leaves the component uncontrolled. An empty string (`""`) is a valid selected value, including when its item is temporarily unavailable. Use a nullable Form schema/state for an empty Select; native form submission may still serialize both an empty selection and a selected empty string as `""`.
