## Import

```tsx
import { Select } from 'moraine'
import type { SelectT } from 'moraine'
```

Use Select for one choice from a non-editable collection. Use [Combobox](/combobox) when users need to type a query, or [BaseSelect](/base-select) when you need to compose the listbox yourself.

## Anatomy

```text
control
└── trigger
    ├── leading (optional)
    ├── value
    ├── clear (optional)
    └── trailing (chevron / loading icon)
content (portaled while open)
└── listbox
    ├── group / groupLabel (optional)
    ├── item (×n)
    ├── separator (optional)
    └── empty (optional)
```

The control slot is the outer visual field and floating anchor. The trigger slot is the sole
interactive button and focus owner. The value slot displays the selected label or `String(value)`
for an unresolved value. Clear is a pointer-only affordance inside the trigger that clears the
selection without toggling the popup.

The popup slots are rendered by Select's default collection content; they are styling targets, not attached `Select` child components. Use [BaseSelect](/base-select) when the listbox itself needs custom composition.

## Usage

### String items

Pass strings when the label and value are identical. Strings and objects can be mixed at the
root or inside a group. Whitespace is preserved, and an empty string is a valid value.

<Preview path="./string-items" />

String items are converted to the same item shape used by callbacks: `'Apple'` becomes
`{ value: 'Apple', label: 'Apple' }`. Object items retain their identity and custom fields.
`SelectT.NormalizedItem<TItem>` names the callback item type. Duplicate values use the first
occurrence, including collisions between strings and objects.

### Value and collection

`value` is the selected item's value, or `null` when nothing is selected. Leave `value` undefined to use uncontrolled selection with `defaultValue`. An empty string is a valid value; item values must be unique. The exact selection type is `SelectT.NormalizedItem<TItem>['value'] | null`, which is also the type passed to `onChange`.

Printable keys perform rapid typeahead navigation across available options without opening an editable input.

<Preview path="./usage-value" />

### Keyboard interaction

| Key                 | Behavior                                      |
| ------------------- | --------------------------------------------- |
| Enter / Space       | Open the popup or commit the active option    |
| ArrowDown / ArrowUp | Open or move through selectable options       |
| Home / End          | Move to the first or last option while open   |
| Printable key       | Typeahead to the matching item label          |
| Escape              | Close the dropdown without changing the value |
