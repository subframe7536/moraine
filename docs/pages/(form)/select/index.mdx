## Import

```tsx
import { Select } from 'moraine'
import type { SelectT } from 'moraine'
```

## Features

- **Single collection value**: Commits one `TItem['value']` or `null`.
- **Non-editable trigger**: Printable keys use typeahead, not query state.
- **Collection rendering**: Supports groups, custom items, incremental loading, and virtualization.
- **Stable anatomy**: Control is the field, Trigger is the button, and Value is the label region.

## Anatomy

```text
control
├── trigger
│   ├── leading (optional)
│   └── value
└── clear (optional)
```

The control slot is the outer visual field and floating anchor. The trigger slot is the actual
primary button. The value slot displays the selected label or `String(value)` for a temporarily
unresolved value. Clear is a sibling action and never toggles the popup.

## Usage

### Value and collection

<Preview path="./basic-select" />

The value API is `TItem['value'] | null`. `undefined` leaves the component uncontrolled, `null`
means no selection, and an empty string remains a valid value. Item values must be unique.

### Large and remote collections

Virtualization is appropriate for large, stable option lists. Incremental loading remains
application-owned and does not change the canonical selection source.

<Preview path="./collections" />

### Keyboard interaction

| Key                 | Behavior                                    |
| ------------------- | ------------------------------------------- |
| Enter / Space       | Open the popup or select the active option  |
| ArrowDown / ArrowUp | Open or move through selectable options     |
| Home / End          | Move to the first or last option while open |
| Printable key       | Typeahead to a matching item                |
| Escape              | Close without changing the value            |
