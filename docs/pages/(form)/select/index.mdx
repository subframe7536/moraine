## Features

- **Combobox & Search Filter**: Enable `search` to turn the select into a searchable combobox with typeahead and fuzzy keyword filtering.
- **Categorized Option Groups**: Structure items into labeled hierarchical sections with non-selectable group headings.
- **Infinite Scroll & Virtualization**: Effortlessly handle massive datasets with TanStack Virtual integration and bottom-scroll async pagination.
- **Clearable Selection**: Enable `allowClear` to render an accessible one-click reset action button.
- **WAI-ARIA Listbox Pattern**: Fully conforms to W3C Combobox/Listbox guidelines with roving active-descendant focus, `aria-expanded`, and keyboard shortcuts.

## Anatomy

Hierarchical slot and element structure:

### Trigger control

```text
control
├── leading (optional status or category icon)
├── input (read-only label or search field)
├── clear (optional clear button)
└── trigger (open/close chevron indicator)
```

### Floating Listbox (Portal)

```text
content (floating popover)
└── listbox (scrollable options container)
    ├── item (selectable option row ×n)
    │   ├── itemLabel (text and icon)
    │   ├── itemDescription (optional subtext)
    │   └── itemTrailing (check indicator)
    ├── group (grouped section container ×n)
    │   └── label (group header)
    └── empty (fallback message when no results match)
```

- `control`: The trigger box maintaining focus and managing open/closed states.
- `listbox`: The floating popover displaying selectable items with active highlight.

## Keyboard Interactions

| Key                                 | Description                                                      |
| ----------------------------------- | ---------------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Opens the listbox or confirms selection of the highlighted item. |
| <kbd>ArrowDown</kbd>                | Highlights the next option in the list.                          |
| <kbd>ArrowUp</kbd>                  | Highlights the previous option in the list.                      |
| <kbd>Home</kbd> / <kbd>End</kbd>    | Jumps highlight directly to the first or last available option.  |
| <kbd>Escape</kbd>                   | Closes the dropdown without changing the current value.          |
| <kbd>Tab</kbd>                      | Closes the listbox and moves focus to the next element.          |
