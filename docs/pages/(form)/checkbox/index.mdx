## Features

- **Tri-State Support**: Fully supports checked, unchecked, and indeterminate states with automatic ARIA sync (`aria-checked="mixed"`).
- **Custom Value Mapping**: Bind custom domain values (such as `'opted-in'` / `'opted-out'`) via `trueValue` and `falseValue` props instead of raw booleans.
- **Card & List Layouts**: Choose between lightweight `list` styling and interactive bounded `card` panels with start, end, or hidden indicator positions.
- **Keyboard Accessible**: Full compliance with WAI-ARIA checkbox pattern, supporting spacebar activation, roving focus, and form label associations.
- **Icon Flexibility**: Customize both checked and indeterminate icons with any UnoCSS or SVG icon name.

## Anatomy

Hierarchical slot and element structure:

```text
root
├── container
│   ├── input (native hidden checkbox)
│   └── control (styled indicator box)
│       └── indicator (icon or checkmark)
└── wrapper (optional label container)
    ├── label (optional)
    └── description (optional)
```

- `root`: Top-level label container with state data attributes (`data-checked`, `data-indeterminate`, `data-disabled`).
- `container`: Box containing the visually hidden native `<input>` and custom styled `control`.
- `control`: The visible checkbox square that animates checkmarks and border styles.
- `indicator`: The rendered icon (defaults to `i-lucide:check` or `i-lucide:minus`).
- `wrapper`: Container grouping the title `label` and optional helper `description`.

## Keyboard Interactions

| Key                    | Description                                                                                         |
| ---------------------- | --------------------------------------------------------------------------------------------------- |
| <kbd>Space</kbd>       | Toggles the checkbox state between checked and unchecked. If indeterminate, transitions to checked. |
| <kbd>Tab</kbd>         | Moves focus to the next focusable element.                                                          |
| <kbd>Shift + Tab</kbd> | Moves focus to the previous focusable element.                                                      |
