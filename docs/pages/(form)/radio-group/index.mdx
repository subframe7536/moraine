import { createSignal } from 'solid-js'

## Import

```tsx
import { RadioGroup } from 'moraine'
import type { RadioGroupT } from 'moraine'
```

Use RadioGroup for one choice from a small visible set. For a longer or space-constrained collection, use [Select](/select).

## Anatomy

```text
root (radio group)
└── item (×n)
    ├── input (hidden native radio)
    ├── control
    │   └── indicator
    └── wrapper
        ├── label
        └── description
```

## Usage

### Single selection

Use one string value for the selected item and pair `value` with `onChange` for controlled state. Disabled items remain visible but cannot be selected. The group uses radio keyboard behavior rather than the independent focus order of checkboxes.

<Preview path="./selection" />

### Forms

Set a `name` when a native form needs the selected value, or place the group inside `Field` for Formisch binding and validation metadata.

<Preview path="./form-usage" />

### Keyboard interaction

| Key                                          | Description                                                   |
| -------------------------------------------- | ------------------------------------------------------------- |
| <kbd>ArrowDown</kbd> / <kbd>ArrowRight</kbd> | Moves focus and selection to the next enabled radio item.     |
| <kbd>ArrowUp</kbd> / <kbd>ArrowLeft</kbd>    | Moves focus and selection to the previous enabled radio item. |
| <kbd>Space</kbd>                             | Selects the focused radio item.                               |
| <kbd>Tab</kbd>                               | Enters or leaves the group according to normal focus order.   |
