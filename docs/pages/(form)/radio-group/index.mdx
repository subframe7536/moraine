## Features

- **Mutually Exclusive Selection**: Enforces single-value selection across all radio options with reactive value binding.
- **Roving Focus Navigation**: Follows W3C WAI-ARIA radio group patterns where arrow keys move focus and select adjacent options.
- **Card, List, and Table Layouts**: Choose between selectable cards with active glow rings, standard form lists, or compact tabular rows.
- **Custom Indicator Placement**: Configure circular radio indicator positions (`start`, `end`, or `hidden` for button-like cards).
- **Per-Option Disabling**: Disable specific deprecated or restricted plan options while keeping the remainder selectable.

## Anatomy

Hierarchical slot and element structure:

```text
root (radiogroup container)
└── item (individual radio option ×n)
    ├── input (hidden native radio input)
    ├── control (styled circle radio container)
    │   └── indicator (inner animated active dot)
    └── wrapper
        ├── label (option title)
        └── description (optional helper text)
```

- `root`: Container managing `role="radiogroup"` and roving tabindex.
- `item`: Composed radio option element with state data attributes (`data-checked`, `data-disabled`).
- `control`: The circular radio border and background.
- `indicator`: The centered active status indicator.

## Keyboard Interactions

| Key                                          | Description                                                                               |
| -------------------------------------------- | ----------------------------------------------------------------------------------------- |
| <kbd>ArrowDown</kbd> / <kbd>ArrowRight</kbd> | Moves focus and selection to the next radio item in the group (wrapping around to start). |
| <kbd>ArrowUp</kbd> / <kbd>ArrowLeft</kbd>    | Moves focus and selection to the previous radio item.                                     |
| <kbd>Space</kbd>                             | Selects the currently focused radio item if not already selected.                         |
| <kbd>Tab</kbd>                               | Moves focus out of the radio group to the next interactive page element.                  |
