## Import

```tsx
import { BaseSelect, useSelectState } from 'moraine'
import { useBaseSelectSearchInput, useSearchValue } from 'moraine/utils'
```

BaseSelect owns array selection, disclosure, highlighted navigation, typeahead, listbox primitives,
and form integration. Collection grouping, filtering, query state, tags, and item creation belong to
the composing control.

## Standard anatomy

```tsx
<BaseSelect items={items}>
  <BaseSelect.Control>
    <BaseSelect.Trigger>Choose</BaseSelect.Trigger>
  </BaseSelect.Control>
  <BaseSelect.Content>
    <BaseSelect.Listbox>{/* items */}</BaseSelect.Listbox>
  </BaseSelect.Content>
</BaseSelect>
```

Control is an optional, non-interactive layout container and floating anchor. It does not toggle,
own keyboard navigation, become a tab stop, or receive role="combobox". Trigger is the primary
select-like focus owner and activator.

## Custom searchable composition

```tsx
function SearchField() {
  const state = useSelectState()
  const query = useSearchValue()
  const input = useBaseSelectSearchInput(state, {}, () => true, query)
  return (
    <BaseSelect.Control>
      <input {...input.binding} />
      <button type="button" tabIndex={-1} onClick={() => state.setOpen(!state.open())}>
        Toggle
      </button>
    </BaseSelect.Control>
  )
}
```

The input helper registers focusOwner; it never becomes the floating anchor. When Control is
omitted, Content falls back to the registered focus owner for resilient custom compositions.

## Styling

BaseSelect exposes control, trigger, content, listbox, item, group, groupLabel, separator, and
empty. Part-local class and style values have final precedence.
