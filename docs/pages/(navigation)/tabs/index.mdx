## Features

- **3 Semantic Visual Styles**: `pill` (enclosed segmented control), `link` (underline border highlight), and `tab` (browser-style card tabs).
- **Horizontal & Vertical Orientations**: Switch between standard top tab rails or left-hand sidebar navigation panels.
- **WAI-ARIA Tablist Pattern**: Follows W3C guidelines with `role="tablist"`, `role="tab"`, `role="tabpanel"`, and roving focus.
- **Leading Icons & Custom Badges**: Embed status icons, unread notification counts, and trailing badges in tab headers.
- **Controlled & Disabled States**: Full programmatic control with reactive value signals and granular per-tab disabled rules.

## Anatomy

Hierarchical slot and element structure:

```text
root (tabs container)
├── list (tablist trigger rail)
│   ├── indicator (sliding active highlight line or pill)
│   └── trigger (individual tab button ×n)
│       ├── leading (icon, optional)
│       ├── label (tab title text)
│       └── trailing (counter badge, optional)
└── content (active tabpanel body content)
```

- `root`: Container managing active tab state and ARIA associations.
- `list`: Container with `role="tablist"`.
- `trigger`: Semantic button with `role="tab"` and `aria-selected`.
- `content`: Associated view panel with `role="tabpanel"`.

## Keyboard Interactions

| Key                                          | Description                                                                 |
| -------------------------------------------- | --------------------------------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Moves focus and selection to the next tab in the tablist (wrapping around). |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Moves focus and selection to the previous tab in the tablist.               |
| <kbd>Home</kbd>                              | Moves focus directly to the first enabled tab.                              |
| <kbd>End</kbd>                               | Moves focus directly to the last enabled tab.                               |
| <kbd>Tab</kbd>                               | Moves focus out of the tablist into the active tabpanel.                    |
