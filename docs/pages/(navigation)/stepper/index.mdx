## Features

- **Linear & Non-Linear Workflows**: Enforce strict sequential completion with `linear={true}` or allow free jumping between unlocked stages.
- **Horizontal & Vertical Orientations**: Standard top horizontal wizard bar or vertical workflow timeline checklist.
- **Integrated Step Content Panels**: Embed active step body content directly inside each item definition or control external views.
- **Completed Step Checkmarks**: Automatically turns past completed step icons into checkmark badges.
- **WAI-ARIA Tablist Semantics**: Accessible `role="tablist"` with `aria-selected` and roving focus between step triggers.

## Anatomy

Hierarchical slot and element structure:

```text
root (stepper container)
├── header (step buttons row or column)
│   └── item (step item element ×n)
│       ├── container
│       │   ├── trigger (step button with circle number or icon)
│       │   └── separator (connecting line between steps)
│       └── wrapper
│           ├── title (step name)
│           └── description (step summary subtext)
└── content (active step panel content)
```

- `root`: Container managing active step index and orientation.
- `header`: Container grouping all step badges and connecting line separators.
- `trigger`: Clickable step pill with completion indicator.
- `content`: Associated content panel for the active step.

## Keyboard Interactions

| Key                                          | Description                                         |
| -------------------------------------------- | --------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Moves focus to the next clickable step trigger.     |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Moves focus to the previous clickable step trigger. |
| <kbd>Enter</kbd> / <kbd>Space</kbd>          | Activates the focused step trigger.                 |
