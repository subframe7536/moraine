## Import

```tsx
import { SidebarFrame, useSidebarFrame } from 'moraine'
import type { SidebarFrameT } from 'moraine'
```

`SidebarFrame` is both the state provider and desktop layout root. `SidebarFrame.Sidebar` renders inline on desktop and automatically moves its content into a mobile Sheet on smaller viewports.

## Anatomy

```text
SidebarFrame
├── SidebarFrame.Sidebar
│   ├── SidebarFrame.SidebarHeader
│   ├── SidebarFrame.SidebarBody
│   └── SidebarFrame.SidebarFooter
├── SidebarFrame.Main
└── SidebarFrame.Trigger
```

`SidebarFrame.Trigger` can appear anywhere inside `SidebarFrame` to toggle sidebar visibility, without requiring a structural placement inside `SidebarFrame.Main`. Composing with `<SidebarFrame.Trigger as={Button} ... />` is the recommended way to obtain standard Moraine button styling.

Call `useSidebarFrame()` from a descendant component for advanced access to `isMobile`, `isOpen`, `scrolled`, `setOpen`, and `toggle`. A global application header belongs outside the frame. For desktop resizing, branch on `isMobile()` and compose the generic `Resizable` component explicitly.
