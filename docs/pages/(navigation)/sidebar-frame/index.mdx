import { Badge, SidebarFrame } from '@src'

## Import

```tsx
import { SidebarFrame, useSidebarFrame } from 'moraine'
import type { SidebarFrameT } from 'moraine'
```

`SidebarFrame` is both the state provider and desktop layout root. `SidebarFrame.Sidebar` renders inline on desktop and automatically moves its content into a Sheet on mobile.

## Anatomy

```text
SidebarFrame
├── SidebarFrame.Sidebar
│   ├── SidebarFrame.SidebarHeader
│   ├── SidebarFrame.SidebarBody
│   └── SidebarFrame.SidebarFooter
└── SidebarFrame.Main
```

Call `useSidebarFrame()` from a descendant component to read `isMobile`, `isOpen`, and `scrolled`, or to call `setOpen` and `toggle`. A global application header belongs outside the frame. For desktop resizing, branch on `isMobile()` and compose the generic `Resizable` component explicitly.
