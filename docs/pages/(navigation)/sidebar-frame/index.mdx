## Import

Import the component and its companion types from the package root:

```tsx
import { SidebarFrame, SidebarFrameSheetResizableRender } from 'moraine'
import type { SidebarFrameT } from 'moraine'
```

## Features

- **Responsive Breakpoint Adaptation**: Automatically switches from desktop fixed/resizable sidebar to mobile overlay slide-out `Sheet` drawer.
- **3 Visual Styles**: Supports `default` (flush side border), `floating` (detached floating card rail), and `inset` (recessed canvas background).
- **Sidebar Sides (`left` & `right`)**: Place navigation on the left or secondary inspector/property panels on the right.
- **Resizable Drawer Adapter**: Integrates with `SidebarFrameSheetResizableRender` for draggable panel resizing and mini-rail collapse states.
- **Dedicated Slot Regions**: Clean modular separation of `sidebarHeaderRender`, `sidebarBodyRender`, `sidebarFooterRender`, and `mainRender`.

## Anatomy

Hierarchical slot and element structure:

```text
root (app shell container)
├── sidebar (desktop panel or mobile sheet drawer)
│   ├── sidebarHeader (organization brand / switcher, optional)
│   ├── sidebarBody (scrollable navigation links)
│   └── sidebarFooter (user profile / settings, optional)
└── main (primary scrollable page content)
```

- `root`: Outer layout frame managing media queries and CSS grid/flex layout.
- `sidebar`: Responsive navigation container with width variables (`--sidebar-width`).
- `main`: Content viewport container.

## Usage

SidebarFrame chooses a desktop resizable sidebar or mobile sheet according to its responsive configuration. The application supplies navigation content and decides when forced mobile behavior is useful for previews or constrained layouts.
