## Playground

<Playground
  controls={[
    {
      kind: 'select',
      prop: 'size',
      label: 'Size',
      defaultValue: 'md',
      options: [
        { label: 'Small', value: 'sm' },
        { label: 'Medium', value: 'md' },

    },
    {
      kind: 'input',
      prop: 'itemsPerPage',
      label: 'Items per page',
      defaultValue: 10,
      inputType: 'number',
    },
    { kind: 'switch', prop: 'showControls', label: 'Show arrows', defaultValue: true },
  ]}
>
  {(props) => {
    const [page, setPage] = createSignal(1)

    return (
      <div class="flex flex-col gap-3 items-center">
        <Pagination
          total={100}
          page={page()}
          onPageChange={setPage}
          itemsPerPage={props.itemsPerPage}
          size={props.size}
          showControls={props.showControls}
        />
        <span class="text-xs text-muted-foreground font-mono">Current Page: {page()} of 10</span>
      </div>
    )

}}

</Playground>

## Slot Structure

Page controls with previous, next, and numbered page link buttons.

```text
root
└── list
    ├── item (prev)
    │   └── prev (Button)
    ├── item (×n, page links)
    │   └── link (Button)
    └── item (next)
        └── next (Button)
```
