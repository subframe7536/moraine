## Features

- **Dynamic Sibling Clamping**: Intelligent ellipsis truncation keeping visible page buttons constrained to `siblingCount` bounds.
- **Edge Jump Buttons**: Toggle `showEdges` to render quick-jump buttons to page 1 and the final page.
- **WAI-ARIA Pagination Landmark**: Renders `<nav aria-label="Pagination">` with `aria-current="page"` and accessible button labels.
- **Link & Button Modes**: Render standard clickable buttons or polymorphic anchor tags (`<a>`) for SEO-friendly URL pagination.
- **Configurable Sizes**: Size scale across `sm` (compact table footers), `md` (standard), and `lg`.

## Anatomy

Hierarchical slot and element structure:

```text
root (semantic <nav aria-label="Pagination">)
└── list (flex list container)
    ├── item (prev button container)
    │   └── prev (Button with previous chevron)
    ├── item (page number or ellipsis ×n)
    │   ├── link (page number Button)
    │   └── ellipsis (decorative span "...")
    └── item (next button container)
        └── next (Button with next chevron)
```

- `root`: Semantic `<nav>` landmark wrapper.
- `list`: Flex container organizing page buttons.
- `prev` / `next`: Directional stepper buttons with boundary auto-disabling.
- `link`: Interactive numbered button with `data-active` indicator.

## Keyboard Interactions

| Key                                 | Description                                                     |
| ----------------------------------- | --------------------------------------------------------------- |
| <kbd>Tab</kbd>                      | Moves focus through pagination links and previous/next buttons. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Navigates to the focused page number.                           |
