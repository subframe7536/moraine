## Features

- **Sibling Window**: `siblingCount` controls how many nearby page numbers remain visible around the current page, with ellipses filling gaps.
- **Edge Controls**: `showEdges` adds controls for the first and last page; `showControls` controls previous/next buttons.
- **Pagination Landmark**: Uses a pagination navigation landmark and marks the active page with `aria-current="page"`.
- **Polymorphic Page Items**: Configure page controls to render with the element/component shape required by your router or application.
- **Controlled State**: `page` and `onPageChange` support application-owned page state.

## Anatomy

```text
root (pagination navigation)
└── list
    ├── item → prev (optional)
    ├── item → page link / ellipsis (×n)
    └── item → next (optional)
```

## Keyboard Interactions

Pagination does not add collection-style arrow navigation. Each interactive page control uses the keyboard semantics of its rendered button, link, or custom polymorphic element.
