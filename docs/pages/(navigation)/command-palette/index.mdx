## Features

- **Inline or Modal Presentation**: Use directly inside views/sidebars or host inside a modal `Dialog` triggerable via `⌘K`.
- **Fuzzy Search & Categorized Groups**: Fast real-time filtering across item labels, descriptions, and keywords grouped into structured sections.
- **Rich Slot Hooks**: Supports `leadingRender`, `trailingRender` (shortcuts/badges), `footerRender` (keyboard hints), and full custom `itemRender`.
- **Multi-Level Sub-Navigation**: Drill down into nested sub-menus (e.g. "Assignee > Select Member") smoothly without closing the palette.
- **WAI-ARIA Combobox / Listbox**: Fully accessible with `role="combobox"`, `aria-activedescendant`, `aria-expanded`, and keyboard navigation.

## Anatomy

Hierarchical slot and element structure:

### Search Input area

```text
root (command palette container)
└── inputWrapper (search header bar)
    ├── search (leading magnifying glass icon or loading spinner)
    ├── input (text query search field)
    └── close (clear or dismiss icon button, optional)
```

### Results Listbox

```text
root
├── listbox (scrollable options list)
│   ├── group (grouped category section ×n)
│   │   ├── label (group category title)
│   │   └── item (command action row ×n)
│   │       ├── itemLeading (icon or avatar)
│   │       ├── itemWrapper
│   │       │   ├── itemLabel (command title)
│   │       │   └── itemDescription (subtext or trailing hint)
│   │       └── itemTrailing (keyboard shortcut kbd badges)
├── empty (custom no results fallback message)
└── footer (bottom status bar with shortcut hints)
```

- `root`: Main surface container.
- `input`: Search input dispatching live filter query signals.
- `listbox`: Scrollable options area highlighting active item.
- `footer`: Optional bottom row explaining keyboard shortcuts.

## Keyboard Interactions

| Key                              | Description                                                   |
| -------------------------------- | ------------------------------------------------------------- |
| <kbd>ArrowDown</kbd>             | Moves highlight to the next command item.                     |
| <kbd>ArrowUp</kbd>               | Moves highlight to the previous command item.                 |
| <kbd>Enter</kbd>                 | Executes the currently highlighted command action.            |
| <kbd>Escape</kbd>                | Clears query or emits `onClose` to dismiss the palette.       |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jumps highlight directly to the first or last available item. |
