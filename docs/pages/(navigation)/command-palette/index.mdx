## Features

- **Inline or Modal Composition**: Render the palette inline or place it inside `Dialog` when your application needs a modal command surface. Global shortcuts such as Cmd/Ctrl+K are registered by the application, not by `CommandPalette` itself.
- **Search & Groups**: Filters command items while preserving grouped presentation.
- **Custom Regions**: Supports `leadingRender`, `trailingRender`, `footerRender`, and custom item rendering.
- **Sub-Navigation**: The sub-navigation APIs let a command surface replace its visible item set while remaining open.
- **Combobox/Listbox Metadata**: The search input and result list expose the roles and active-item metadata used by keyboard navigation.
- **Loading State**: `loading` changes the palette presentation; asynchronous request orchestration remains caller-owned.

## Keyboard Interactions

| Key                              | Description                                                           |
| -------------------------------- | --------------------------------------------------------------------- |
| <kbd>ArrowDown</kbd>             | Moves to the next available command.                                  |
| <kbd>ArrowUp</kbd>               | Moves to the previous available command.                              |
| <kbd>Enter</kbd>                 | Activates the current command.                                        |
| <kbd>Escape</kbd>                | Clears the current query or requests close according to current state.|
| <kbd>Home</kbd> / <kbd>End</kbd> | Moves to the first or last available command.                          |
