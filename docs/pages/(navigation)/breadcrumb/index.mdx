## Features

- **WAI-ARIA Breadcrumb Landmark**: Semantic `<nav aria-label="Breadcrumb">` wrapping an ordered `<ol>` list.
- **Current Page Indication**: The final item is automatically rendered as text with `aria-current="page"`.
- **Custom Separator Glyph or JSX**: Choose chevron, slash, arrow, or custom SVG separators.
- **Leading Icons & Avatars**: Embed section icons or repository icons alongside trail labels.
- **Responsive Wrapping Control**: Toggle `wrap` to gracefully wrap long path chains without truncating text.

## Anatomy

Hierarchical slot and element structure:

```text
root (semantic <nav aria-label="Breadcrumb">)
└── list (<ol> ordered navigation container)
    ├── item (<li> element ×n)
    │   ├── link (clickable ancestor anchor)
    │   └── page (non-clickable current page text with aria-current="page")
    └── separator (<li> delimiter with aria-hidden="true")
```

- `root`: Outer `<nav>` landmark.
- `list`: Semantic ordered `<ol>` list.
- `link`: Clickable parent directory / section link.
- `separator`: Decorative divider between items.
- `page`: Terminal node indicating the user's current location.

## Keyboard Interactions

| Key              | Description                                                                 |
| ---------------- | --------------------------------------------------------------------------- |
| <kbd>Tab</kbd>   | Navigates focus sequentially through clickable ancestor links in the trail. |
| <kbd>Enter</kbd> | Activates the focused link to navigate to the parent path.                  |
