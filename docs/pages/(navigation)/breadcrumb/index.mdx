import { Breadcrumb } from '@src'

## Import

```tsx
import { Breadcrumb } from 'moraine'
import type { BreadcrumbT } from 'moraine'
```

Use Breadcrumb to show a resource’s place in a navigation hierarchy. The current page is represented as a non-link item.

## Anatomy

```text
root (<nav aria-label="Breadcrumb">)
└── list (<ol>)
    ├── item (<li> ×n)
    │   ├── link (ancestor item)
    │   └── page (current item)
    └── separator (decorative)
```

## Usage

### Items and current page

Use links for navigable ancestors. The last item is the current page by default; use `active` to select another item explicitly. Current and disabled items are non-interactive.
