## Features

- **Breadcrumb Landmark**: Uses `<nav aria-label="Breadcrumb">` with an ordered list.
- **Current Page Metadata**: The terminal page item is non-interactive and marked with `aria-current="page"`.
- **Custom Separators**: Use an icon source or custom separator content between trail entries.
- **Leading Icons**: Individual items can include a leading icon.
- **Wrapping Control**: `wrap` controls whether longer trails wrap onto additional lines.

## Anatomy

```text
root (<nav aria-label="Breadcrumb">)
└── list (<ol>)
    ├── item (<li> ×n)
    │   ├── link (ancestor item)
    │   └── page (current item)
    └── separator (decorative)
```

## Keyboard Interactions

Breadcrumb does not add custom keyboard handling; linked ancestors use their underlying link/button semantics and normal document focus order.
