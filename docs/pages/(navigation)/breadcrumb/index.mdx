## Playground

<Playground
  controls={[
    {
      kind: 'input',
      prop: 'separator',
      label: 'Separator',
      defaultValue: 'i-lucide:chevron-right',
    },
    { kind: 'switch', prop: 'wrap', label: 'Wrap items', defaultValue: false },
  ]}
>
  {(props) => {
    const TRAIL_ITEMS = [
      { label: 'Home', href: '#', icon: 'i-lucide:home' },
      { label: 'Projects', href: '#' },
      { label: 'Design System', href: '#' },
      { label: 'Components' },
    ]

    return (
      <Breadcrumb
        items={TRAIL_ITEMS}
        separator={props.separator || 'i-lucide:chevron-right'}
        wrap={props.wrap}
      />
    )

}}

</Playground>

## Slot Structure

Ordered navigation list with links, separators, and a non-clickable current page.

```text
root
└── list
    ├── item
    │   └── link
    ├── separator
    └── item
        └── page
```
