## Import

```tsx
import { Breadcrumb } from 'moraine'
```

## Slot Structure

Ordered navigation list with links, separators, and a non-clickable current page.

```text
root
└── list
    ├── item
    │   └── link
    ├── separator
    └── item
        └── page
```
