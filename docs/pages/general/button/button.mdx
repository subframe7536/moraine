## Import

```tsx
import { Button } from 'moraine'
```

## Slot Structure

Trigger element with optional leading and trailing icon slots.

```text
root
├── leading (Icon, optional)
├── label (optional)
└── trailing (Icon, optional)
```

### Disable Active Style

Use `disableActiveTransform` to keep hover feedback while removing the pressed-state color and movement styles. The button remains interactive.

```tsx
<Button disableActiveTransform>Continue</Button>
```
