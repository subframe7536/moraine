## Import

```tsx
import { ListBox } from 'moraine'
```

## Slot Structure

`ListBox` is a flat list. Add `label` and `separator` entries when the caller needs structural rows; filtering and search inputs remain outside the component.

```text
content
├── label (optional)
├── item (×n)
│   ├── itemLeading (optional)
│   ├── itemWrapper
│   │   ├── itemLabel
│   │   └── itemDescription (optional)
│   └── itemTrailing (optional)
├── separator (optional)
└── empty (optional)
```
