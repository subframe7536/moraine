## Import

```tsx
import { Avatar, AvatarGroup } from 'moraine'
```

## Slot Structure

Avatar renders a single image/fallback frame. AvatarGroup renders grouped avatars with an overflow counter.

### Single avatar

```text
root
├── image
├── fallback
│   └── fallbackIcon (Icon, optional)
└── badge (optional)
```

### Avatar group

```text
root
├── count (optional, overflow count)
└── item (×n)
    ├── image
    ├── fallback
    │   └── fallbackIcon (Icon, optional)
    └── badge (optional)
```
