## Import

```tsx
import { RadioGroup } from 'moraine'
```

## Slot Structure

Radiogroup root with mutually exclusive radio items. Use `FormField` for the group label, description, help text, and validation message.

```text
root
└── item (×n)
    ├── input
    ├── control
    │   └── indicator
    └── wrapper (optional)
        ├── label (optional)
        └── description (optional)
```
