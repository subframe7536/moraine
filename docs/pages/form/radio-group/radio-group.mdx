## Import

```tsx
import { RadioGroup } from 'moraine'
```

## Slot Structure

Fieldset with optional legend and mutually exclusive radio items.

```text
root
└── fieldset
    ├── legend (optional)
    └── item (×n)
        ├── container
        │   ├── input
        │   └── control
        │       └── indicator
        └── wrapper (optional)
            ├── label (optional)
            └── description (optional)
```
