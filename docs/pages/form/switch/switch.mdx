## Import

```tsx
import { Switch } from 'moraine'
```

## Slot Structure

Toggle track with thumb and optional label area.

```text
root
├── container
│   ├── input
│   └── track
│       └── thumb
└── wrapper (optional)
    ├── label (optional)
    └── description (optional)
```
