## Import

```tsx
import { FileUpload } from 'moraine'
```

## Slot Structure

Upload control and optional file preview list.

### Upload area

```text
root
└── control (dropzone or trigger button)
    └── wrapper
        ├── icon (Icon)
        ├── label (optional)
        └── description (optional)
```

### File preview list

```text
root
└── files
    └── file (×n)
        ├── filePreview
        ├── fileMeta
        │   ├── fileName
        │   └── fileSize
        └── fileRemove
```
