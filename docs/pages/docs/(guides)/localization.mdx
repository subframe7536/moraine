Moraine components ship English accessible names, placeholders, and the `en` locale. That fallback is active with no `MoraineProvider` in the tree. Add a provider to replace the copy, switch the locale used by `InputNumber`, or set the direction used by menus, sliders, and portaled overlays. Nest a provider to override part of the tree.

## Provider props

| Prop       | Omitted                           | Set                                                                             |
| :--------- | :-------------------------------- | :------------------------------------------------------------------------------ |
| `locale`   | Inherits the parent locale.       | Replaces it with a BCP 47 tag such as `de-DE`.                                  |
| `dir`      | Inherits the parent direction.    | Replaces it with `ltr` or `rtl`, or `null` to clear back to document detection. |
| `messages` | Inherits the parent message pack. | Deep-merges a partial pack over the parent. The base pack is English.           |

With no provider, `locale` is `en`, `dir` is unset, and messages are the English pack. An omitted `locale` or `messages` prop inherits those defaults. An omitted `dir` stays unset, so direction still comes from the document.

`locale` is exposed as shared application locale context. Components may use it for locale-sensitive behavior; currently `InputNumber` uses it for number parsing and formatting. `InputNumber` reads `locale` from its own prop, then falls back to the provider.

```tsx title="src/App.tsx"
import { MoraineProvider } from 'moraine'
import type { MoraineMessagesInput } from 'moraine'

const zhCN = {
  dialog: { close: '关闭' },
  pagination: {
    label: '分页',
    status: ({ page, total }) => `第 ${page} 页，共 ${total} 页`,
    page: ({ page, total }) => `第 ${page} 页，共 ${total} 页`,
    currentPage: ({ page, total }) => `第 ${page} 页，共 ${total} 页，当前页`,
    prev: ({ page }) => (page === undefined ? '上一页' : `上一页，第 ${page} 页`),
    next: ({ page }) => (page === undefined ? '下一页' : `下一页，第 ${page} 页`),
  },
} satisfies MoraineMessagesInput

export function App(props) {
  return (
    <MoraineProvider locale="zh-CN" dir="ltr" messages={zhCN}>
      {props.children}
    </MoraineProvider>
  )
}
```

Changing `messages`, `locale`, or `dir` updates the rendered text and behavior without remounting the components. `useLocale()` returns stable `locale()` and `dir()` accessors for application code that needs the same values.

A component prop always wins over the pack. `placeholder`, `aria-label`, `ariaLabel`, and `label` keep the caller's text, and the pack fills only what the caller left unset.

## Message packs

`MoraineMessages` is the full English shape. `MoraineMessagesInput` is the deep-partial type you pass to the provider. Groups are `dialog`, `sheet`, `breadcrumb`, `commandPalette`, `select`, `combobox`, `multiSelect`, `slider`, `pagination`, `inputNumber`, `fileUpload`, `tagsField`, `resizable`, `sidebarFrame`, `form`, and `kbd`.

Text that includes a number or a name is a function, so the translation controls word order:

```ts
const pagination = {
  prev: ({ page }) => (page === undefined ? '上一页' : `上一页，第 ${page} 页`),
}
```

`page` is omitted when the control is already on that edge. Plural rules stay in the pack, for example with `Intl.PluralRules`:

```ts
const rules = new Intl.PluralRules('en')

const pagination = {
  page: ({ page, total }) =>
    rules.select(total) === 'one'
      ? `Go to page ${page} of ${total} page`
      : `Go to page ${page} of ${total} pages`,
}
```

`kbd` is a record of accessible names for the built-in key aliases. The keycap symbol stays the same; only the announced name changes.

## Direction

`dir` controls Moraine component direction-sensitive behavior, such as horizontal keyboard navigation, slider interaction direction, and portaled overlay positioning. It does not set a `dir` attribute on arbitrary descendants. Set `dir` on your application root when you need the browser's full RTL layout behavior.

Portaled popover, dialog, and sheet content receive `dir` from the provider when the component does not set `dir` itself. A component's own `dir` attribute always takes precedence over the provider. The attribute is omitted when neither is set, so server markup stays unchanged until you opt in.

Shared overlay direction uses the provider value when it is set, and otherwise reads the element and document the way it did before. A component's own `dir` attribute still wins over the provider. When the component does not set `dir`, the provider wins over an ancestor or the document.
