`createCopy` writes strings or `ClipboardItem` values to the clipboard and tracks the result as a reactive state. It writes through the Clipboard API, falls back to `document.execCommand('copy')` when that API is unavailable, and holds a `copied` or `failed` state for a set duration before returning to `idle`.

## Import

```tsx
import { createCopy } from 'moraine/utils'
```

## Features

- Writes with `navigator.clipboard.writeText` or `navigator.clipboard.write`, and falls back to `document.execCommand('copy')` when neither is available.
- Accepts a `string`, `ClipboardItem`, `ClipboardItem[]`, a `Promise` of any of these, or an accessor returning them.
- In the fallback path, extracts plain text from a `ClipboardItem`, or serializes the data with `JSON.stringify` when no text type is present.
- Exposes `isCopied()` and `state()` (`'idle' | 'copied' | 'failed'`); the active state resets to `idle` after `copiedDuration` milliseconds.
- Returns `false` from `copy()` and skips clipboard calls on the server.

## Signature

```ts
function createCopy(options?: CreateCopyOptions): CreateCopyReturn

interface CreateCopyOptions {
  /**
   * Default source value to copy if none is provided to copy().
   */
  value?: CopySource

  /**
   * Duration in milliseconds to hold the 'copied' state before returning to 'idle'.
   * @default 2000
   */
  copiedDuration?: number | (() => number | undefined)

  /**
   * Callback invoked when a copy succeeds.
   */
  onCopy?: (data: CopyData) => void

  /**
   * Callback invoked when a copy fails.
   */
  onError?: (error: unknown) => void

  /**
   * Callback invoked when the copy status changes.
   */
  onStatusChange?: (details: { isCopied: boolean; state: CopyState }) => void
}

interface CreateCopyReturn {
  isCopied: Accessor<boolean>
  isError: Accessor<boolean>
  state: Accessor<'idle' | 'copied' | 'failed'>
  copy: (data?: CopySource) => Promise<boolean>
  reset: () => void
  error: Accessor<unknown>
  isSupported: Accessor<boolean>
}
```

## Usage Example

```tsx title="src/ClipboardSnippet.tsx"
import { createCopy } from 'moraine/utils'

export function ClipboardSnippet() {
  const clipboard = createCopy({
    copiedDuration: 2000,
  })

  return (
    <div class="flex gap-2 items-center">
      <code class="px-2 py-1 bg-muted rounded text-xs font-mono">pnpm add moraine</code>
      <button
        type="button"
        onClick={() => clipboard.copy('pnpm add moraine')}
        class="text-xs px-2 py-1 rounded border"
      >
        {clipboard.isCopied() ? 'Copied!' : 'Copy'}
      </button>
    </div>
  )
}
```

## Fallback Mechanics

When `navigator.clipboard` is missing or its write call throws, `createCopy` falls back to `document.execCommand('copy')`:

1. For a string, it adds a visually hidden read-only `<textarea>`, selects the content, and runs the command.
2. For a `ClipboardItem` or `ClipboardItem[]`, it looks for a `text/plain` or `text/*` type, reads it through `item.getType(type)` and `blob.text()`, then runs the command on that text. If no text type is found or reading fails, it runs the command on `JSON.stringify(data)`.
