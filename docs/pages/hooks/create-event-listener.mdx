`createEventListener` and `createEventListenerMap` attach DOM event listeners to a `Window`, `Document`, `MediaQueryList`, element, or other `EventTarget`. Each returns a `detach` function and, when called inside an active Solid owner scope, also registers that removal with `onCleanup` so the listener detaches automatically when the scope disposes.

## Import

```tsx
import { createEventListener, createEventListenerMap } from 'moraine/utils'
```

## Signatures

```ts
function createEventListener<
  TTarget extends EventTarget,
  TType extends EventTypeForTarget<TTarget>,
>(
  target: TTarget | null | undefined,
  type: TType,
  listener: (event: EventMapForTarget<TTarget>[TType]) => void,
  options?: boolean | AddEventListenerOptions,
): VoidFunction

function createEventListenerMap<TTarget extends EventTarget>(
  target: TTarget | null | undefined,
  listeners: EventListenerMap<TTarget>,
  options?: boolean | AddEventListenerOptions,
): VoidFunction
```

`EventListenerMap` maps event types to either a listener or a `[listener, options]` tuple. A tuple's options replace the shared `options` for that event.

## Usage Example

### Single Event with `createEventListener`

```tsx title="src/EscapeListener.tsx"
import { onSettled } from 'solid-js'
import { createEventListener } from 'moraine/utils'

export function EscapeListener(props: { onEscape: () => void }) {
  onSettled(() =>
    // Strongly typed: e is KeyboardEvent for window keydown.
    createEventListener(window, 'keydown', (e) => {
      if (e.key === 'Escape') {
        props.onEscape()
      }
    }),
  )

  return null
}
```

### Multiple Events with `createEventListenerMap`

```tsx title="src/DragObserver.tsx"
import { onSettled } from 'solid-js'
import { createEventListenerMap } from 'moraine/utils'

export function DragObserver() {
  onSettled(() =>
    createEventListenerMap(window, {
      pointermove: (e) => console.log('Pointer at:', e.clientX, e.clientY),
      pointerup: () => console.log('Drag ended'),
      pointercancel: () => console.log('Drag cancelled'),
    }),
  )

  return null
}
```

## Features

- The event type and `event` argument narrow from the target: `window` `keydown` gives a `KeyboardEvent`, `window` `resize` gives a `UIEvent`.
- Returns a `detach` cleanup function. When called in an owned scope (such as a component body), cleanup also registers with `onCleanup` automatically; in ownerless Solid 2 callbacks (such as `onSettled` or the apply phase of `createEffect`), return the `detach` function so Solid runs it on teardown.
- A `null` or `undefined` target is a no-op; no listener is attached and a no-op `detach` function is returned.
- The hooks are not reactive. They read `target`, `type`, and `options` once. To follow a changing target, call them in the apply phase of `createEffect(target, (el) => createEventListener(el, ...))` and return the `detach` result.
- Call them from a component body, `onSettled`, or an effect's apply phase. Do not call them inside a `ref` callback.
