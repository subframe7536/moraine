## Import

```tsx
import { SidebarFrame, SidebarFrameSheetResizableRender } from 'moraine'
```

## Slot Structure

Root frame containing a sidebar with optional header/footer and a scrollable main area.

```text
root
├── sidebar
│   ├── sidebarHeader (optional)
│   ├── sidebarBody
│   └── sidebarFooter (optional)
└── main
```
