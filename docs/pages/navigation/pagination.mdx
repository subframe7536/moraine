## Slot Structure

Page controls with previous, next, and numbered page link buttons.

```text
root
└── list
    ├── item (prev)
    │   └── prev (Button)
    ├── item (×n, page links)
    │   └── link (Button)
    └── item (next)
        └── next (Button)
```
