Moraine is a SolidJS component library with atomic class styling. It is **pre-1.0; breaking changes may occur**.

[Browse the component directory](#component-directory) · [Configure styling](/styling) · [Read TypeScript guidance](/typescript)

## Setup

1. Install Moraine and SolidJS with your package manager.

```shell title="bun" group-id="install"
bun add moraine
```

```shell title="pnpm" group-id="install"
pnpm add moraine
```

```shell title="npm" group-id="install"
npm install moraine
```

2. Configure either [UnoCSS](/styling#unocss) or [Tailwind CSS](/styling#tailwind-css) before rendering components. Both integrations expose Moraine's semantic tokens and component utilities.

3. Import the components you need from `moraine`, then use the directory below to move to their API pages.
