## Import

```tsx
import { Modal } from 'moraine'
import type { ModalT } from 'moraine'
```

Use Modal when you need to compose backdrop, trigger, and content directly. Use [Dialog](/dialog) for a structured title, description, body, and footer.

## Anatomy

```text
Modal (state provider)
├── Modal.Trigger
├── Modal.Overlay (portal backdrop)
└── Modal.Content (portal surface)
    └── children ({ close })
```

- `Modal`: Coordinates open state and dismissal behavior; it does not render a DOM root of its own.
- `Modal.Trigger`: Polymorphic element that opens the modal.
- `Modal.Overlay`: Portaled backdrop layer with entry/exit motion.
- `Modal.Content`: Portaled dialog content surface.

## Usage

### Composition

Compose `Modal.Trigger` with `Modal.Overlay` and `Modal.Content`. The root renders no element, so put direct `class` and `style` on the rendered parts; root `classes` and `styles` set defaults for this Modal. Overlay and Content render through a Portal and coordinate exit motion and focus. Use `Dialog` or `Sheet` when you need their structured content regions. See [Styling](/styling/overrides#override-component-styles).

<Preview path="./modal-composition" />

### State, styling, and exit lifecycle

Use `open` with `onOpenChange` for controlled visibility. `onExitComplete` waits for the overlay and content exit animations to finish. An empty `class` does not disable built-in styles.

<Preview path="./modal-lifecycle" />

### Keyboard interaction

| Key                    | Description                                        |
| ---------------------- | -------------------------------------------------- |
| <kbd>Escape</kbd>      | Requests dismissal when `dismissible={true}`.      |
| <kbd>Tab</kbd>         | Moves focus forward within the modal focus scope.  |
| <kbd>Shift + Tab</kbd> | Moves focus backward within the modal focus scope. |
