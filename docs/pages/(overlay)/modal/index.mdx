## Features

- **Composable Primitives**: `Modal`, `Modal.Trigger`, `Modal.Overlay`, and `Modal.Content` separate state, trigger, backdrop overlay, and content responsibilities.
- **Overridable Defaults**: `Modal.Overlay` and `Modal.Content` provide default layout, surface, and transition classes. Supplying a custom content `class` replaces the default content class set.
- **Focus Management**: Keeps focus within the active modal surface and restores focus when it closes.
- **Scroll Lock & Portal Rendering**: Portals modal overlay and content, and prevents background body scrolling while open.
- **Dismissal & Overlay Control**: Configure outside/Escape dismissal and optional overlay rendering.
- **Dialog Semantics**: Supports `ariaLabel`, `ariaLabelledBy`, and the dialog role on the content surface.

## Anatomy

```text
Modal (state provider)
├── Modal.Trigger
├── Modal.Overlay (portal backdrop)
└── Modal.Content (portal surface)
    └── children ({ close })
```

- `Modal`: Coordinates open state and dismissal behavior; it does not render a DOM root of its own.
- `Modal.Trigger`: Polymorphic element that opens the modal.
- `Modal.Overlay`: Portaled backdrop layer with entry/exit motion.
- `Modal.Content`: Portaled dialog content surface.

## Usage

### Composition

`Modal` is a state provider, not a DOM root. Compose `Modal.Trigger` with `Modal.Overlay` and `Modal.Content`; the overlay and content are portaled and coordinate exit motion and focus behavior. Use `Dialog` or `Sheet` when their structured shell is a closer fit.

<Preview path="./modal-composition" />

### State, styling, and exit lifecycle

Use `open` with `onOpenChange` for controlled visibility. `Modal.Content` applies default popup classes only when its `class` is omitted; provide a class when the application owns the content animation. `onExitComplete` waits for the registered overlay and content exit presence to finish.

<Preview path="./modal-lifecycle" />

### Keyboard interaction

| Key                    | Description                                        |
| ---------------------- | -------------------------------------------------- |
| <kbd>Escape</kbd>      | Requests dismissal when `dismissible={true}`.      |
| <kbd>Tab</kbd>         | Moves focus forward within the modal focus scope.  |
| <kbd>Shift + Tab</kbd> | Moves focus backward within the modal focus scope. |
