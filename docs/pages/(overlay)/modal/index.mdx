## Composition

`Modal` owns state, scroll locking, focus containment, dismissal, and nested-overlay behavior.
`Modal.Trigger` renders a native button by default, and accepts `as` for a different intrinsic root
or a component such as `Button`. `Modal.Content` owns the portal and renders the overlay and content
as sibling surfaces. Set `overlay` to render the optional backdrop.

When `Modal.Content` does not receive a `class`, it uses the default popup transition classes
(`data-expanded:animate-popup-in` and `data-closed:animate-popup-out`). Passing `class` replaces
the default content classes completely, so custom surfaces can provide their own layout and motion.

```text
Modal
├── Modal.Trigger
└── Modal.Content (portal)
    ├── overlay (optional)
    └── content
        └── custom content
```

Provide `ariaLabel`, `ariaLabelledBy`, or another accessible naming strategy for every modal.
