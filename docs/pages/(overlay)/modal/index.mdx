## Features

- **Unopinionated Headless Architecture**: Pure structural primitives (`Modal`, `Modal.Trigger`, `Modal.Content`) with complete styling freedom.
- **Robust Focus Trap & Restore**: Automatically restricts Tab navigation inside the active surface and restores focus accurately on close.
- **Scroll Lock & Portal Rendering**: Renders outside the main DOM tree via Portal and safely prevents background body scroll bleed.
- **Dismissible & Backdrop Control**: Configure backdrop overlay rendering and handle click-outside or ESC dismissal.
- **WAI-ARIA Dialog Compliance**: Supports `ariaLabel`, `ariaLabelledBy`, and `role="dialog"`.

## Anatomy

Hierarchical slot and element structure:

```text
Modal (state root & focus manager)
├── Modal.Trigger (clickable opener button)
└── Modal.Content (portal container)
    ├── overlay (optional backdrop screen)
    └── content (custom surface card)
        └── contentRender ({ close, open })
```

- `Modal`: Coordinates open/close signals and keyboard event listeners.
- `Modal.Trigger`: Polymorphic element opening the modal on click.
- `Modal.Content`: Portaled container rendering backdrop and surface.

## Keyboard Interactions

| Key                    | Description                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| <kbd>Escape</kbd>      | Dismisses the modal when `dismissible={true}`.                       |
| <kbd>Tab</kbd>         | Cycles forward through focusable elements inside the modal surface.  |
| <kbd>Shift + Tab</kbd> | Cycles backward through focusable elements inside the modal surface. |
