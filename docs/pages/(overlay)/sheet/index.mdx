## Import

Import the component and its companion types from the package root:

```tsx
import { Sheet } from 'moraine'
import type { SheetT } from 'moraine'
```

## Features

- **4 Edge Slide Directions**: Opens smoothly from `right` (inspector panel), `left` (mobile navigation), `bottom` (action sheet), or `top` (notification drawer).
- **Focus Containment & Trapping**: Maintains keyboard Tab focus within the active drawer and restores focus upon dismissal.
- **Scroll Lock & Backdrop Overlay**: Freezes background viewport scrolling and provides a dark backdrop.
- **Structured Content Slots**: Predefined slots for `title`, `description`, `body`, `actions`, `footer`, and `close`.
- **Dismissible & Outside Interaction Control**: Supports click-outside and Escape dismiss with prevention callbacks.

## Anatomy

Hierarchical slot and element structure:

```text
trigger (button opening drawer)
├── overlay (dark backdrop screen)
└── content (sliding drawer panel)
    ├── header (top region)
    │   ├── wrapper
    │   │   ├── title (accessible drawer title)
    │   │   └── description (subheading text)
    │   ├── actions (optional custom toolbar buttons)
    │   └── close (top-right close icon button)
    ├── body (scrollable main content area)
    └── footer (bottom actions / buttons)
```

- `trigger`: Element launching the slideover drawer.
- `overlay`: Backdrop element handling click-to-dismiss.
- `content`: Sliding sheet element positioned along viewport edges.

## Usage

### Structured drawer

Use `side` to choose the viewport edge, then compose title, description, body, actions, and footer through the provided regions. Sheet is the structured alternative to manually composing a Modal surface.

### State and dismissal

Use controlled open state when a layout owns visibility. Disable normal dismissal only when the sheet has a clear explicit close action; `onClosePrevent` receives blocked outside or Escape attempts.

### Keyboard interaction

| Key                    | Description                                                  |
| ---------------------- | ------------------------------------------------------------ |
| <kbd>Escape</kbd>      | Dismisses the open sheet and returns focus to the trigger.   |
| <kbd>Tab</kbd>         | Cycles forward through focusable elements inside the sheet.  |
| <kbd>Shift + Tab</kbd> | Cycles backward through focusable elements inside the sheet. |
