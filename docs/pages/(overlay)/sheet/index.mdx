## Slot Structure

Polymorphic trigger root with optional backdrop and a sliding panel with title, body, footer, and close slots.

```text
trigger
├── overlay (optional)
└── content (portal)
    ├── header (optional)
    │   ├── wrapper (optional)
    │   │   ├── title (optional)
    │   │   └── description (optional)
    │   ├── actions (optional)
    │   └── close (optional)
    ├── body (optional)
    └── footer (optional)
```
