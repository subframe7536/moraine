import { Button, Input, Sheet } from '@src'

## Import

Import the component and its companion types from the package root:

```tsx
import { Sheet } from 'moraine'
import type { SheetT } from 'moraine'
```

Use Sheet for a focused drawer from a viewport edge, such as mobile navigation or an inspector. It shares modal dismissal and focus behavior with its overlay family.

## Anatomy

`Sheet` does not render a DOM element itself. It coordinates its Trigger and Content. Content children fill the body unless you provide a `body` prop.

Hierarchical slot and element structure:

```text
Root (context only)
├── Trigger (button opening drawer)
├── overlay (dark backdrop screen)
└── content (sliding drawer panel)
    ├── header (optional top region)
    │   ├── title (accessible drawer title)
    │   └── description (subheading text)
    ├── contentClose (optional top-right close icon button)
    ├── body (scrollable main content area)
    └── footer (bottom actions / buttons)
```

- `trigger`: Element launching the slideover drawer.
- `overlay`: Backdrop element handling click-to-dismiss.
- `content`: Sliding sheet element positioned along viewport edges.

Put DOM attributes and direct `class` or `style` on the part that renders the element. Root `classes` and `styles` provide defaults for this Sheet instance. See [Styling](/styling#override-component-styles) for how overrides combine.

`Sheet.Close` closes the Sheet and accepts its own `class` and `style`, but does not receive the automatic corner-close styling. With `close={true}`, `Sheet.Content` renders the `contentClose` button even with a custom `header`. Put primary actions in `footer` or supply a custom header.

## Usage

### Structured drawer

Use `side` to choose the viewport edge, then compose title, description, body, and footer through the provided regions. Sheet is the structured alternative to manually composing a Modal surface.

<Preview path="./drawer-usage" />

### State and dismissal

Use controlled open state when a layout owns visibility. Disable normal dismissal only when the sheet has a clear explicit close action; `onClosePrevent` receives blocked outside or Escape attempts.

<Preview path="./state-usage" />

### Keyboard interaction

| Key                    | Description                                                  |
| ---------------------- | ------------------------------------------------------------ |
| <kbd>Escape</kbd>      | Dismisses the open sheet and returns focus to the trigger.   |
| <kbd>Tab</kbd>         | Cycles forward through focusable elements inside the sheet.  |
| <kbd>Shift + Tab</kbd> | Cycles backward through focusable elements inside the sheet. |
