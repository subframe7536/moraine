import { Button, Input, Sheet } from '@src'

## Import

Import the component and its companion types from the package root:

```tsx
import { Sheet } from 'moraine'
import type { SheetT } from 'moraine'
```

Use Sheet for a focused drawer from a viewport edge, such as mobile navigation or an inspector. It shares modal dismissal and focus behavior with its overlay family.

## Anatomy

`Sheet` coordinates its Trigger and Content without rendering a root DOM element. The structured regions are independent parts:

```text
Sheet
├── Trigger
├── Close
└── Content
    ├── Header
    │   ├── Title
    │   ├── Description
    │   └── Action
    ├── contentClose
    ├── Body
    └── Footer
```

Set `title` and `description` on Content for a simple header:

```tsx
<Sheet>
  <Sheet.Content title="Settings" description="Update your account.">
    <Sheet.Body>...</Sheet.Body>
    <Sheet.Footer>...</Sheet.Footer>
  </Sheet.Content>
</Sheet>
```

For full composition, create the header explicitly:

```tsx
<Sheet.Content>
  <Sheet.Header>
    <Sheet.Title>Settings</Sheet.Title>
    <Sheet.Description>Update your account.</Sheet.Description>
    <Sheet.Action>...</Sheet.Action>
  </Sheet.Header>
  <Sheet.Body>...</Sheet.Body>
  <Sheet.Footer>...</Sheet.Footer>
</Sheet.Content>
```

Explicit `Sheet.Header` replaces the header generated by Content `title` and `description`. `Sheet.Title` and `Sheet.Description` register their actual IDs for the surface's ARIA relationships. Without a title, supply root `ariaLabel` or native ARIA attributes on Content. Configure the overlay, side, inset layout, transition, focus trap, and automatic close button on the root. `Sheet.Action` is the header-side action region; `contentClose` is the automatic corner close rendered by Content. `Sheet.Close` is a separate close control you can place anywhere inside the root.

Set `class` or `style` directly on each part. Root `classes` and `styles` provide family-wide slot defaults; Content `classes` and `styles` configure only `overlay`, `content`, and `contentClose`. See [Styling](/styling/customization#style-overrides).

## Usage

### Structured drawer

Set root `side` to choose the viewport edge, then compose title, description, body, and footer through the provided regions. Sheet is the structured alternative to manually composing a Modal surface.

<Preview path="./drawer-usage" />

### State and dismissal

Use controlled open state when a layout owns visibility. Disable normal dismissal only when the sheet has a clear explicit close action; `onClosePrevent` receives blocked outside or Escape attempts.

<Preview path="./state-usage" />

### Keyboard interaction

| Key                    | Description                                                  |
| ---------------------- | ------------------------------------------------------------ |
| <kbd>Escape</kbd>      | Dismisses the open sheet and returns focus to the trigger.   |
| <kbd>Tab</kbd>         | Cycles forward through focusable elements inside the sheet.  |
| <kbd>Shift + Tab</kbd> | Cycles backward through focusable elements inside the sheet. |
