## Import

```tsx
import { Tooltip } from 'moraine'
```

## Slot Structure

Polymorphic trigger root with a floating content portal containing text and optional keyboard hints.

```text
trigger
└── content (portal)
    ├── text (optional)
    └── kbds (optional)
        └── kbd (×n)
```
