## Import

```tsx
import { Tooltip } from 'moraine'
import type { TooltipT } from 'moraine'
```

## Features

- **Hover & Focus Triggers**: Opens from pointer hover or focus and uses configured open/close timing.
- **Shortcut Keycaps**: `kbds` renders the provided shortcut keys with Moraine's Kbd components.
- **Inverted Styling**: `invert` switches the tooltip color treatment.
- **Floating Placement**: Uses the shared Floating UI positioning layer for placement and collision handling.
- **Tooltip Semantics**: The floating hint uses `role="tooltip"` and associates itself with the trigger through the shared overlay trigger metadata.

Tooltips should contain supplemental, non-interactive information. Do not rely on tooltip text as the only way to label an otherwise unlabeled control.

```text
trigger
└── content (portal, role="tooltip")
    ├── text (optional)
    └── kbds (optional)
        └── kbd (×n)
```

## Usage

### Supplemental information

Use tooltips for non-interactive hints that supplement an already labeled trigger. Do not use tooltip text as the sole accessible name of an icon-only control.

### Triggering and shortcuts

Tooltip opens from pointer hover and focus. `kbds` displays shortcut notation alongside the hint; it does not register that shortcut.

### Keyboard interaction

Focusing a focusable trigger can display the tooltip. Escape dismisses an open tooltip according to the shared tooltip overlay behavior; focus remains on the trigger rather than moving into the tooltip content.
