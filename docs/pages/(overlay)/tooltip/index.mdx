## Features

- **Hover & Focus Synchronization**: Automatically displays on pointer hover or keyboard Tab focus with debounced delay timing.
- **Embedded Shortcut Keycaps (`kbds`)**: Pass an array of keys (`kbds={['⌘', 'K']}`) to automatically render styled inline `Kbd` badges.
- **Color Inversion Variant**: Toggle `invert={true}` for high-contrast dark keycap styling.
- **Floating UI Smart Placements**: Supports all 12 Floating UI alignment coordinates (`top`, `bottom`, `left`, `right`) with auto-flip and collision avoidance.
- **WAI-ARIA Tooltip Pattern**: Uses `role="tooltip"` with `aria-describedby` linking the trigger to the hint text for screen readers.

## Anatomy

Hierarchical slot and element structure:

```text
trigger (hoverable / focusable element)
└── content (floating tooltip portal)
    ├── text (informational label string)
    └── kbds (inline keyboard shortcut container, optional)
        └── kbd (individual key badge ×n)
```

- `trigger`: Component or HTML element accepting pointer and focus handlers.
- `content`: Portaled floating pill container with fade and scale animations.
- `kbds`: Slot displaying keyboard shortcut combinations.

## Keyboard Interactions

| Key               | Description                                                             |
| ----------------- | ----------------------------------------------------------------------- |
| <kbd>Tab</kbd>    | Focusing the trigger element displays the tooltip after standard delay. |
| <kbd>Escape</kbd> | Dismisses the visible tooltip immediately without shifting focus.       |
