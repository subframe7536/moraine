## Features

- **Pointer-Anchored Positioning**: Opens at the context interaction point and uses the shared floating-positioning layer to stay within available viewport space.
- **Pointer and Touch Triggers**: Supports context-menu pointer interaction and the component's long-press trigger behavior.
- **Nested Submenus**: Menu items can contain nested child menus.
- **Checkbox & Radio Items**: Menu data supports persistent checked items and radio-style single-choice groups.
- **Menu Semantics**: The menu surface and interactive rows expose menu/menuitem semantics and keyboard-highlight state through the shared menu primitive.

## Anatomy

```text
trigger
└── content (floating portal)
    └── group (×n)
        ├── label (optional)
        ├── separator (optional)
        └── item (×n)
            ├── itemLeading
            ├── itemWrapper
            │   ├── itemLabel
            │   └── itemDescription
            └── itemTrailing
```

## Keyboard Interactions

| Key                                             | Description                                                      |
| ----------------------------------------------- | ---------------------------------------------------------------- |
| <kbd>Shift + F10</kbd> / <kbd>ContextMenu</kbd> | Opens from a focused trigger when the trigger supports it.       |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>       | Moves the active item through available menu entries.            |
| <kbd>ArrowRight</kbd>                           | Opens an available submenu from its parent item.                 |
| <kbd>ArrowLeft</kbd>                            | Returns from a submenu to its parent menu.                       |
| <kbd>Enter</kbd> / <kbd>Space</kbd>             | Activates the current menu item.                                 |
| <kbd>Escape</kbd>                               | Closes the current menu layer.                                   |
