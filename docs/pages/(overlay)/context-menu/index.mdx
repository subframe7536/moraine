## Import

```tsx
import { ContextMenu } from 'moraine'
import type { ContextMenuT } from 'moraine'
```

Use ContextMenu for actions tied to a specific surface or item at the pointer location. Keep essential actions discoverable through another visible path.

## Anatomy

```text
ContextMenu (state only; no DOM)
├── trigger (ContextMenu.Trigger)
├── overlay (optional; portaled while mounted)
└── positioner (internal; portaled while mounted)
    └── content (ContextMenu.Content)
        ├── group (×n)
        │   ├── groupLabel (optional)
        │   └── item (×n)
        ├── item (ungrouped, ×n)
        │   ├── itemLeading (optional)
        │   ├── itemWrapper (optional)
        │   │   ├── itemLabel (optional)
        │   │   └── itemDescription (optional)
        │   └── itemTrailing
        │       ├── itemKbds (optional)
        │       ├── itemIndicator (optional)
        │       └── itemSubIndicator (optional)
        └── separator (×n)
```

Items inside a group use the same subtree as ungrouped items. Put native surface attributes on Content. Root `classes` and `styles` set defaults for this menu; Content can override its slots, including nested submenu layers. See [Styling](/styling/customization#style-overrides).

## Usage

### Triggering the menu

Wrap the target with `ContextMenu.Trigger`. The menu opens from a context-menu gesture, keyboard context-menu keys, or a supported touch/pen long press. Avoid putting essential actions only in a context menu.

<Preview path="./trigger-usage" />

### Item models

Groups, separators, checkbox items, radio items, disabled items, and nested children are all represented in the public item model. Keep state for checkbox and radio values in the application and update it through item callbacks.

<Preview path="./items-usage" />

### Keyboard interaction

| Key                                             | Description                                                |
| ----------------------------------------------- | ---------------------------------------------------------- |
| <kbd>Shift + F10</kbd> / <kbd>ContextMenu</kbd> | Opens from a focused trigger when the trigger supports it. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>       | Moves the active item through available menu entries.      |
| <kbd>ArrowRight</kbd>                           | Opens an available submenu from its parent item.           |
| <kbd>ArrowLeft</kbd>                            | Returns from a submenu to its parent menu.                 |
| <kbd>Enter</kbd> / <kbd>Space</kbd>             | Activates the current menu item.                           |
| <kbd>Escape</kbd>                               | Closes the current menu layer.                             |
