## Features

- **Precise Cursor Coordinate Anchoring**: Opens positioned exactly at the cursor point, with smart viewport edge avoidance and auto-flipping.
- **Mobile Long-Press Support**: Automatically detects touch pointer dwell events on mobile/tablet touchscreens.
- **Nested Cascading Submenus**: Multi-level submenu trees with intelligent pointer intent heuristics.
- **Checkbox & Radio Option Items**: Support persistent toggles and mutually exclusive group selections inside the menu.
- **WAI-ARIA Menu Standards**: Full implementation of `role="menu"`, `role="menuitem"`, active-descendant highlight, and roving arrow navigation.

## Anatomy

Hierarchical slot and element structure:

```text
trigger (right-click target area)
└── content (floating overlay portal)
    └── group (grouped section container ×n)
        ├── label (group category title, optional)
        ├── separator (divider line, optional)
        └── item (individual menu action ×n)
            ├── itemLeading (icon or check indicator)
            ├── itemWrapper
            │   ├── itemLabel (action title)
            │   └── itemDescription (subtext or trailing hint)
            └── itemTrailing (keyboard shortcut kbd badges or submenu chevron)
```

- `trigger`: Area listening for `contextmenu` and long-press touch events.
- `content`: Floating menu panel container.
- `item`: Selectable menu row with focus highlight and click handler.

## Keyboard Interactions

| Key                                             | Description                                                      |
| ----------------------------------------------- | ---------------------------------------------------------------- |
| <kbd>Shift + F10</kbd> / <kbd>ContextMenu</kbd> | Opens the context menu on the focused trigger element.           |
| <kbd>ArrowDown</kbd>                            | Moves highlight to the next menu item.                           |
| <kbd>ArrowUp</kbd>                              | Moves highlight to the previous menu item.                       |
| <kbd>ArrowRight</kbd>                           | Opens a nested submenu when focused on a submenu trigger.        |
| <kbd>ArrowLeft</kbd>                            | Closes the open submenu and returns focus to the parent trigger. |
| <kbd>Enter</kbd> / <kbd>Space</kbd>             | Activates the highlighted menu item and closes the menu.         |
| <kbd>Escape</kbd>                               | Closes the open context menu.                                    |
