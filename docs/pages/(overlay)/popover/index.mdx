## Features

- **Floating UI Positioning**: Anchors to the trigger and uses the shared Popper positioning layer for collision-aware placement.
- **Click & Hover Modes**: `mode="click"` is the default; hover mode supports `openDelay` and `closeDelay` and also responds to trigger focus/blur.
- **Dismissal Control**: Outside interaction and Escape close a dismissible popover. With `dismissible={false}`, those close attempts are prevented and can be observed through `onClosePrevent`.
- **Optional Modal Behavior**: `modal` and `preventScroll` are forwarded to the underlying Popper primitive when modal interaction is required.
- **Dialog Semantics**: The floating content uses `role="dialog"`; provide `ariaLabel` when the dialog does not have another accessible naming mechanism.

## Keyboard Interactions

Keyboard behavior depends on the trigger element and Popper mode. Escape requests dismissal when the popover is dismissible; focusable controls inside the content participate in normal document focus order. Moraine does not imply a focus trap unless modal behavior is explicitly enabled by the underlying overlay configuration.
