## Features

- **Floating UI Coordinate Positioning**: Anchors precisely to the trigger element with collision detection, shift, and auto-flip protection.
- **Click & Hover Trigger Modes**: Open on click for forms/actions, or on hover with custom `openDelay` and `closeDelay` for rich preview cards.
- **Dismissible & Outside Interaction Control**: Smooth dismiss on outside clicks or Escape, with option to lock interaction (`dismissible={false}`).
- **WAI-ARIA Dialog Role**: Supports `aria-haspopup="dialog"`, `aria-expanded`, and focus containment.

## Anatomy

Hierarchical slot and element structure:

```text
trigger (button or element opening popover)
└── content (floating panel portal)
    └── body (custom content card)
```

- `trigger`: Element receiving click or hover listeners.
- `content`: Portaled floating container with entering/exiting animations.
- `body`: Surface rendering custom form controls or rich information.

## Keyboard Interactions

| Key                                 | Description                                                          |
| ----------------------------------- | -------------------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Opens the popover when focused on the trigger button.                |
| <kbd>Escape</kbd>                   | Closes the open popover and restores focus to the trigger.           |
| <kbd>Tab</kbd>                      | Navigates through interactive form controls inside the popover body. |
