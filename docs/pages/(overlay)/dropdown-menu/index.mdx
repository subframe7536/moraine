## Import

```tsx
import { DropdownMenu } from 'moraine'
import type { DropdownMenuT } from 'moraine'
```

## Features

- **Floating UI Positioning**: Anchors the menu to its trigger through Moraine's shared floating-positioning primitive.
- **Groups & Separators**: Organize menu items into labeled sections.
- **Nested Submenus**: Items can open child menus; nesting depth should be chosen with usability and layout constraints in mind rather than treated as unbounded.
- **Checkbox & Radio Items**: Menu data supports toggle state and radio-style single-choice groups.
- **Menu Semantics**: The shared menu behavior exposes menu/menuitem roles, highlighted state, and keyboard navigation without claiming conformance beyond the implemented behavior.

## Anatomy

```text
trigger
└── content (floating portal)
    └── group (×n)
        ├── label (optional)
        ├── separator (optional)
        └── item (×n)
            ├── itemLeading
            ├── itemWrapper
            │   ├── itemLabel
            │   └── itemDescription
            └── itemTrailing
```

## Usage

### Trigger and items

Render the trigger with the provided props so the menu can provide its click, keyboard, and ARIA behavior. Describe each action in the item model; groups and separators organize that model without adding application state.

### Stateful and nested items

Checkbox and radio-like menu items receive their checked or selected state from your application through their callbacks. Nested children create submenus. Disabled items remain visible but cannot be activated.

### Keyboard interaction

| Key                                                        | Description                                           |
| ---------------------------------------------------------- | ----------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> | Opens the menu from an eligible trigger interaction.  |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>                  | Moves the active item through available menu entries. |
| <kbd>ArrowRight</kbd>                                      | Opens an available submenu from its parent item.      |
| <kbd>ArrowLeft</kbd>                                       | Returns from a submenu to its parent menu.            |
| <kbd>Enter</kbd> / <kbd>Space</kbd>                        | Activates the current menu item.                      |
| <kbd>Escape</kbd>                                          | Closes the current menu layer.                        |
