## Features

- **Anchored Floating Overlay**: Automatically positions relative to the trigger using Floating UI with smart collision detection and auto-flip.
- **Categorized Sections & Separators**: Organize action items into clean labeled groups with hairline dividers.
- **Multi-Level Submenus**: Supports infinite submenu nesting with smooth delay timers and diagonal pointer guidance.
- **Checkbox & Radio Menu Items**: Supports toggle states and single-choice lists directly inside the dropdown.
- **WAI-ARIA Menu Standards**: Strict conformance to `role="menu"` and `role="menuitem"`, with roving focus and keyboard activation.

## Anatomy

Hierarchical slot and element structure:

```text
trigger (button launching dropdown)
└── content (floating overlay portal)
    └── group (section container ×n)
        ├── label (group header, optional)
        ├── separator (hairline divider line, optional)
        └── item (individual action item ×n)
            ├── itemLeading (icon, avatar, or check indicator)
            ├── itemWrapper
            │   ├── itemLabel (action title)
            │   └── itemDescription (subtext or trailing shortcut hint)
            └── itemTrailing (kbd shortcuts or nested submenu chevron)
```

- `trigger`: Component or element receiving pointer/click handlers.
- `content`: Floating menu card rendered via portal.
- `item`: Selectable row executing an action on click or Enter.

## Keyboard Interactions

| Key                                                        | Description                                                       |
| ---------------------------------------------------------- | ----------------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> | Opens the dropdown menu and focuses the first item.               |
| <kbd>ArrowDown</kbd>                                       | Moves highlight to the next menu item.                            |
| <kbd>ArrowUp</kbd>                                         | Moves highlight to the previous menu item.                        |
| <kbd>ArrowRight</kbd>                                      | Opens a nested submenu when focused on a submenu trigger.         |
| <kbd>ArrowLeft</kbd>                                       | Closes the open submenu and returns focus to the parent trigger.  |
| <kbd>Enter</kbd> / <kbd>Space</kbd>                        | Executes the highlighted action and closes the menu.              |
| <kbd>Escape</kbd>                                          | Closes the dropdown menu and returns focus to the trigger button. |
