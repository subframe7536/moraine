## Features

- **Automated Focus Trapping & Restoration**: Keeps keyboard navigation constrained within the modal while open, and restores focus back to the triggering element upon dismissal.
- **Scroll Locking & Backdrop Blur**: Locks background document scrollbars and renders an accessible backdrop overlay.
- **Structured Content Slots**: Out-of-the-box slots for `title`, `description`, `body`, `footer`, and top-right `close` button.
- **Fullscreen & Prevent-Close Controls**: Enable `fullscreen` mode for mobile/tablet workflows, or intercept dismissal attempts with `preventClose`.
- **WAI-ARIA Dialog Role**: Automatically injects `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, and `aria-describedby`.

## Anatomy

Hierarchical slot and element structure:

```text
trigger (element opening the dialog)
├── overlay (dark backdrop overlay with blur)
└── content (floating centered modal card)
    ├── header (modal header region)
    │   ├── wrapper
    │   │   ├── title (accessible modal heading)
    │   │   └── description (subheading description)
    │   └── close (top-right dismiss icon button)
    ├── body (scrollable body container)
    └── footer (bottom actions container, e.g. Cancel / Confirm)
```

- `trigger`: Component or element receiving click handler to launch dialog.
- `overlay`: Translucent screen blocker intercepting outside clicks.
- `content`: Floating centered modal panel.
- `header` / `body` / `footer`: Structured regions.

## Keyboard Interactions

| Key                                 | Description                                                          |
| ----------------------------------- | -------------------------------------------------------------------- |
| <kbd>Escape</kbd>                   | Dismisses the dialog (unless `preventClose` is active).              |
| <kbd>Tab</kbd>                      | Cycles focus forward through interactive controls inside the dialog. |
| <kbd>Shift + Tab</kbd>              | Cycles focus backward through interactive controls.                  |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused button inside the dialog.                      |
