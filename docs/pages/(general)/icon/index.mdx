## Features

- **UnoCSS Pure CSS Icon Integration**: Effortlessly load any Iconify glyph (`i-lucide:sparkles`, `i-simple-icons:github`) via pure CSS masking.
- **Custom JSX & SVG Support**: Accepts custom SVG JSX components, render functions, or string class names interchangeably.
- **Dynamic Numeric Sizing**: Pass numeric pixel values (`size={24}`) or UnoCSS utility sizes (`class="size-6"`).
- **Accessible By Default**: Injects `aria-hidden="true"` by default for decorative icons.

## Anatomy

Hierarchical slot and element structure:

```text
root (span with pure CSS icon mask or embedded SVG)
```

- `root`: An inline-block `<span role="img">` or custom SVG node styled with currentColor.
