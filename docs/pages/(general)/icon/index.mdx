## Features

- **UnoCSS Icon Classes**: String names are applied as icon utility classes, including application-defined aliases such as `icon-search`.
- **JSX & Component Sources**: `name` can also be a JSX node or Solid component.
- **Explicit Sizing**: Numeric `size` values are interpreted as pixels; string values are passed through as CSS font-size values.
- **Decorative by Default**: When no `aria-label` is provided, the rendered icon receives `aria-hidden="true"`. Add an accessible label when the icon itself carries meaning.

## Anatomy

```text
root (dynamic icon element)
```

For string icon names, `Icon` renders a `<div>` by default and applies the string as a class. JSX nodes and components are rendered through Solid's dynamic component mechanism. The root receives `data-slot="icon"` unless `slotName` overrides it.
