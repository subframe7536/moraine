## Features

- **Single & Multiple Expansion Modes**: Allow only one section open at a time (`single`) or multiple concurrent open panels (`multiple`).
- **Smooth Height Transitions**: Animates expanding and collapsing states cleanly without layout pops or calculation glitches.
- **WAI-ARIA Disclosure Pattern**: Follows W3C Accordion practices using proper `<button>` triggers with `aria-expanded` and `aria-controls`.
- **Leading & Trailing Slot Customization**: Easily embed icons, badges, status dots, or custom trigger chevron glyphs (`trailing="icon-plus"`).
- **Per-Section Disabling**: Disable locked or permission-gated sections while keeping others interactive.

## Anatomy

Hierarchical slot and element structure:

```text
root (accordion container)
└── item (individual section ×n)
    ├── header (heading wrapper)
    │   └── trigger (clickable button)
    │       ├── leading (icon, optional)
    │       ├── label (section title)
    │       └── trailing (animated chevron or icon)
    └── content (collapsible panel)
```

- `root`: Container element managing shared expansion state.
- `item`: Bounded section wrapper with `data-expanded` attributes.
- `trigger`: Semantic `<button>` handling click and keyboard activation.
- `content`: Animateable body container revealing the section's content.

## Keyboard Interactions

| Key                                 | Description                                                 |
| ----------------------------------- | ----------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Expands or collapses the focused accordion trigger.         |
| <kbd>ArrowDown</kbd>                | Moves focus to the next accordion header trigger.           |
| <kbd>ArrowUp</kbd>                  | Moves focus to the previous accordion header trigger.       |
| <kbd>Home</kbd>                     | Moves focus directly to the first accordion header trigger. |
| <kbd>End</kbd>                      | Moves focus directly to the last accordion header trigger.  |
