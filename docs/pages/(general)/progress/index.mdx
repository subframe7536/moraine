## Import

```tsx
import { Progress } from 'moraine'
```

## Slot Structure

Track with a fill indicator, optional status text, and step labels.

```text
root
├── status (optional, determinate only)
├── track
│   └── indicator
└── steps (optional, step mode)
    └── step (×n)
```
