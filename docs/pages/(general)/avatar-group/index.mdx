## Import

Import the component and its companion types from the package root:

```tsx
import { AvatarGroup } from 'moraine'
import type { AvatarGroupT } from 'moraine'
```

## Features

- **Negative Spacing Stacking**: Automatically overlays avatars with matching background ring borders to cleanly delineate adjacent items.
- **Dynamic Overflow Truncation**: When total items exceed `max`, extra avatars are summarized into an accessible `+N` badge.
- **Cascading Size Control**: Setting `size` on `AvatarGroup` automatically propagates to all nested avatars and the overflow badge.
- **Interactive Depth Elevation**: Individual avatars lift on hover with elevation z-index so users can inspect obscured faces.

## Anatomy

Hierarchical slot and element structure:

```text
root (horizontal avatar stack)
├── item (individual Avatar instance ×n)
│   ├── image
│   ├── fallback
│   └── badge
└── count (overflow counter pill "+N")
```

- `root`: Flex container applying negative horizontal margins and border rings.
- `item`: Composed child `Avatar` instances.
- `count`: Badge showing remaining count when `children.length > max`.

## Usage

### Grouping avatars

Use `AvatarGroup` to apply consistent overlap and ordering to a collection of Avatar children. Configure an overflow indicator when only a bounded number should be visible; it communicates a count, not the omitted identities.
