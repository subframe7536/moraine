## Features

- **Image Preloading & Status**: Preloads `src` with `Image` in the browser and exposes `idle`, `loading`, `loaded`, or `error` through `data-status` and `onStatusChange`.
- **Fallback Initials**: Uses explicit `text` when provided; otherwise derives up to two uppercase initials from `alt`.
- **Icon Fallback**: `fallback` can provide an icon instead of fallback text.
- **Status Badge**: Position a badge icon in any corner with `badgePosition`.
- **Accessible Fallback**: The loaded image uses `alt`; while unavailable, fallback content can use `alt` or `text` as its accessible label.

`Avatar` preloads the source before exposing it on the rendered `<img>`. It does not set native `loading="lazy"` automatically.

