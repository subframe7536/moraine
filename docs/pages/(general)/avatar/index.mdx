## Features

- **Graceful Async Loading**: Displays fallback text/initials immediately while the image preloads in the background, preventing blank flashes or layout shifts.
- **Smart Initials Derivation**: Automatically extracts 2-letter uppercase initials from `alt` text if no explicit `text` is provided.
- **Status Badges**: Position presence dots, verified badges, or custom icons at `top-left`, `top-right`, `bottom-left`, or `bottom-right`.
- **Icon Fallback**: Render standard user icons or custom SVGs when no image URL or initials are available.
- **Uniform Size Scale**: Proportional avatar radii and typography across `xs`, `sm`, `md`, `lg`, and `xl`.

## Anatomy

Hierarchical slot and element structure:

```text
root (circular image frame)
├── image (rendered when URL loads successfully)
├── fallback (initials or user glyph)
│   └── fallbackIcon (Icon, rendered if icon fallback)
└── badge (optional status indicator pill or icon)
```

- `root`: Container applying circular clip path, border, and size dimensions.
- `image`: HTML `<img>` tag with lazy loading and error detection.
- `fallback`: Background container displaying formatted initials.
- `badge`: Corner indicator displaying online presence or verification status.
