## Slot Structure

Avatar renders a single image/fallback frame. Use [`AvatarGroup`](/general/avatar-group) for grouped avatars with an overflow counter.

### Single avatar

```text
root
├── image
├── fallback
│   └── fallbackIcon (Icon, optional)
└── badge (optional)
```
