## Import

```tsx
import { List } from 'moraine'
import { useListVirtualizer } from 'moraine/virtualizer'
import type { ListT } from 'moraine'
```

## Features

- **Caller-Controlled Rendering**: `itemRender` receives `{ item, index, props }`, leaving row markup to the caller.
- **Polymorphic Root**: The root defaults to `<ul>` with `role="list"` and can be changed with `as`.
- **Optional Virtual Rendering**: `virtualRender` replaces normal iteration with a caller-provided renderer.
- **Virtualizer Helper**: `useListVirtualizer` can be used with `virtualRender` to render only the visible portion of larger collections and pass row measurement props to `itemRender`.

`List` itself does not impose a dataset-size or frame-rate guarantee; virtualization performance depends on row content, browser workload, and virtualizer configuration.

## Anatomy

```text
root (<ul> by default)
└── itemRender ({ item, index, props } ×n)
```

When virtualization is enabled, `props` contains attributes supplied by the virtual renderer for the final row element.
