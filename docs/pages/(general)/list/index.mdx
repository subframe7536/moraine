## Features

- **Fine-Grained Item Rendering**: Uses `itemRender` callback receiving `{ item, index }` context for total markup control.
- **Polymorphic Container**: Default semantic `<ul>` root (`role="list"`), easily configurable to `<div>`, `<ol>`, or custom components via `as`.
- **First-Class Virtualization**: Integrates with TanStack Virtual via `useListVirtualizer` for infinite scroll lists of 100,000+ rows.
- **Dynamic Row Height Measurement**: Automatically measures variable-height content cards and re-indexes layout gaps smoothly.

## Anatomy

Hierarchical slot and element structure:

```text
root (semantic <ul> or polymorphic container)
└── itemRender ({ item, index } ×n)
    └── <li> (custom caller-defined row markup)
```

- `root`: Container element with `role="list"` and scroll tracking.
- `itemRender`: High-efficiency Solid JSX factory rendering individual array items.
