## Features

- **Polymorphic Rendering**: Render as a semantic `<button>`, anchor `<a>` link (`as="a"`), or any custom Solid component without losing button styles.
- **Auto-Loading from Async Handlers**: Passing an async promise-returning function to `onClick` automatically displays a loading spinner until the promise resolves.
- **Smart Loading Spinner Placement**: Replaces `leading` icon first, or `trailing` icon if no leading icon is present.
- **Icon Buttons**: Support square icon-only buttons with built-in accessibility labeling.
- **6 Semantic Variants**: Includes `default`, `secondary`, `outline`, `ghost`, `destructive`, and `link`.

## Anatomy

Hierarchical slot and element structure:

```text
root (<button> or polymorphic element)
├── leading (icon, image, or spinner)
├── label (button text children)
└── trailing (icon or shortcut badge)
```

- `root`: Interactive focusable container with hover, active, and focus-visible states.
- `leading`: Left icon slot automatically swapped with an animated spinner when `loading={true}`.
- `trailing`: Right icon slot.
