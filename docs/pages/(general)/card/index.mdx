## Features

- **Structured Section Slots**: Composable `header`, `title`, `description`, `action`, `body`, and `footer` slots for standard UI patterns.
- **Header Action Adornment**: Top-right `action` slot for contextual status badges, dropdown action menus, or close buttons.
- **Comfortable & Compact Densities**: Toggle `compact={true}` for tight table summaries, data density layouts, or sidebar widgets.
- **Media & Cover Image Embedding**: Easily embed edge-to-edge cover images or interactive preview panels.
- **Semantic HTML Tagging**: Renders as an accessible section/article surface with consistent theme border tokens (`bg-card`, `border-border`).

## Anatomy

Hierarchical slot and element structure:

```text
root (card surface container)
├── header (header region)
│   ├── titleWrapper
│   │   ├── title (card heading)
│   │   └── description (subheading text)
│   └── action (top-right badge or button)
├── body (main content area, children)
└── footer (bottom actions / metadata bar)
```

- `root`: Background card container applying surface styling, rounded borders, and shadows.
- `header`: Top row organizing title, description, and action button.
- `body`: Main slot where children are rendered with standard interior padding.
- `footer`: Bottom row bordered action bar for confirmation buttons or secondary links.
