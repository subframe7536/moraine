import { Badge, Button, Card } from '@src'

## Import

```tsx
import { Card } from 'moraine'
import type { CardT } from 'moraine'
```

Use Card to arrange related content and actions on one surface. It does not make the content a document section or supply a heading level.

## Anatomy

```text
root (<div>)
├── header (optional)
│   ├── title (optional)
│   ├── description (optional)
│   └── action (optional)
├── body (children, optional)
└── footer (optional)
```

## Usage

### Structured content

Use the title, description, body, footer, and action regions for a conventional card layout. For a non-standard header, replace that region with custom content rather than forcing text-only props into a richer design.

<Preview path="./card-structure" />

### Semantics

Card is a layout surface. Choose an appropriate root element or add the heading and link semantics required by the surrounding page.
