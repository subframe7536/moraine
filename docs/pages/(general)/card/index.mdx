import { Badge, Button, Card } from '@src'

## Import

```tsx
import { Card } from 'moraine'
import type { CardT } from 'moraine'
```

## Features

- **Structured Regions**: Compose `header`, `title`, `description`, `action`, body children, and `footer` content.
- **Header Override**: Supplying `header` replaces the built-in title/description header content.
- **Compact Spacing**: `compact` reduces header, body, and footer spacing for denser layouts.
- **Flexible Body Content**: The body accepts arbitrary JSX, including media and interactive controls.

`Card` renders a `<div>` root and does not assign document-section semantics automatically. Add suitable headings, landmarks, or ARIA metadata in the surrounding application when the content requires them.

## Anatomy

```text
root (<div>)
├── header (optional)
│   ├── title (optional)
│   ├── description (optional)
│   └── action (optional)
├── body (children, optional)
└── footer (optional)
```

## Usage

### Structured content

Use the title, description, body, footer, and action regions for a conventional card layout. For a non-standard header, replace that region with custom content rather than forcing text-only props into a richer design.

### Semantics

Card is a layout surface. Choose an appropriate root element or add the heading and link semantics required by the surrounding page.
