## Features

- **Seamless Edge Merging**: Automatically removes intermediate border radii and collapses adjacent borders into clean connected button rails.
- **Contextual Prop Inheritance**: Propagates `size` and `variant` to all child buttons, while allowing individual buttons to override them when necessary.
- **Divider Separator**: Enable `separator={true}` to inject decorative hairline divider borders between adjoining button items.
- **Horizontal & Vertical Layouts**: Support both horizontal toolbar segments and vertical control stacks.
- **Split-Button & Dropdown Compositions**: Effortlessly pair primary action buttons with chevron dropdown triggers in a unified pill container.

## Anatomy

Hierarchical slot and element structure:

```text
root (button group container)
├── Button (child button item ×n)
└── separator (hairline divider line between buttons, optional)
```

- `root`: Flex container managing border collapsing and role orientation.
- `separator`: Decorative divider element inserted between consecutive buttons.

## Keyboard Interactions

| Key                                 | Description                                                |
| ----------------------------------- | ---------------------------------------------------------- |
| <kbd>Tab</kbd>                      | Moves focus sequentially through the buttons in the group. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the currently focused button in the group.       |
