import { Button, Card, Collapsible, Icon } from '@src'

## Import

```tsx
import { Collapsible } from 'moraine'
import type { CollapsibleT } from 'moraine'
```

## Features

- **Controlled & Uncontrolled State**: Use `open` with `onOpenChange`, or initialize uncontrolled state with `defaultOpen`.
- **Composable Trigger and Content**: `Collapsible.Trigger` and `Collapsible.Content` can be placed within caller-owned layout.
- **Optional Transition**: `transition` enables the built-in open/close transition for the content region.
- **Disclosure Metadata**: Trigger state is reflected through `aria-expanded` and the trigger/content association.
- **Disabled State**: Disabling the root prevents its trigger from changing disclosure state.

```text
Collapsible (state provider)
├── Collapsible.Trigger
└── Collapsible.Content
    └── content
```

## Usage

### State ownership

Use `open` with `onOpenChange` for controlled state, or `defaultOpen` when the component owns its initial state. The trigger and content primitives may be composed into a custom layout.

<Preview path="./state-ownership" />

### Content lifetime

The content transition and mount behavior are separate choices. Keep content mounted when it holds state that should survive closing; unmount it when inactive content should leave the document.

<Preview path="./content-lifetime" />

### Keyboard interaction

The trigger uses button semantics by default. Polymorphic triggers inherit the keyboard semantics of the supplied element or component.

| Key                                 | Description                                               |
| ----------------------------------- | --------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates a native button trigger and toggles disclosure. |
| <kbd>Tab</kbd>                      | Follows normal document focus order.                      |
