## Features

- **Smooth CSS Height Transitions**: Measures dynamic intrinsic element scrollHeight for fluid zero-to-full height unfolding without jerky jumps.
- **Controlled & Uncontrolled State**: Bind `open` and `onOpenChange` or let the component manage its own `defaultOpen` state internally.
- **Composable Subcomponents**: Assemble complex surfaces freely with `Collapsible.Trigger` and `Collapsible.Content`.
- **WAI-ARIA Disclosure Compliance**: Emits `aria-expanded` and `aria-controls` connecting the trigger button directly to the collapsible panel.
- **Disabled State Propagation**: Disabling the root automatically cascades to all triggers and suppresses expansion events.

## Anatomy

Hierarchical slot and element structure:

```text
root (Collapsible container)
├── Collapsible.Trigger (clickable toggle button)
└── Collapsible.Content (collapsible panel)
    └── content-wrapper (internal zero-height overflow clip)
        └── {children}
```

- `root`: State provider managing open/closed boolean signals.
- `Collapsible.Trigger`: Semantic button or polymorphic trigger toggling open state.
- `Collapsible.Content`: Animated container transitioning `max-height` and `opacity`.

## Keyboard Interactions

| Key                                 | Description                                                                               |
| ----------------------------------- | ----------------------------------------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Toggles the expanded / collapsed state of the focused trigger.                            |
| <kbd>Tab</kbd>                      | Moves focus between the trigger and any interactive elements inside the expanded content. |
