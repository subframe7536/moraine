## Import

```tsx
import { Resizable } from 'moraine'
import type { ResizableT } from 'moraine'
```

`Resizable` owns the whole size vector through `value`/`defaultValue`. Numbers are pixels and percentage strings are relative to the root. Missing or extra entries are normalized against the current panel count. `Resizable.Panel` owns constraints and collapse capability. Place `Resizable.Handle` only where adjacent panels should interact; omitting it leaves the panels adjacent without a separator.

## Anatomy

```text
root (Resizable)
├── panel (Resizable.Panel)
├── handle (Resizable.Handle)
│   ├── intersection (optional)
│   ├── handleControl (optional)
│   └── intersection (optional)
└── panel (Resizable.Panel)
```

Each handle can independently set `action="collapse"`, enable `intersection`, or render a custom grip through its children. Use `children={false}` to keep the divider while omitting the inner grip.

## Usage

### Panel constraints

Give the root `defaultValue` for initial sizes and set each panel's minimum or maximum as needed. The handle changes the sizes of its adjacent panels; a panel without a neighboring handle remains fixed at that boundary. Use `value` with `onChange` when the surrounding layout needs to persist or reset a split. Callbacks return pixel sizes.

### Keyboard interaction

| Key                                          | Description                                                   |
| -------------------------------------------- | ------------------------------------------------------------- |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Resizes in the decreasing direction for the active separator. |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Resizes in the increasing direction for the active separator. |
| <kbd>Home</kbd>                              | Moves the adjacent panel toward its minimum permitted size.   |
| <kbd>End</kbd>                               | Moves the adjacent panel toward its maximum permitted size.   |
| <kbd>Enter</kbd>                             | Toggles the nearest collapsible panel for collapse handles.   |
