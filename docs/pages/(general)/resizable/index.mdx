## Features

- **Pointer Resizing**: Drag separators to resize adjacent panels within their configured constraints.
- **Pixel & Percentage Constraints**: `min`, `max`, and `defaultSize` accept the size forms supported by panel configuration.
- **Collapsible Panels**: Configure collapsible panels and collapsed minimum sizes for compact rails.
- **Nested Layouts**: Compose resizable instances to build multi-axis layouts.
- **Separator Semantics**: Interactive separators expose separator semantics and keyboard resizing controls.

Performance depends on the content rendered inside each panel and the surrounding application; Resizable does not promise a fixed frame rate or zero-latency dragging.

## Keyboard Interactions

| Key                                          | Description                                                     |
| -------------------------------------------- | --------------------------------------------------------------- |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Resizes in the decreasing direction for the active separator.   |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Resizes in the increasing direction for the active separator.   |
| <kbd>Home</kbd>                              | Moves the adjacent panel toward its minimum permitted size.      |
| <kbd>End</kbd>                               | Moves the adjacent panel toward its maximum permitted size.      |
| <kbd>Enter</kbd>                             | Toggles collapse/expand when collapse behavior is configured.    |
