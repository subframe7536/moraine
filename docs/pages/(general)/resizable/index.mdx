## Features

- **Fluid Pointer Dragging**: Smooth hardware-accelerated divider dragging with zero lag and boundary snapping.
- **Pixel & Percentage Constraints**: Set precise `min`, `max`, and `defaultSize` constraints using percentages (`'30%'`) or pixels (`240`).
- **Collapsible Rails**: Click the splitter handle to instantly collapse a sidebar down to a mini rail icon bar.
- **Nested Intersections**: Create 4-quadrant IDE layouts with multi-axis draggable intersection handles.
- **WAI-ARIA Separator Support**: Focusable splitters implementing `role="separator"` with full keyboard resizing.

## Anatomy

Hierarchical slot and element structure:

```text
root (resizable container)
├── panel (individual resizable pane ×n)
└── divider (interactive splitter between adjacent panels)
    ├── cross-target (intersection corner drag hit target)
    └── handle (optional centered grip pill)
```

- `root`: Container managing flex proportions and pointer events.
- `panel`: Bounded container rendering panel children.
- `divider`: Draggable separator with active cursor styling.
- `handle`: Visual grip pill with click-to-collapse support.

## Keyboard Interactions

| Key                                          | Description                                                    |
| -------------------------------------------- | -------------------------------------------------------------- |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd>    | Decreases the preceding panel size by step increment.          |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | Increases the preceding panel size by step increment.          |
| <kbd>Home</kbd>                              | Resizes preceding panel to its minimum permitted bound.        |
| <kbd>End</kbd>                               | Resizes preceding panel to its maximum permitted bound.        |
| <kbd>Enter</kbd>                             | Toggles collapse/expand if the panel is marked as collapsible. |
