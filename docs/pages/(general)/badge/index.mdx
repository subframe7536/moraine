## Features

- **Semantic Visual Variants**: Choose between `default` (soft tone), `outline` (border-only), `solid` (high-contrast primary), and `subtle`.
- **Leading & Trailing Adornments**: Embed status icons, animated spinners, dismissal buttons, or git branch icons effortlessly.
- **Proportional Size Scale**: Three standard sizes (`sm`, `md`, `lg`) adjusting inner padding, font size, and icon dimensions.
- **WAI-ARIA Accessibility**: Rendered as semantic badges with proper inline formatting.

## Anatomy

Hierarchical slot and element structure:

```text
root (badge container)
├── leading (icon or status dot, optional)
├── label (badge text content)
└── trailing (icon or dismiss action, optional)
```

- `root`: Inline-flex container managing rounded corners, border, and typography.
- `leading`: Left icon or status indicator element.
- `trailing`: Right icon or action button element.
