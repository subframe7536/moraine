## Import

```tsx
import { Badge } from 'moraine'
import type { BadgeT } from 'moraine'
```

## Features

- **Visual Variants**: `default`, `outline`, `solid`, and `subtle` presentations share the same content model.
- **Leading & Trailing Adornments**: Add icons or other supported adornment content around the label.
- **Size Scale**: `sm`, `md`, and `lg` adjust padding, typography, and icon sizing.
- **Presentation Semantics**: Badge is presentational text rather than a special ARIA widget. If a badge contains an interactive control, that control must provide its own semantics and accessible name.

## Anatomy

```text
root
├── leading (optional)
├── label
└── trailing (optional)
```

## Usage

Use `Badge` for compact, presentational status or metadata alongside a separately labeled control or heading. It does not add interactive behavior or replace an accessible status announcement where one is required.
