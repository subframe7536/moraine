## Import

Import the component and its companion types from the package root:

```tsx
import { KbdGroup } from 'moraine'
import type { KbdGroupT } from 'moraine'
```

## Features

- **Simultaneous Chords (`items`)**: Joins keys pressed at the same time (e.g. `⌘ + K` or `Ctrl + Shift + P`) with a configurable plus separator.
- **Sequential Multi-Step Chords (`sequence`)**: Supports multi-stage keyboard commands (e.g. `g` then `i` for Git inbox, or `Ctrl+K` then `Ctrl+S`).
- **Custom Dividers**: Customize delimiter characters between simultaneous keys (`+`, `-`) or ordered steps (`then`, `->`).
- **Cascading Size & Variant Propagation**: Uniformly applies size and color styling across all nested keycaps.

## Anatomy

Hierarchical slot and element structure:

```text
root (kbd group container)
├── chord (simultaneous key combination container)
│   ├── item (individual Kbd element ×n)
│   └── divider (separator between keys, e.g. "+")
└── sequenceDivider (delimiter between chord steps, e.g. "then")
```

- `root`: Flex container wrapping shortcut chords in semantic flow order.
- `chord`: Grouping for simultaneous key presses.
- `divider`: Plus sign or joiner glyph.
- `sequenceDivider`: Text separator indicating temporal succession.
