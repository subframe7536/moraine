## Import

Import the component and its companion types from the package root:

```tsx
import { KbdGroup } from 'moraine'
import type { KbdGroupT } from 'moraine'
```

## Features

- **Data-driven Items**: Render one simultaneous shortcut from string keys or `Kbd` item objects.
- **Automatic `Kbd` Rendering**: Every item becomes a generated `Kbd` while preserving accessible labels on object items.
- **Inline Separator**: Customize the notation between keys with text or JSX; `"+"` is used by default.
- **Semantic Root**: The group renders as a `<kbd>` element.
- **Shared Size & Variant**: `size` and `variant` apply uniformly to every generated keycap.

> `separator` is inline shortcut notation such as `"+"`; it is unrelated to the standalone `Separator` layout primitive.

## Anatomy

Hierarchical slot and element structure:

```text
root <kbd>
├── item <kbd>
├── inline separator content
└── item <kbd>
```

The only theme slots are `root` and `item`. Separator content is rendered inline and is not a theme slot.

### Grouping shortcuts

Use `KbdGroup` to display keys that are pressed together. The rendered notation is descriptive and does not register a shortcut.
