
## Features

- **Horizontal & Vertical Orientations**: Controls the line direction and sets matching `aria-orientation` metadata.
- **Border Styles**: Choose `solid`, `dashed`, or `dotted`.
- **Thickness Scale**: `sm`, `md`, and `lg` adjust the rendered separator thickness.
- **Semantic or Decorative Use**: The root always renders as `<div role="separator">`; `decorative` adds `aria-hidden="true"` so assistive technologies ignore it.

## Usage

### Root styling

`Separator` has one `<div>` root. Use direct `class` and `style` props for a local override, or configure `separator.base.root` in your Design for application defaults. It does not accept instance `classes` or `styles` maps.

### Visual and semantic dividers

Use a semantic separator when it marks a real thematic break, and decorative mode for purely visual division. Choose horizontal or vertical orientation to match the surrounding layout.
