## Import

```tsx
import { Separator } from 'moraine'
import type { SeparatorT } from 'moraine'
```

Use Separator to divide related regions with a visible line. Choose its orientation to match the layout boundary.

## Anatomy

```text
root (<div role="separator" aria-orientation data-orientation>)
```

## Usage

### Root styling

`Separator` has one `<div>` root. Use direct `class` and `style` props for a local override, or configure `separator.base.root` in your Theme for application defaults. It does not accept instance `classes` or `styles` maps.

<Preview path="./root-styling" />

### Semantic orientation

Every `Separator` exposes `role="separator"`, `aria-orientation`, and `data-orientation`. Choose horizontal or vertical orientation to match the surrounding layout.
