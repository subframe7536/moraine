## Slot Structure

Wrapper trigger with optional backdrop and a floating panel with title, body, and footer slots.

```text
trigger
├── overlay (optional)
└── content (portal)
    ├── header (optional)
    │   ├── wrapper (optional)
    │   │   ├── title (optional)
    │   │   └── description (optional)
    │   └── close (optional)
    ├── body (optional)
    └── footer (optional)
```
