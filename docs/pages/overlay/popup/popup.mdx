## Import

```tsx
import { Popup } from 'moraine'
```

## Slot Structure

Polymorphic trigger root with an optional backdrop and a floating content portal.

```text
trigger
├── overlay (optional)
└── content (portal)
```

## Accessible Naming

Popup content is exposed as a dialog. Use `title` to render its accessible title and automatically
connect `aria-labelledby`; use `description` for `aria-describedby`. When no title is rendered,
`ariaLabel` provides the accessible name. The `content` prop remains body content and is not inferred
as the dialog name.

```tsx
<Popup title="Account actions" description="Choose an action" content={<div>Actions</div>} />
```
