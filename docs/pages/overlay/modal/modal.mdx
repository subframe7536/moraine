Use `Dialog` or `Sheet` for their standard layouts. Use the Modal primitives when a custom modal
surface cannot be expressed by either component.

## Import

```tsx
import { Modal } from 'moraine'
```

## Composition

`Modal` owns state, scroll locking, focus containment, dismissal, and nested-overlay behavior.
`Modal.Trigger` connects a single trigger element. `Modal.Content` owns the portal and renders the
overlay and content as sibling surfaces. Set `overlay` to render the optional backdrop.

```text
Modal
├── Modal.Trigger
└── Modal.Content (portal)
    ├── overlay (optional)
    └── content
        └── custom content
```

Provide `ariaLabel`, `ariaLabelledBy`, or another accessible naming strategy for every modal.
