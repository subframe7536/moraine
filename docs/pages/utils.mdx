## Styling helpers

`cn` is exported from `moraine` to combine conditional class values and resolve supported utility conflicts.

```tsx
import { cn } from 'moraine'

const className = cn(
  'px-2.5 py-1 bg-primary text-primary-foreground',
  disabled && 'opacity-60 pointer-events-none',
)
```

## Shared hooks

Import low-level hooks from the dedicated subpath:

```tsx
import {
  createContextProvider,
  createMediaQuery,
  useBaseSelectSearchInput,
  useControllableValue,
  useDisclosureState,
  useEventListener,
  useEventListenerMap,
  useLoadingAutoClick,
  useResizableHandle,
  useSearchValue,
  useSelectableCollectionNavigation,
  useSlider,
  useTransitionPresence,
} from 'moraine/utils'

import { useId } from 'moraine'
import { useListVirtualizer } from 'moraine/virtualizer'
```

### `useControllableValue`

Bridge controlled and uncontrolled state with a single accessor/setter pair. `value` may return `undefined` to indicate uncontrolled mode, while the required `defaultValue` accessor supplies a concrete fallback. The returned accessor always resolves to `T`, the setter accepts only `T` or `(previous: T) => T`, and controlled/uncontrolled mode may change reactively.

```tsx
const [value, setValue] = useControllableValue({
  value: () => props.value,
  defaultValue: () => props.defaultValue ?? '',
})
```

### `useDisclosureState`

Track open-state metadata for collapsible content, including `data-*` attributes and measured content height.

### `useTransitionPresence`

Keep an element mounted until its exit animation finishes.

### `useSelectableCollectionNavigation`

Add keyboard navigation for tabs, radio groups, listboxes, and similar selectable collections.

### `useSearchValue` and `useBaseSelectSearchInput`

Build a custom searchable `BaseSelect` while keeping query state and the text input outside the primitive. `useSearchValue` manages controlled or uncontrolled query state. `useBaseSelectSearchInput` supplies IME-safe input, ARIA, focus, and navigation bindings within a `BaseSelect` composition.

### `useSlider`

Manage headless state, pointer dragging, keyboard navigation, step snapping, and thumb styles for single or multi-thumb range sliders.

```tsx
const slider = useSlider({
  min: 0,
  max: 100,
  step: 1,
  defaultValue: 50,
})
```

### `useResizableHandle`

Manage pointer drag interactions, keyboard resizing, and intersection detection for custom resizable panel handles.

### `createMediaQuery`

Create a reactive boolean accessor from a media query.

```tsx
const isMobile = createMediaQuery('(max-width: 768px)', false)
```

### `useListVirtualizer`

Import this optional adapter from `moraine/virtualizer` and install `@tanstack/virtual-core`. Ordinary components and `moraine/utils` do not require it.

Create a `virtualRender` adapter for `List`, `Select`, or `MultiSelect` based on `@tanstack/virtual-core`. Configure row measurement with `estimateSize` and forward `scrollToIndex` through Select or MultiSelect's `scrollToItem` prop when keyboard navigation must reveal an off-screen item.

### `useId`

Create a stable accessor for an explicit or generated element ID.

```tsx
const id = useId(() => props.id, 'dialog')
```

### `useEventListener` and `useEventListenerMap`

Attach event listeners with automatic cleanup when the owner scope is disposed.

### `useLoadingAutoClick`

Wrap asynchronous click handlers and derive a loading state while the returned promise is pending.

### `createContextProvider`

Create a typed Solid context provider and matching consumer hook with optional fallback support.
